# Runtime preview verification v1

This directory contains verification/checksum utilities and example support metadata for a runtime-preview candidate.

- `verify_runtime_preview_candidate_v1.py` — candidate verification.
- `test_runtime_preview_candidate_v1.py` — verification tests.
- `make_sha256sums_v1.py` — checksum generation.
- `support.example.json` — example support metadata.
- `development-benchmark.json` — retained development benchmark metadata.

For the active public release boundary, use [`../README.md`](../README.md). This directory does not independently establish release readiness.
