The current design.

Research has converged on separating long-lived semantic knowledge from short-lived bindings, routes, visual anchors, and motor calibration.

01 · UNIVERSAL

Unknown apps still work

Keyboard, pointer, text, focus, drag, scroll, and observation remain the universal fallback floor.

02 · LEARN

Successful use becomes cheaper

Repeated traces can become semantic methods and short workflows instead of being replayed verbatim.

03 · DEOPT

Invalidate the smallest stale layer

A stale click route does not imply that the semantic method itself is wrong.

04 · GUARD

Skip predictable failures

If focus, geometry, or binding is observably stale, deopt before paying the failure timeout.

05 · OBSERVE

Gate redundant images

The next research track suppresses unchanged or irrelevant visual observations before they reach the model.

06 · VERIFY

Escalate uncertainty

Cheap local verification handles the normal path; ambiguous state can still escalate to a richer observation.

RESEARCH RULES
  1. Correctness is a hard gate.
  2. Fresh/hidden evaluation follows tuning.
  3. Bytes are not tokens; observed pixels are not image tokens.
  4. Negative results stay in the record.
  5. Python is for fast iteration now; implementation stabilization comes later.

Research, not a black box.

Each public checkpoint includes the harnesses, reports, and summary CSVs behind the claim.

Input delivery + sparse reactive control

XTerm, Chromium, LibreOffice Calc, and Inkscape. Established that fixed sleeps do not guarantee application consumption or semantic completion.
