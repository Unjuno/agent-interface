## What a worker leaves

- The owning Issue and narrow question; exact branch/source and additive output.
- Executed command/test, result scope, retained raw/conditions/audit as applicable.
- Adoption/repair/rejection decision and an actual next action or named missing gate.
- Delivery PR/merge and resource release state, when relevant.

Keep this map short. Put scientific detail in the relevant agenda/report and
ownership updates in the existing Issue. If a row is blocked, hold only that
operation and choose independent useful work; do not create a new coordination
service, successor Issue or reservation merely to stay active.
