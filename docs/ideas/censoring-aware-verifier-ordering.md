# Censoring-aware online verifier ordering — #8919

- **Status:** Unverified successor proposal; no allocation or result is recorded for #8919.
- **Source:** Open [Issue #8919](https://github.com/Unjuno/agent-interface/issues/8919).
- **Idea:** Test whether a learner can choose the order of a small, frozen set of pure, read-only, reorderable verification predicates under workload drift using only the observed cost and three-valued result of each selected order. Do not impute outcomes or costs for suffix predicates skipped by short-circuiting. Reorder only between cases; every mandatory predicate must complete before a final PASS.
- **Prior evidence:** [#4258](https://github.com/Unjuno/agent-interface/issues/4258) reported a scoped synthetic cost-ordering PASS: weighted predicate cost 16.61 to 8.40 with exact three-valued semantics, while p95/p99 remained 18 cost units. [#4733](https://github.com/Unjuno/agent-interface/issues/4733) mapped a synthetic crossover at alpha 0.70 on its finite grid. Its issue index also preserves `FAIL`/`HOLD` audit and allocation-integrity outcomes; these are not erased or upgraded by #8919.
- **Overlap:** #5306 concerns whether to acquire another check; #8919 concerns ordering a fixed mandatory set using censored selected-order feedback. It does not authorize changing safety policy or dropping checks.
- **Next test:** A separately frozen simulator should compare the #4258 fixed order against a predeclared non-stationary learner over stable and drift streams, expose only selected-order observations to the learner, and use an independent scorer for counterfactual regret and semantic checks. Report exploration cost, adaptation lag, tails, UNKNOWN mismatches, and false PASS. No real latency claim follows from synthetic cost units.
