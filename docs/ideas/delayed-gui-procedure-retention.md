# Delayed GUI-procedure retention after repeated automation

- **Status:** No-participant design and power-sensitivity work only.
- **Source:** Issue [#8032](https://github.com/Unjuno/agent-interface/issues/8032).
- **Idea:** Develop a consented evaluation of whether repeated automation changes delayed procedural retention, with an initial no-participant protocol and sensitivity analysis.
- **Outcome:** A02's synthetic ordinal-score packet reconstructed 54 power cells across three authored baseline PMFs and assumed effect sizes, plus a 20,000-replicate null control. It is not a real participant power estimate and provides no evidence that automation degrades or preserves skill. Draft [PR #8075](https://github.com/Unjuno/agent-interface/pull/8075) contains the packet; no participant study is authorized by it.
