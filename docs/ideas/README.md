# Idea History

This directory is the compact history of ideas raised in Agent Interface.

It is not a task tracker. GitHub Issues remain the intake, discussion, experiment, and execution surface. Unscheduled idea menus can be consolidated here and their Issues closed as `not planned`, with a link to the preserved idea and its unresolved questions. Closure for consolidation does not mean scientific completion or rejection. See the [repository consolidation plan](../REPOSITORY_CONSOLIDATION.md).

## What belongs here

For each idea, retain:

- **Idea** — the proposal or hypothesis in one short statement.
- **Source** — the originating GitHub Issue(s) or retained research record.
- **Outcome** — what was learned, implemented, rejected, superseded, or left unresolved.
- **Status** — one of:
  - **adopted**
  - **rejected**
  - **superseded**
  - **on hold**
  - **unverified**
  - **inconclusive**

Closed Issues remain valid provenance and should not be omitted merely because they are closed.

## Entry format

```markdown
## <Idea title>

- **Status:** <status>
- **Source:** #123, #456
- **Idea:** <one-paragraph summary>
- **Outcome:** <brief result; link to detailed evidence when useful>
```
