# Revealed information-cost rationalizability in fixed-model GUI agents — #8907

- **Status:** Open, unverified evaluation-method proposal; no Agent Interface experiment or result is recorded.
- **Source:** [Issue #8907](https://github.com/Unjuno/agent-interface/issues/8907).
- **Question:** Across controlled changes in downstream stakes, can one fixed model's observed choices of what information to query be rationalized by a stable general information-acquisition cost on held-out problems, or must that account be rejected/left unidentified? This does not assume a model has human-like preferences or a literal intrinsic cost.
- **Proposed test:** Use a small synthetic GUI-like task with fixed states, priors, query options, channels, wording, model/version, tool schema, and decoding settings; vary payoff schedules only. Randomize schedules/order and repeat. Apply nonparametric revealed-choice tests to query and final-action distributions, hold out payoff schedules, and test power on scripted known-rationalizable and inconsistent policies. Include free-perfect-information, irrelevant/dominated-query, payoff-rescaling, and one-step/sequential controls.
- **Cost separation:** Record query selection, delivered/used observations, final action, token/API cost, tool calls, latency, and failures separately. Operational metering is not the latent behavioral information cost; do not assume a linear Shannon cost or infer it from API usage.
- **Related repository work:** #5306/#7934/#8879 concern VOI, observation selection, or adaptive acquisition; #8623 concerns epistemic-action benchmarking. #8907 tests whether a stable cost interpretation of a fixed model's *observed query choices* is warranted. It is diagnostic, not a new query policy.
- **Prior-art boundary:** [Caplin & Dean (2015)](https://www.aeaweb.org/articles?id=10.1257/aer.20140117) characterize choice patterns consistent with a general costly-information-acquisition model and recover cost bounds. [Dean & Neligh (2023)](https://www.journals.uchicago.edu/doi/10.1086/725174) find human behavior broadly consistent with a general rational-inattention model in their experiments, while rejecting key predictions of the linear Shannon-cost model. [Cook et al. (FEDS 2026-006)](https://www.federalreserve.gov/econres/feds/what-do-llms-want.htm) study revealed LLM choices in allocation games and sequential job search, reporting less consistent rationalizability and more fragile preferences in the sequential setting. These works motivate the transfer; none establishes a GUI-agent result.
- **Decision boundary:** Method validation requires recovering preregistered rationalizable controls and rejecting inconsistent controls at stated error rates. Model conclusions must be scoped to the fixed model/configuration and held-out task family; use `INSUFFICIENT/NOT_IDENTIFIABLE` when assumptions, power, or identification fail. Do not claim optimality, human-like preference, cross-model generality, or production benefit.
