# Route/task-mix hysteresis under feedback

- **Status:** Unverified transfer beyond the finite synthetic model
- **Source:** [#8648](https://github.com/Unjuno/agent-interface/issues/8648), related #5702, #6655, #8135, and #6327; C02 evidence in open [PR #8827](https://github.com/Unjuno/agent-interface/pull/8827)
- **Idea:** Test whether route choices that affect future task demand can create path-dependent long-run route/task-mix outcomes, even when the current route advantage and exogenous conditions match. This challenges fixed-task, per-episode comparisons as a complete long-run value measure; it does not claim the repository already has multiple equilibria or authorize live route adaptation.
- **Outcome:** C01 stopped before candidate/auditor execution when WSLc initialization failed; its corrected source remained uninvoked (0/0). Separate C02 is `PASS_METHOD_SCOPED`: candidate and raw-only auditor each ran once, independently reconstructed 288 profiles and 6,048 endpoints, rejected 5/5 mutations, and found zero nonconverged endpoints. In the held-out `delta=20` slice, three coupled parameter settings met the frozen hysteresis criterion; all three controls had zero qualifying regions. C02 used host CPython after the container image could not be read from the content store.
- **Limits:** The equations and response functions are authored and finite. No real route, task demand, user, GUI, welfare, latency, safety, or product behavior was observed; no automatic route policy is established.
- **Next test:** Any transfer requires evidence that real route selection changes future task mix, with fixed task opportunities and independent correctness/safety outcomes. Keep the fixed-task baseline and any long-run evaluation separate.

C01 and C02 are distinct; C02 does not repair or rerun C01. See the [C01/C02 issue record](https://github.com/Unjuno/agent-interface/issues/8648#issuecomment-6071166617) and [C02 result](https://github.com/Unjuno/agent-interface/issues/8648#issuecomment-6071194912).
