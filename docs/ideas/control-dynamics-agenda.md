## Phase-dependent controllability under interface delays — #8668

- **Status:** open; A01 `FAIL_HARNESS` invalidated; A02 retains `HOLD_STALE_ACK_TRANSITION_UNTESTED`; A03–A05 report separate finite method results. No result establishes live-control behavior.
- **Source:** [Issue #8668](https://github.com/Unjuno/agent-interface/issues/8668); [A01 correction PR #8698](https://github.com/Unjuno/agent-interface/pull/8698); [A02 result PR #8745](https://github.com/Unjuno/agent-interface/pull/8745); [A03 result PR #8751](https://github.com/Unjuno/agent-interface/pull/8751); [A04 result PR #8761](https://github.com/Unjuno/agent-interface/pull/8761); [A05 result PR #8796](https://github.com/Unjuno/agent-interface/pull/8796).
- **Idea:** Test whether a logical interface operation's controllability changes across proposal, admission, queue, emission, consumption, and effect-acknowledgement phases when control and observation messages can be delayed or reordered.
- **Outcome:** A01's reported static-policy contrast was withdrawn after a read-only consistency check found 228/481 counterfactual rows reused a plant already changed by cancellation; no rerun was made. The separately frozen A02 computed each policy action against the same 481 exogenous schedules: its authored optimistic static-cancelable comparator made 102 false cancellation claims and admitted 51 unsafe duplicate retries, while static-uncontrollable and fail-closed comparators each missed 114/114 safe removals. The phase-refined arm preserved 228/228 modeled safe removals with zero false cancellations or unsafe duplicates, and the raw-only auditor rejected all five mutations. Independent review then found A02's stale-ACK outcome was hard-coded in both candidate and auditor, leaving that transition untested. A03 isolated operation-ID/attempt binding: the raw-only audit reconstructed 317/317 schedules and rejected 9/9 mutations; versus the identity-blind comparator's 32 false completions and 12 unsafe retries, the bound reducer had zero false completions, false cancellations, unsafe retries, contradictory-ACK gate failures, or neutral-release aborts. A04 isolated request-bound ACK transitions: 18/18 reconstructed, 8/8 mutations rejected, and four eligible pre-emission cancel/no-effect retries preserved; the latest-type comparator had three false completions and six unsafe retries, while the request-bound output had zero unsafe classifications in this fixture. A05 covered six authored emitted-frontier cases: it preserved the valid queued cancellation and returned UNKNOWN/no retry for two identical emitted views with opposite hidden effect truth; the phase-blind comparator made one false no-effect conclusion and one unsafe retry, and three mutation checks were rejected. A03–A05 support only their respective authored finite subhypotheses. Backend phase observability, delay bounds, GUI effects, product safety, and task benefit remain unverified.
