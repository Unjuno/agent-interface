# No-gold identifiability for GUI effect checkers — #8887

- **Status:** Unverified method-transfer idea with one narrow retained counterexample; the full method remains unvalidated.
- **Source:** Open [Issue #8887](https://github.com/Unjuno/agent-interface/issues/8887); open evidence [PR #8893](https://github.com/Unjuno/agent-interface/pull/8893), head `4b12463f50031ebcae64bbaf24c671cb1b91c6b9`.
- **Idea:** Determine when reliability claims for multiple imperfect objective effect checkers are identifiable without a gold-labelled outcome set, under explicit dependence, prevalence, invariance, missingness, and abstention assumptions. Agreement must not be treated as accuracy or action authority.
- **Retained result:** PR #8893 records `PASS_COUNTEREXAMPLE_ONLY`: four checker columns agree on all eight rows in two same-prevalence hidden worlds, but finite-panel correctness is 100% versus 50%. The candidate returned `UNIDENTIFIABLE_WITHOUT_INDEPENDENCE_EVIDENCE`; the independent auditor reconstructed both worlds and rejected four mutations. Candidate and auditor each ran once; retries 0.
- **Relation to prior work:** #5314 addresses verifier failure domains and quorum credit; #5315/#7993 use labelled outcomes for risk calibration; #5766 covers scorer semantic drift; #7436 concerns human adjudication; #8088 challenges shared specification omissions. #8887 asks whether reliability is statistically identifiable without gold labels, and does not establish a runtime quorum or validate a latent-class estimator.
- **Next test:** If pursued, separately test identifiable and near-nonidentifiable controls, conditional dependence, cross-stratum drift, outcome-dependent missingness, abstentions, and label switching; compare agreement, independence-based latent classes, dependence-aware/partial-identification reports, and explicit `UNIDENTIFIABLE`. Retain convergence failures and independent truth-based evaluation. Do not treat the existing counterexample control as full method PASS.
- **Limits:** The A01 pair is synthetic and only demonstrates that perfect agreement can coexist with different accuracy. It validates no real checker, GUI effect, or reliability estimate. Preserve open PR #8893's scoped evidence and review state.
