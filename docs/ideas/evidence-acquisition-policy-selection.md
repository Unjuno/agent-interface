## Smallest useful test

Use a finite exact-rational decision tree with a small set of observations, costs, deadlines, and explicit outcome dependencies. Include cases where adaptive diminishing returns holds, plus complementary, redundant, correlated/common-cause, stale, and infeasible observations where it fails. Compare greedy, fixed depth-2/3 lookahead, exact Bellman, and a certificate-gated portfolio; separate calibration cases from held-out cases. Keep mandatory safety checks outside policy selection and count the certificate's compute cost.

A future successor, if pursued, needs a new allocation identity, corrected frozen candidate and genuinely independent oracle before a single run; it must not overwrite or pool A01. The auditor should reconstruct reachable histories, conditional marginals, policy paths, expected loss, and overhead. Reject a false certificate, any skipped mandatory check, or any upgrade of UNKNOWN. If no bounded policy has a robust benefit after overhead, retain STOP/YIELD and record no selection value. A finite pass would establish only method behavior on the frozen model family, not live GUI latency, model value, or runtime safety.
