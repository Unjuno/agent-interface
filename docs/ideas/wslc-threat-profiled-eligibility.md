- **Status:** `HOLD_REVIEW_DISAGREEMENT`; this documentation-only threat/asset review certifies no runtime and does not grant operational lane clearance.
- **Source:** Issue [#8150](https://github.com/Unjuno/agent-interface/issues/8150).
- **Idea:** Evaluate whether a runtime's effective controls match the threats and protected assets of a specific experiment before using it for untrusted code.
- **Outcome:** Merged [PR #8167](https://github.com/Unjuno/agent-interface/pull/8167) preserves the frozen protocol, cases, and both raw blind reviews. The [T0 result](../../research/analysis/threat_profiled_runtime_eligibility_8150_t0_20261005/T0_RESULT.md) records 7 workload profiles × 5 runtime categories (35 ordinal cells) and weighted Cohen's κ = 0.8955223881 against a preregistered 0.70 threshold. Separately, reviewers interpreted the M3 mutation differently: one retained INELIGIBLE because protected assets remained in the profile, while the other used HOLD when the boundary premise was omitted. Since M3 required HOLD/UNKNOWN and author tie-adjudication was forbidden, the frozen disposition remains `HOLD_REVIEW_DISAGREEMENT`, not PASS. Preserve the [raw reviewer A](../../research/analysis/threat_profiled_runtime_eligibility_8150_t0_20261005/reviewer_a_raw.md) and [raw reviewer B](../../research/analysis/threat_profiled_runtime_eligibility_8150_t0_20261005/reviewer_b_raw.md) unchanged.

  This is a documentation/retained-evidence review of per-experiment threats, protected assets, and claimed controls; no WSL, WSLc, Docker, container, network, process, filesystem, or memory operation occurred. It does not establish runtime security or eligibility in operation. Operational readiness and authorization remain separate: [#7924](wslc-client-ownership-readiness.md) retains unknown WSLc owner/release, and [#7970](post-ga-wsl-filesystem-placement.md) retains its filesystem-placement start gate. Neither is cleared by this T0, and this T0 does not clear either gate. It does not show WSLc is insecure, Docker categorically safer, any configuration meets a threat model, or general resource isolation, OOM prevention, or parity.
