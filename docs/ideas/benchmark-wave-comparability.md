# Anchor-gated comparability across benchmark waves

This open proposal asks when separately collected GUI-agent benchmark waves can be cautiously compared after task mix or forms change. It does not invalidate existing scores, create a universal common scale, or replace direct same-task pairing.

## Issue #8885

- **Status:** open, proposed, unverified; no result or implementation PR is reported.
- **Source:** [Issue #8885](https://github.com/Unjuno/agent-interface/issues/8885); [National Research Council, *Uncommon Measures*](https://doi.org/10.17226/6332); [Harris, “Some Musings on Comparable Scores”](https://doi.org/10.1111/emip.12609); [Anchor benchmark generation](https://arxiv.org/abs/2605.26321).
- **Problem:** Scores from different waves can vary because of system behavior, task-family composition, changed contracts/oracles, or exposure/order. Existing paired same-task studies remain the preferred causal estimate; this proposal addresses only residual comparisons when pairing is unavailable or a benchmark is refreshed.
- **Method:** Retain immutable task, environment, route/model, oracle and scorer identities; report assigned, unknown, unsafe, failed and timed-out rows by family; sample representative common task contracts using fresh sealed variants; track exposure and order. Compare raw outcomes, prespecified task-mix standardization, and an anchor-linked estimate. Test anchor invariance and family overlap before linking, and preserve per-family estimates and absolute safety outcomes.
- **Decision boundary:** Link only for a predeclared target inference and only when construct/contracts, scoring, exposure and anchor assumptions pass. Differential anchor behavior, absent family support, or material route-by-family interaction yields `NOT_COMPARABLE` or `PARTIAL_LINK_ONLY`; never normalize away safety failures. This is not psychometric equating to a shared latent “agent ability” scale.
- **Nearest work:** #12 defines the held-out cross-domain benchmark/oracle contract; #5980 studies construct convergence; #6000 calibrates difficulty bands for one visual comparison; #8582 tests human/agent item differential functioning; #5939 checks aggregate route wins against strata; #57 retains matched same-task comparisons as primary. None is interchangeable with this cross-wave linking proposal.
- **Next finite test:** A deterministic synthetic table with multiple task families, two waves and known outcomes should include composition-only shift, uniform route effect, route-by-family interaction, anchor drift, non-overlap, exposure effects, and unknown/unsafe rows. Compare raw, fixed-target weighting and anchor linking with exact arithmetic and an independent raw-only audit. No model, GUI, participant or provider call is required for this method test.
- **Limits:** A finite method pass would establish only sensitivity on its frozen table. It would not validate empirical benchmark comparability, justify score conversion, certify safety, or establish a longitudinal performance scale.
