# Calc compiled continuation: integration contract

Status: design for #57 and #56, not a live adapter or an economic result. The existing compiled core and v3 caller remain authoritative. The retained Calc table self-use is evidence of modal interruptions, not a matched comparison.

## Boundary

A domain adapter must bind a caller-selected document/surface and target references to fresh observations, independent predicate evidence, and separately issued admission authority. It must not embed coordinates or action authority in symbols. A recognizer must report unknown/ambiguous when it cannot establish a predicate; a historical screenshot or its path is not current evidence. Capture identity, sequence, scope, and association must survive through admission and execution.

The saved `calc-table-live-01` save and confirm receipts both report `needs_decision`, `focus_changed`, zero completed steps, and verified release even though the application changed modal state. `program_write_may_have_been_attempted` is true. Therefore zero completed steps is not evidence of no effect or permission to replay. After a terminal with possible input, preserve the prefix and delivery uncertainty; a bounded observation-only continuation may obtain fresh evidence without acquiring new input authority. Fresh state may justify a separately admitted next action, but may not silently convert an interrupted execution into a completed core transition.

The workflow must distinguish observed document contents, dialog presence, selected target identity, and independently scored persisted workbook contents. The compiled core's completion is not task success. Unknown/missing/ambiguous target or stale scope must stop before new input; cancellation, expiry, unavailable or failed release, and blocking I/O must preserve their existing boundaries. Treat retained raw evidence as retrievable only when its bytes and identity can actually be verified.

## First integration slice

Build and test a pure mapping of a **single completed socket stage receipt** into typed facts: release state, possible dispatch, completion/interruption, evidence reference and uncertainty. The mapper accepts explicit input only, never opens a socket or GUI, does not mint authorization, and must not equate a historical capture with fresh observation. Map an interrupted possible-write stage to a typed stop with retained evidence, not a replay. Bind this mapper into a test-only composed caller/core fixture only after those facts are verified. Subsequent work must supply actual capture/target resolution, bounded socket I/O, independently scored task effects and the outer three-arm accounting before a live comparison.
