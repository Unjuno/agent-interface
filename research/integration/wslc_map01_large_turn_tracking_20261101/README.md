# MAP01 tracking after a large view turn

This fresh WSLc labeled-frame probe extends the earlier [80 ms camera-shift pilot](../wslc_map01_labeled_frame_tracking_20261031/). It keeps the same fixed navigation, 20 game-state RGB frames and offline candidate/scorer, but changes the guarded left turn between frames 4 and 5 to 1000 ms. No model or attack was used. The evaluator chooses the initial center of the largest first-frame Zombieman label; each candidate receives only the initial/current RGB frames and that initial point. Later game labels are used only for offline scoring.

In aa07, target ID 14 appeared in the first five frames and was not present in the labels for frames 5–19. The fixed 8x8 MAD <=32 candidate returned its original point on all 20 frames: 5 inside the initial target's reported box and 15 with that target not labeled. The wider search with a local 8x8 recheck returned 5 points inside the reported box and abstained on the other 15. Target-not-labeled is an unknown identity outcome, not proof that the target disappeared or that a shot would be unsafe. The fixed point in these 15 frames therefore cannot be established as belonging to the original target by this oracle.

All three guarded navigation/turn programs and owner close recorded verified neutral releases; the final tested keymap was empty. Game health and kill counters did not change. The 20 frames form one correlated sequence and cannot estimate reliability. Wide matching's abstentions in this case do not qualify it for safe action or negate the earlier small-occlusion counterexample. The captures and labels come from ViZDoom's game-state API, not the X11 screenshots used by the live controller; this is not model grounding, real-time actuation or MAP01 completion.

The first aa06 allocation stopped before game startup: the read-only `/src` working directory prevented creation of ViZDoom's temporary directory and the process exited 139. It is retained. The distinct aa07 allocation changed only the container working directory to writable `/tmp`; source remained read-only. WSLc used the pinned image, network none, private Xvfb, 1 CPU / 1 GiB, seed 991031, skill 1 and 35 tics/s.

`public.zip` retains frozen runner/scorer, conditions, failure, frames, labels, action and close receipts and scorer output. `audit.py` verifies hashes, action releases and all 20 frames, reruns the frozen scorer, and removes later labels in a temporary copy to confirm candidate points remain unchanged while scores change. Run without Python optimization using NumPy and Pillow. These are semantic and measurement limits, not a broad benchmark score; Issue 57 and MAP01 completion remain open.
