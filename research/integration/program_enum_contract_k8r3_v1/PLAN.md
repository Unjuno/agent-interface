## Accepted-domain argument

For a JSON string, the new type test is true and the same membership test is
used. JSON null, booleans and numbers cannot equal an allowed string, so both
versions reject them. Arrays and objects cannot belong to the all-string enum;
the previous membership raises TypeError, whereas the new type test rejects
before membership. Thus no JSON value previously accepted becomes rejected and
no new JSON value becomes accepted. Rejection diagnostics, not accepted values,
change. Existing exception annotation provides the original operation index.
