# Idle observation prototype: private Xvfb stop trial

This retains one exploratory WSLc trial of an **unmerged** isolated prototype based on main `46ff81d345de4b08cd62de1bb4fa4ff1b4f7ec0c`. The prototype adds an explicitly bounded idle capture through the existing read-only worker. It stages history outside a short cancellation lock and orders the final sequence commitment against cancellation acknowledgement. A dedicated, single-capture cancellation scope is used; the trial does not add this method to the public owner/MCP API.

On one CPU and 1 GiB, with no container network or image pull, the test created its own Xvfb and X window. It recorded a healthy sequence-1 capture, sent SIGSTOP to that Xvfb, requested a second capture with a 300 ms deadline, then sent SIGCONT. The second call reported unavailable after **301.825 ms**; the observation worker was retired, its thread exited after resume, the owner sequence remained 1, review was required, and keyboard/button state read neutral before and after. Xvfb exited zero. The reader separately persisted an observation-2 artifact after the resumed X request, but the owner did not publish sequence 2. Both artifacts and the raw trial output are retained.

The test successfully sent SIGSTOP but did **not independently record the Xvfb process state or the precise moment its capture request blocked**. Thus the result supports the recorded timeout and late-publication behavior in this cell but does not by itself prove the intended stopped-server ordering. The result file is produced by the same trial process, not a separate observer. This single run, fixed timing and cooperative scheduling do not establish a hard 300 ms bound, physical release under held input, general responsiveness, MAP01 completion or task effect. It uses no model and emits no task input.

Before this trial, Fake X tests of the prototype covered cancellation before publication, commitment before cancellation, late response rejection, a dedicated-scope reuse refusal, and refusal of guarded keyboard and window activation inside the dedicated scope. The complete 29-test local subset ran both normally and with `-O`; these test results are not independently logged in this archive. Other entry points, concurrent direct bridge readers, lifecycle-mode observations, full owner/MCP integration, real input/recovery, and independent server-state observation remain open. In particular, a saved late worker artifact is not published authority and does not prove the worker was forcibly terminated at its deadline.
