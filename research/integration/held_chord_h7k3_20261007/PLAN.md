## Conditional argument
With a single actor, unchanged mapping, and confirmed existing owned holds,
a chord that changes only newly acquired keycodes cannot release a previously
held code on its successful path. The held set and newly acquired set are
disjoint by construction; every generated release targets the latter. Conversely,
the old successful chord explicitly releases every named code, including a
preheld modifier. This proof says nothing about failure paths, external actors,
keymap changes or whether preserving a hold is the desired public semantic.
The native residual is actual XTEST state/event delivery, not the set argument.
