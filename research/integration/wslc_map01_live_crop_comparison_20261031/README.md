# WSLc MAP01 live full-image versus crop comparison

This exploratory four-allocation comparison connects the static crop pilot to a live, development-selected Freedoom2 MAP01 route. Both arms use the same runner, exact 8x8 source/current patch check and additional checks immediately before a model-selected bounded attack. Each arm obtains two `gpt-6.1-sol` low model decisions in one fresh session; a first fire proposal may run only while the second decision is pending, if the existing exact-patch, geometry and binding guards pass. The second answer is recorded, not executed. Game labels, health and kill counters are evaluation-only and are not passed to the model.

The full arm sends the full 1280×1024 screenshot. The crop arm sends the exact 640×480 game window and adds `(320,272)` to returned model coordinates before the same runtime guard. Each request verifies that the captured target geometry is `[320,272,640,480]`; otherwise it stops. The fixed ordered allocation plan was full/crop/crop/full, one attempt each. Runtime and screenshot behavior were not otherwise changed between arms.

In x03 and x04 the game engine first reported a kill while the caller was still waiting for the second model result, after the new attack was dispatched; this is an observed game counter, not independent proof of which input caused the kill. x01/x02 show safe withholding for the specific exact-patch mismatch, not task success. All navigation inputs, completed attacks and owner closes had verified neutral releases, final W/E/D/A/F keymaps were empty, and all model sessions reported closed. Equal pixels and a geometric center check do not establish hostile identity or a clear line of fire; screenshot-to-key emission remains non-atomic.

The two-call median input-plus-output total was 26,765.5 full versus 23,230.5 crop tokens. Cached input is included within input and is not added again; pricing was unavailable. The median request-1-to-observed-response-2 interval was 6.981 s full versus 7.307 s crop. This container-clock interval includes host crop/transfer and both model waits, but excludes initial game startup/navigation and final teardown; it is not a complete task duration or provider-only latency. The fixed same-seed order has only two runs per arm, model-selected durations differ, caching differs, and one action per arm succeeded. These results cannot establish a general speedup, reliability rate, causal advantage, or equal cost. The crop discards external context and the fixed mapping is valid only for the verified geometry. No MAP01 completion is claimed.

Four fresh network-none WSLc containers used private Xvfb, one CPU, 1 GiB, a 90 s watchdog, Freedoom2 MAP01 skill 1 seed 991031 at 35 tics/s, and image `sha256:6150a4f3c779a51b3ac6a7d93bc1d0450803325efb7ab38ade8b1aaf79c33e25`; Windows host model calls used network access. The named containers were confirmed exited and removed. The read-only Python runtime subset matched the earlier fixed-patch probe; intervening main changes were research only. ZIPs preserve the frozen sources, conditions, complete game samples, synthetic screenshots, crop images, model prompts/results/usage, input and release receipts, and logs. The private app-server protocol journals remain local with SHA-256 and size in each `private-local-manifest.json`. Before packaging, each private journal was checked locally for the two sent prompt/image paths; `local-protocol-check.json` is a derived attestation, not the public raw journal.

Run `python audit.py` with Pillow in normal Python mode. It verifies frozen hashes, source geometry and screenshot binding, pixel-exact crop and coordinate conversion, model result/usage linkage, local protocol-check consistency, session and call uniqueness, source/current and pre-key gate images, game sample chronology, observed action and neutral release. It cannot independently re-read the omitted private protocols or prove general semantic safety. More diverse tasks, geometry changes, negative/adversarial cases, matched repetitions, finite recovery and end-to-end timings are needed before adopting the crop path.
