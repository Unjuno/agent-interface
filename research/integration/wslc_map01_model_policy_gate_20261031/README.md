# Model-selected MAP01 policy and visual revalidation

Two new fixed-order WSLc Freedoom MAP01 allocations start along the development-selected route in `wslc_freedoom_map01_threat_route_20261031`. A prestarted `gpt-6.1-sol` low session receives a screenshot and selects a structured `fire` or `idle` policy, a target point, and a bounded duration. After that first model result, the local caller compares an 8×8 RGB patch around the selected point and the window binding against a fresh capture. It then starts a second model turn on the fresh image. The control is stipulated to send no policy input; the candidate would send a bounded attack pulse during that second turn only when the first policy is `fire` and the patch/binding check passes. Game labels and object telemetry are retained for evaluation and are not sent to the model or used as inputs to this policy.

| Run | First model policy | Patch and binding | Local disposition | Game result |
| --- | --- | --- | --- | --- |
| g01 control | fire, 500 ms | patch equal; binding equal | no input by control design | 0 kills, 0 health loss |
| g02 apply | fire, 500 ms | patch changed; binding equal | no input, guard ineligible | 0 kills, 0 health loss |

Both runs reached a visible Zombieman, completed two model turns in the same session, advanced game time during both turns, and verified release of the earlier navigation inputs and owner-close release. g02 did not execute a model-selected attack: it safely withheld this particular action because its exact local patch changed. g01 demonstrates that the equality gate can accept in its own run but is not a positive action control, since that arm deliberately sends no policy input. No model-selected attack effect, damage reduction, cancellation/recovery, combat reliability or MAP01 completion is established.

The gate is intentionally narrow and research-only. Exact patch equality can reject harmless animation, and equality of 8×8 pixels plus window binding does not establish target identity, a clear line of fire or a correct model decision. The model-selected point is checked but not used to aim; shooting uses the current game crosshair. The check occurs before the next model call's start marker and is not atomic with a later input, leaving a check-to-use gap. The prompt requests a centered enemy but the caller does not independently enforce semantic centering. These gaps must be addressed before treating the policy as a general safe control mechanism. The runs are one fixed-order sample per arm on a development-selected route, not a benchmark distribution.

Raw conditions, schema, prompts, model call results and per-turn usage, two model images, game telemetry, screenshots and input/close receipts are retained in the archives. Private model protocol journals stay local and are represented by hashes and size. `python audit.py` independently crops both PNGs, recomputes patch hashes, checks model call IDs/usage and bindings, verifies that no fire input was sent, and checks release and game progression. Cached input and reasoning output are subsets of input and output, not additional tokens.
