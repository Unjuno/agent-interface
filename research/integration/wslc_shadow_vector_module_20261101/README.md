# Research-only vector patch search and WSLc verification

`research/live_control/shadow_patch_match_v1.py` extracts the bounded 16×16 RGB search used in the shadow experiment. It scores every valid two-pixel-grid position within ±80 by ±60 pixels, clips at image boundaries, uses signed arithmetic, deterministically orders ties, and reports a spatially distinct runner-up when one exists. It returns `authority_granted=False` and `requires_revalidation=True` on every result. Inputs must be equal-size bounded uint8 RGB arrays; callers must supply stable snapshots and separately establish freshness, binding, semantic identity and custody. A score is not evidence that a candidate is the intended target. NumPy is required for this research component; it is not wired into the production control path.

Allocation ea01 ran four component tests in both standard Python and `-O` inside a private WSLc container. They cover a translated unique patch, scalar-oracle agreement on clipped boundaries and random RGB data, ambiguous duplicate matches, and rejection of malformed inputs. A replay of the prior dx01 images returned candidate `(672,586)`, score sum 8388, distinct runner-up sum 8748, 4,941 candidates, no authority and mandatory revalidation, agreeing with the retained scalar evidence. The single replay took 9.241 ms in this run; it is not a benchmark distribution or end-to-end speedup. The prior observation-worker test module also passed 12 tests in standard and `-O` local Python against the retained runtime snapshot; it is not a current-main live integration test.

`public.zip` retains source, tests, conditions, input images, WSLc output and verification receipts. SHA-256: `8949ebf5f862ec350de17478acc7bfad93d1c959c0bfe574a8bb21ecbcccf5e5`. Run `python audit.py` without `-O` (Pillow required) to check the archive and pinned dx01 provenance, source identity, test receipts and independently recomputed candidate scores. Actual model behavior, target identity, integration with action gates, general timing and MAP01 completion remain unverified. No model or control input was used in ea01; WSLc listed no active allocation afterwards.
