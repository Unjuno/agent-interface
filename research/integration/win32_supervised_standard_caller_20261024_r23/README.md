# Standard Win32 recovery continuation — R23

R23 is one bounded public stdio-MCP trial on the user-authorized Windows PC. It first cancels one action while a low-level hook holds Q-down for 250 ms after cancel and then forwards it. Only after public recovered status and same-generation independent Q-up readback does it submit a second, distinct action using a fresh observation, new lease, new program ID, and a different call ID on the same fixture generation. That second action replaces and saves a different sentinel. This is a new authorized action, never replay of the canceled program.

The test asks whether the same live session and target generation can accept a fresh task after a verified recovery, and whether its post-recovery effect is independently retained. Runtime task_success remains null. No WSLc or Docker operation, retry, replay, or external window is part of this packet. Freeze all conditions and source hashes before the one-shot probe. Preserve all outcomes.
