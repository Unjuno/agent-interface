This single fresh WSLc attempt extends #9907. The fourth continuation is deliberately withheld if eligible. The fifth decision is revalidated against a fresh image; only if it proposes fire and the geometry/binding checks pass but the sampled target patch changes beyond the preselected threshold does the caller request at most one sixth model decision from a new image. The sixth answer is checked again; idle or a failed gate produces no action. There is no further retry.
