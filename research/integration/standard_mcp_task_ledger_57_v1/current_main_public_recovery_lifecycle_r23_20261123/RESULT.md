# R23 — post-merge public recovery Fake lifecycle

## Result

The ten preregistered independent-process attempts all passed: 5/5 normal and 5/5 under `-O`. Each log reports `Ran 1 test ... OK`; every exit receipt is 0. Individual durations were 0.207–0.222 s normal and 0.208–0.220 s optimized.

The test is the public compiled-caller recovery/task-oracle composition. Each process creates fresh IDs and fixtures, verifies that exact public observation IDs match server-bound Fake callbacks, confirms the lower real-observer `open_session` guard was untouched, preserves source action UNKNOWN/null task success, requires separate matching release/horizon evidence, denies replay, and drains accepted Futures/reports before close.

## Comparison and interpretation

R04 had 7/10 on an earlier source and default D: temp path, with two uncertain/unreleased actions and one observation callback timeout. R23's 10/10 on merged main is an improvement in this local Fake fixture after observer binding and dedicated short C: temp roots, but the change in source, temporary storage and test instrumentation means the result does not isolate one causal factor. R23 is a repeatability result for this synthetic path only, not a real-input reliability estimate.
