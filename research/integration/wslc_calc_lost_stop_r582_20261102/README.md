# Calc lost-stop-response simulation: R582

One fresh WSLc Calc instance displayed a blank sheet, then the host observation deadline expired. The actual identity-checking helper's stop command returned successfully; the test hook then deliberately raised OSError at the caller boundary. The actual two-stage recovery module recorded UNKNOWN for that call, independently re-inspected the same full CID and label, observed exited code 137, removed it without force and observed an empty exact-ID post-list. Task status remained UNKNOWN. This is an injected wrapper exception after a real stop, not a real failed transport or parent death.

Conditions, source copies, screenshot and redacted observations are included. Complete raw outputs and journals remain private locally because they contain host paths and environment data; hashes are retained here but do not make raw independently available. The 6-second monitoring budget is not a total wall-time bound. This single no-input trial does not prove input release, absence of delayed operations, task success, general recovery, live MAP01 or speed. Source files are experimental, not an independently supervised production driver.

Independent review matched 22 running inspect responses, the four retained source hashes, the screenshot hash and both journals. Host elapsed time was 10.563 seconds. The fine ordering of helper return and the injected exception follows the retained sequential source; journal and fault events have no individual timestamps. The helper journal is complete in this sample, so real lost transport or lost journal writes were not tested. Exit code 137 is an observation, not proof of the exact cause of termination or of input release. The corrected payload's internal exception path was not exercised in this run.
