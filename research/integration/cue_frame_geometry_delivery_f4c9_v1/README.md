unchanged audit and saved controls without scientific rerun.

**D:** retain the original scoped result only; require complete lossless
restoration, byte-identical original audit and saved-control verification.
Any publication mismatch is HOLD, not permission to rerun or relabel science.
Ten publication-test methods exercise one positive restore and nine negative
methods (including multiple path cases). Local checks do not assert GitHub CI.

**C:** a producer already emitting reference-bound local coordinates needs no
adapter. Different coordinates may contain identical pixels in a uniform image;
the experiment uses distinct nonuniform patterns and independent raw root pixels.
Capture geometry and image are separate quiescent X requests, not a general
atomic snapshot. The weak adapter is authored research code, not an alleged
production vulnerability. Hashes identify bytes, not source authenticity.

**U:** scrolling/reflow/scale/rotation, object-following, concurrent capture,
source authentication, current input admission, human/model utility, token or
latency gain, arbitrary GUI/backend and product readiness remain untested.
Same-author separate audit implementation is not external human review.
