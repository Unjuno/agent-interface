# G21 grayscale plus PSM consensus diagnostic

This is a bounded follow-up to G20's rejected thresholded PSM7 OCR route. It tests one different candidate: unthresholded grayscale cells, nearest-neighbor 4x scaling, and unanimity across fixed Tesseract PSM modes 6/7/8/10/13 with abstention on disagreement. G12's one-crop PSM comparison already established that the five modes can agree on one known image; this run applies that predeclared refusal rule to the full eleven-frame G20 corpus.

The diagnostic reuses known G08-G12 frames from G20 and is not held out. Duplicate source hashes are repeated frame evidence, not independent samples. The ground-truth sidecar is separate from `input/` and the candidate code does not load it. Five modes from one Tesseract build are correlated outputs, not independent votes. Package attributes keep the original CRLF manifest/oracle bytes exact across checkouts.

See `FREEZE.md` for the exact preregistered candidate and decision rule. `ENVIRONMENT.txt` records the OrbStack image-store error before the local run. `candidate.py` wrote the original raw record once; that local copy is retained as ignored `candidate-out/RAW.private.json`. Public `candidate-out/RAW.json` is the allowlisted path-normalized derivative; `REDACTION_PROVENANCE.json` binds both SHA256 values and `REDACTION_AUDIT.json` records the local field-by-field comparison. No OCR output, timing, crop hash, exit code, or input hash changed. No GUI, model, native input, previous allocation replay, or runtime change is included.

The first audit failure is preserved as `AUDIT.json`; audit v2 checked the local original and the public `audit_publication.py` writes `PUBLICATION_AUDIT.json` from the redacted derivative without rerunning OCR. The post-run clarification and its reason are in `FREEZE_ADDENDUM.md`. Disposition and audit status are recorded in `REPORT.md`. These results only inform the known-image OCR blocker and do not establish held-out accuracy, a safe runtime recognition strategy, task effects, or end-to-end efficiency.
