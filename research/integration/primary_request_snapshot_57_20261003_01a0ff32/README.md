## Finding and repair

`relay_host.send` serializes a synchronous argument snapshot. The exported raw
`primary_caller.call` previously retained the caller's original argument reference
and consulted it after awaited original presentation. A normal presentation
callback mutating a nested batch alias or expected feedback title therefore made
the caller STOP despite the complete, original, source-consistent response.
The typed feedback helper and an external pre-call clone already prevent this.

Four added runtime lines copy arguments once before request validation/control
admission and host send. Later checks use that same admitted snapshot. Clone
failure latches STOP and preserves the original exception before host dispatch.
Tool availability is still checked first. No new capture, action, retry, authority,
response rewriting or auto-recovery is added. The original reply remains returned.
