# Delayed cancellation and RPC replies across the idle deadline

One fresh WSLc cell exercises the unmerged [#10074](https://github.com/Unjuno/agent-interface/pull/10074) draft `ade6624badddf0eb2d9941bd9918381b67725d9c` through an actual spawned owner, private Xvfb and separate synthetic X target. The runtime and target bytes match the [preceding successor cell](../wslc_idle_owned_rpc_successor_20261101). This runner adds **test-only parent-side wrappers** that deliberately hold the real child RPC reply and defer reading the control reply until after a 500 ms parent deadline; it does not simulate partial pipe frames or prove a naturally occurring transport stall.

The test observed Xvfb stopped and the idle RPC pending, sent cancellation, and buffered the real child RPC response before the deadline. The parent observation returned unavailable approximately **0.120 ms after the deadline** and quarantined the owner. Close while the control reply was held returned `cleanup_deferred` / `UNKNOWN`, without release. When the wrapper allowed the control reply through, the raw child receipt said `cancel_requested`; because the parent had already quarantined the owner, the parent returned `cancel_unconfirmed` / `UNKNOWN` without release. The delayed RPC reply did not restore the owner's state. A later close retired the exact old process without automatic release, still `UNKNOWN`.

After Xvfb resumed, a different spawned owner captured the preflighted target and sent a guarded `a`; the separate target recorded press/release and value `a`, the new owner verified release and final input was neutral. The target and private server exited zero. The old operation was read-only and no key was intentionally held during the failure. The wrappers and event timestamps are test instrumentation, and this is one fixed-order cell. It does not establish finite cleanup of held inputs, absence of all late server events, real transport failure behavior, a hard deadline, MAP01 or general reliability. WSLc reported its 1 GiB limit excludes swap.
