# MAP01 model-selected policy: change detected while attack is held

Twelve fresh WSLc Freedoom2 MAP01 allocations explore cancellation after a model-selected attack begins. Each uses the development-selected enemy route, the current-main guarded X11 bridge at `c5f00bd4c0b9deef5f46d22777ef7d14acf185a6`, the pinned image, seed 991031, skill 1, one CPU, private Xvfb and no container network. A prestarted `gpt-6.1-sol` low session selects a bounded fire/idle policy on an image; the candidate applies it while a second model turn is pending. The selected point is checked but not used to aim. Engine labels and score are evaluation-only, not policy input.

The injected condition first observes the attack key down using a separate X11 connection, then maps a magenta window over the selected 8×8 patch. This test-specific monitor captures the root image once after injection, compares the patch, and requests the active guarded input's cooperative cancellation when it detects a mismatch. It is not a continuously running production monitor. Cancellation is for the local attack program; the second model call continues. Acknowledging the cancel request itself is not proof of key release, so the action receipt and final X11/owner readback are checked separately.

| Series | Gate | Observations |
| --- | --- | --- |
| j01–j04 | exact pixel equality | j01/j03 refused at input guard, j02 stopped at earlier source check; j04 completed and scored one kill. No injected held-key case reached cancellation. |
| k01–k04 | mean absolute channel difference ≤20 | k01/k04 completed and scored one kill; k02 stopped at source check; k03 retained a host file-access error before a model call. No injected held-key cancellation. |
| l01–l04 | mean absolute channel difference ≤32 | l01/l04 completed and scored one kill. In l02/l03 the monitor observed F down, detected the injected change, requested cancel, and the incomplete wait ended with verified empty release. |

For l02 and l03 the local time from cancel request to the action receipt's verified release was 7.165 ms and 8.635 ms, respectively. Both requests and releases occurred before the caller observed the second model-done marker. These are two observed timings, not a deadline guarantee or distribution. Both injected runs had zero recorded kill delta, but the key had already been pressed: the execution receipt explicitly retains `failed_op_effect` as unknown. Zero kills does not prove that no shot or other effect occurred. Normal runs also had no observed health loss, so the pair does not demonstrate damage reduction.

The thresholds were selected sequentially after inspecting earlier failed image checks, including the observed j/k pixel differences. They are exploratory tuning, not an independently calibrated detector or evidence of safe semantic target recognition. A mean pixel threshold can miss a meaningful change, allow the wrong object, or fail on harmless animation; centering is geometric and the crosshair aim is not controlled by the model point. Capture-to-key emission remains non-atomic, and the artificial overlay is only one perturbation. Fixed-order small samples do not establish general reliability, autonomous recovery, v39 threat-policy qualification or MAP01 completion.

The k03 host caught a Windows sharing `PermissionError` and wrote an error despite host/container exit 0; it is retained, not counted as a successful model call. The l series adds a bounded two-second retry only for host-side request/image file reads; no model or input operation is replayed. All planned allocations and prior tuning failures are archived with screenshots, model results/usage, game samples and receipts. Private model journals remain local and are represented by hashes and size. `python audit.py` independently recomputes image differences, verifies each model/image association, action/release records and the cancel ordering, and checks that both injected action effects remain unknown.
