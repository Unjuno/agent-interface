# Fresh Calc integration with fixture grounding: R587

One fresh isolated WSLc container ran the archived fresh Calc route with the same 168 runtime/input/driver files as R585 and R586. A host fixture supplied fixed reviewed coordinates for three image-hash-bound requests; it was not a model and produced no usage or token measurements. After entry, a new observation was supplied to the third request, followed by a further observation and guarded Save. The host XML parser independently read exactly 472 and 615 in the saved FODS. Click, entry and Save each produced a nonempty verified neutral release; owner close was verified and a subsequent X readback found no keys and no mouse buttons 1–3 pressed. Exit 0 and identity-verified container removal were recorded.

Conditions, source hashes, scripts, independently checked results and the saved FODS are retained. Full local journals, screenshots and action receipts can contain host paths and environment; hashes are listed but raw is not independently accessible from the repository. This is one fixed-fixture fresh-route engineering trial, not a model call, a statistical three-route efficiency result, parent-death test, general recovery guarantee, full deadline bound or MAP01 result. The pixel difference was detected before mint; no stale capability was submitted to the runtime. Host and container timings are different intervals on separate monotonic clocks.

Independent review confirmed all 168 source/input hashes and experiment hash, fixture request sequences 1→3→12 with matching image digests, nonempty release evidence for all three actions, the FODS contents, and 37 driver inspections plus two cleanup inspections bound to one CID and label. Recorded host elapsed time was 6.703 s and the separate container task interval was 1.382 s. These are descriptive individual observations, not a speed comparison.
