## Concrete composed-path gap

There are useful but separate pieces today: the shared compiled GUI graph composes with the private Win32 `MoveBridge` under inert API doubles (`runtime/guarded_win32_v1/test_compiled_core_composition.py`); an opt-in public `guarded-win32` MCP route has owner/recovery/oracle tests (`runtime/cli_v1/test_mcp_win32_composition.py`); and the public `supervised-win32` standard caller has generation, release/recovery and independent task-oracle tests (`runtime/cli_v1/test_mcp_supervised_win32.py`). These tests are not one route. The public compiled MCP tool documented in `runtime/cli_v1/MCP.md` is currently the guarded X11 path; the guarded Win32 route explicitly does not register `interface_guarded_compiled`.

Before another live allocation, add one deterministic integration regression that drives the shared compiled graph through the existing supervised Win32 public caller and proves: (1) observed evidence selects a later graph action; (2) that action goes through standard generation admission and operation custody; (3) changing the generation during the inter-action wait blocks the suffix before input; (4) completed-prefix/effect evidence stays retained and the old canceled call remains immutable/UNKNOWN; and (5) no oracle success is issued for the refused suffix. The 121-test local run shows the adjacent components pass, but this cross-route composition is the single smallest missing check identified here.

## Public API contract readback

The Win32 server has two distinct routes. `supervised-win32` exposes `interface_observe`, static-only `interface_validate`, one-shot `interface_dispatch`, `interface_cancel`, `interface_results`, and optional server-side `interface_verify_task`. `_run_supervised_win32_dispatch` performs the authoritative target-generation admission and then starts the producer inside the single dispatch operation. `interface_validate` explicitly does not grant runtime admission or freshness. The opt-in `guarded-win32` route exposes a different bind/admit/start tool family. The public `interface_guarded_compiled` registration is limited to the guarded X11 caller.

Therefore a graph adapter must not treat `interface_validate` as its action authorization. The public Win32 `interface_dispatch` remains the final authority check for each graph-selected action; any graph-side admission is only a typed precondition. The integration test must exercise the real dispatch path, retain its call/operation/generation receipt, and map dispatch refusal or unknown custody to a graph safe stop without retry. `runtime/cli_v1/mcp_server.py`, `runtime/cli_v1/mcp_win32.py`, `runtime/cli_v1/MCP.md`, and `runtime/core_v1/COMPILED_GUI.md` are the authoritative local contracts used for this conclusion.
