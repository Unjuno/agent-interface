# WSLc MAP01 crop comparison through cancelled-input recovery

This two-allocation exploratory follow-up connects the full-image/crop comparison to the existing bounded cancellation and recovery path. Each fresh run uses the same development-selected MAP01 route, a real `gpt-6.1-sol` low session, two initial model calls, and an attack only when the unchanged geometry/binding and existing local image checks allow it. An injected overlay is applied only after the monitor observes the attack key held; a detected mismatch triggers local cancellation. The runner proceeds to review/replanning only if cancellation was actually requested; otherwise it records an unmet precondition and stops. After review, the previous alias must be refused. A bounded optional aim correction, a deliberately withheld fourth attack, a fifth decision and at most one sixth decision follow. The full arm sends the complete screenshot; the crop arm sends the exact game window and maps returned coordinates back after checking geometry `[320,272,640,480]`. Game telemetry is evaluation-only.

Both interrupted actions reported `execution_failed` with partial effect **unknown**; their release receipts and the final owner closes verified neutral input, and final keymap checks were empty. A fresh window review succeeded and the old alias was refused without dispatch. In y02 the fifth patch difference was 34.271 and the sixth 34.917, both above the fixed threshold 32; no fifth or sixth attack was sent. In y01 the fifth decision was idle. The game engine's ammo counter moved 50→49 in both cases, but this does not determine the full effect of the interrupted attack. Neither run achieved a kill or verified a post-recovery attack effect.

This is one development-selected fixed-order run per arm. The runs made different numbers of model calls and took different actions, had different cache use, and followed diverging game states; their token totals and elapsed times are **not a matched efficiency comparison**. Cached input is a subset of input and must not be added; price is unavailable. The measured interval starts at request 1 and ends at the observed final response, excluding startup/navigation and teardown. These results show specific cancellation, neutral-release, review and stale-alias behavior under a test-injected disturbance, not general recovery, successful combat, semantic safety, throughput or MAP01 completion. The exact crop omits external context and the coordinate mapping is only valid under the checked geometry. The screenshot-to-key boundary remains non-atomic.

Both runs used fresh network-none WSLc containers, private Xvfb, one CPU, 1 GiB, a 150 s watchdog, Freedoom2 MAP01 skill 1 seed 991031 at 35 tics/s, and image `sha256:6150a4f3c779a51b3ac6a7d93bc1d0450803325efb7ab38ade8b1aaf79c33e25`; Windows host model access used network. The read-only Python runtime subset matched the earlier fixed-patch probe; intervening main changes were research only. Both named containers were verified exited and removed; both model sessions reported closed. ZIPs retain frozen code and conditions, synthetic screenshots and crops, model prompts/results/usage, game samples, cancellation, review, stale-reference and input-release receipts. Private app-server protocol journals remain local with hashes and byte sizes in `private-local-manifest.json`; before packaging, the exact sent prompt and image path for each call were checked locally. The sanitized `local-protocol-check.json` is an attestation, not the public raw journal.

Run `python audit.py` with Pillow in normal Python mode. It checks frozen hashes, screenshot binding, pixel-exact crop and coordinate mapping, call/usage/session linkage, initial and before-key guard images, observed-held/cancel/release/review ordering, stale-alias refusal, fifth/sixth gate images and outcomes, game samples and neutral release. It cannot inspect omitted private protocol bytes or prove semantic or causal game effects. Wider conditions, independently scored post-recovery tasks, longer fault patterns and matched performance tests remain necessary.
