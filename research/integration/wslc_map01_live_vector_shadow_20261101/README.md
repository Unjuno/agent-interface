# WSLc MAP01: live shadow scalar/vector score comparison

Two preregistered model-guided episodes extend the artificial-change shadow matcher. When the fourth-call target fails solely on patch freshness, a scalar 16x16 Pillow search is followed by a NumPy search on the same retained images. The vector timer includes its import statement, crop-to-array conversion and ranking; prior library loading and the scalar-first execution order can affect timing. Every one of 4,941 candidate scores and its ordering must agree. Both calculations are shadow-only: neither can authorize input, and the existing model re-grounding and guards remain mandatory.

- dz01: a synthetic gray overlay caused the shadow path to run. All scores agreed. Scalar elapsed 200.372 ms; vector elapsed 7.889 ms, including the stated conversion/ranking. The shared best difference was 33.25 and the provisional shadow rule held. After the overlay was removed, the fifth model call and unmodified gate led to a completed 200 ms recovery shot and separately verified release. Ammo changed 49→48, while hits remained 1 and damage remained 15; no additional hit is established.
- dz02: the model target was outside the center gate, so neither shadow algorithm ran and no recovery fire was dispatched. Terminal neutral input was verified.

This is one sequential live observation with an artificial perturbation, not a randomized timing study or an end-to-end speedup. Both algorithms were run, so the vector path added work in this experiment. Equal pixel scores do not establish target identity or a safe tracker. The second case supplies no timing data. No general reliability, production readiness or MAP01 completion is established; the candidate snapshot is not asserted identical to main.
