# WSLc MAP01: cancellation callback timing, dg01

This single positive-control run used an artificial magenta overlay in a private Xvfb display while a model-selected, capped 500 ms fire action was held. It evaluates the research monitor's timestamping and the action owner's separate neutral-release check. Conditions and candidate files were frozen before the run. The snapshot is not asserted to equal current main.

The monitor detected the changed 8x8 patch and requested cancellation. Capture ended at 28,911,550,740 ns, callback began at 28,911,578,582 ns and finished at 28,911,594,719 ns, and the action owner independently verified all keys and buttons up at 28,918,336,487 ns, on the container monotonic clock. Thus this run measured 6.757905 ms from callback start to verified release; callback elapsed 0.016137 ms (including copying its result). Cancellation acknowledgement itself reports release unconfirmed. The action was interrupted with partial effect unknown; the simulator independently reported ammunition 50 to 49, one hit and 15 damage, with zero kills. Two model calls and ordinary samples overlapped the monitor. This is not a benchmark distribution, a hard latency bound, a semantic environment-change detector, or MAP01 completion. A blocked callback is still possible, and custody remains with the caller until both worker and action end and release is verified.

`public.zip` contains frozen candidate sources, conditions, screenshots, raw result and observations, launcher output, private-file hashes and a per-member manifest. The zip SHA-256 is `4376cecacdc0cda7009840e3223968e8d5130f894d7f7b585a9dd324dca9b84b`.
