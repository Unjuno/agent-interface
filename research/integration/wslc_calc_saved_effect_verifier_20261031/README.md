# WSLc Calc: saved-file evidence integrated into a research graph

Two fresh WSLc containers used a known blank FODS, fixed reviewed A1 point, main-equivalent runtime 0e3bc97b0186cff2d23ce0e3e0dee3f8386de62f, the pinned Calc image, one CPU, 1 GiB, no network, and a 60-second timeout. No model call. A research-only graph now invokes `saved_effect.verify_saved` after the Save action, and takes its complete branch only after the verifier returns succeeded. The verifier rejects a missing, unchanged, malformed, wrong-value, nested-row or oversized file, reads a bounded regular file with identity/metadata stability checks, and requires an exact changed two-cell FODS result. The expected baseline digest is checked before launch. The owned fixture and single intended writer are trust assumptions; this is not a generic persistence verifier.

- A01: the graph returned TASK_SUCCEEDED / method_complete after a verified Save effect, with two completed transitions, no pending effect and verified releases. The verifier recorded SHA-256 cfb5536cbf0bb2e109b599aa5c70db6f4a1dd9e90bc5905d9edf9d7ea4ddc663. A separately written XML audit checked that the post-close file had the same hash, exactly A1=731 and A2=864, one sheet, two direct rows and no formulas. Close release and neutral X keys/buttons were verified.
- A02 negative control changed only the verifier path to a nonexistent file. The actual task document was saved correctly by independent inspection, but the graph reported SAFE_YIELD / effect_unavailable, with Save pending. The process exit 0 does not mean graph success. Both runs retain all raw outcomes.

The exposed local verifier suite ran 4 tests under normal Python and `-O`, all passing; 106 existing compiled-core tests also passed. The two trial input manifests and 305 frozen runtime hashes matched; both containers were absent after execution, and ZIP integrity passed. These are research artifacts, not a runtime API integration. This single known-task, fixed-layout positive and missing-file control do not establish robustness across applications, live model decisions, partial input recovery with this verifier, matched economics, or MAP01 completion. A stable file snapshot does not independently establish crash durability or exclusive authorship outside the controlled test.
