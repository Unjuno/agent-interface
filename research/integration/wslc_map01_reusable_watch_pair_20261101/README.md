# Reusable bounded patch watch: MAP01 live pair

`research/live_control/bounded_patch_watch_v1.py` extracts the prior [separate-connection monitor](../wslc_map01_thread_monitor_pair_20261101/README.md) into an opt-in research component. The caller supplies a unique action-scoped token, a probe factory with `held()`, `capture()` and `close()`, an exact reference byte string and a cancellation callback. The worker samples only after observing held input, compares mean absolute byte difference, and requests cancellation once on a change, a sample/time budget exhaustion or a probe error. It never reports release as verified. A cancellation acknowledgement is retained separately from the action owner's actual release receipt.

`join(timeout)` returns `running` when a callback or worker has not ended. Python cannot preempt a stuck probe or cancellation callback: the caller must provide bounded operations, retain ownership, and must not start a replacement action or reuse a token until the worker and action terminate and release is independently verified. The monitor uses a daemon thread so a stuck callback is not a process-lifetime guarantee. The 2-second limit begins after the probe factory returns; it is not a hard OS or real-time deadline. Token non-reuse and rejection of a prior token in a new `NativeHandleBridge.cancellation_scope` are covered by local tests, but this component does not itself enforce bridge ownership or semantic target identity.

Two new WSLc MAP01 allocations use the exact archived component in the prior test-specific caller. Both use an independent X11 connection for the probe, a 500 ms capped fire action while a second model call's start/done markers are outstanding, and game counters only for evaluation. df01 watches natural pixels; df02 maps an 8x8 magenta test overlay after the first held capture as a positive control.

|---|---|---|---|---|
| df01 natural | 10 captures; final MAD 130.99 | one cancel requested; action execution failed with partial effect unknown; separate release verified | 50→49; 0→1; 0→15 | neutral |
| df02 injected | 2 captures; final MAD 162.96 | one cancel requested; action execution failed with partial effect unknown; separate release verified | 50→49; 0→1; 0→15 | neutral |

In each run, a normal pending-game sample was recorded between the first and last monitor captures. The first pending-sample gaps were 228.58 and 228.37 ms. The last capture ended 1.67 and 7.89 ms before the action release records, respectively; these are **not** request-to-release measurements because the component did not timestamp the cancellation call. Game counters and labels come from the same simulator and do not resolve the interrupted action's complete effect. No kill or health loss was recorded by the final sample. The natural patch change's cause and semantic identity are unknown; the injected change is artificial.

The 10 component/token tests and 12 related observation-worker tests passed locally under Python and Python `-O` (22 each). `public.zip` contains the exact frozen component and 316-file candidate, test source, conditions, images, monitor crops, model responses, evaluator samples and action/release receipts. `audit.py` checks candidate equality, all hashes, crop differences, sampled overlap, cancel acknowledgement versus release and simulator records. Run the audit without optimization and with Pillow. Private model protocol/workspace files remain local with hashes and sizes and are not independently audited. WSLc used the pinned image, network none, private Xvfb, one CPU / 1 GiB and a 180-second watchdog; host OS, executable and external model service versions are not pinned.

This is a single fixed-order pair on one seed, with test-controlled injection and a non-semantic local pixel heuristic. It is not a production integration, a cancellation deadline, robust supervision, general safety, model-efficiency or MAP01 completion result. Issues 57 and 59 remain open.
