# WSLc MAP01: stale-image withholding and fresh model replan

This finite, preregistered probe extends the [ammo-aware model attack/wait pair](../wslc_map01_model_ammo_control_20261031/). On a fresh Freedoom2 MAP01 skill-1 seed-991031 allocation, the runner navigated, observed an A-key hold, cancelled it, verified release, reviewed the window and confirmed the old alias was refused. It submitted a fresh full X11 screenshot to a persistent host `gpt-6.1-sol` low-effort session. After the request was posted and before the result was handled, the runner mapped a controlled magenta 160×160 X11 overlay around screen center. This timing does not independently prove the provider had already begun inference when the overlay appeared.

The first model response proposed fire at (655, 527) for 1,000 ms. The sampled 8×8 region at that point changed by mean absolute difference 164.307 against the threshold 32, while the binding remained equal. The runner withheld the first proposal before dispatch; this is a local gate decision, not a claim that a native action was submitted and refused. The overlay was removed, a new review advanced the binding revision, and a second screenshot was sent in the same model session. The second proposal was fire at the same point for 1,000 ms. Its fresh comparison difference was 0; the three input-stage checks saw difference 21.479, below 32, and the guarded action completed with verified empty release.

The simulator reported selected-weapon ammo 50 → 47 across the second action while the kill counter remained 0 through eight passive samples, ending roughly 1.37 s after the action sample. Final tested keys were up and owner/host closures reported success. This is a distinguishable simulator response, not evidence of a hit or later effect. The earlier cancelled turn may have had a partial effect. The overlay is synthetic and one successful local case does not prove general semantic safety, V39 planner-fence recovery, speedup or MAP01 completion.

Provider usage for the first call was 12,476 input and 65 output tokens (0 cached input); the second was 14,205 input and 31 output tokens (12,416 cached input). Adapter call times were 5.383 s and 1.880 s. Calls have different context and cache, so these are not a controlled speed comparison.

`public.zip` retains frozen conditions/code, model screenshots and public responses/usage, observation and guard evidence, samples and owner records. Private model protocol/call files remain local and are hash-indexed by `private-hashes.json`. `python audit.py` with Pillow verifies hashes, source and changed image patches, overlay/review ordering, three input-stage patches, game counters and release ordering. WSLc used private Xvfb, network none, one CPU, 1 GiB and a 180 s watchdog.
