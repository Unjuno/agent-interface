The angle is a game-engine observation after the bounded turn; it is not a verified post-recovery attack effect or proof of the interrupted action's full effect.

The fourth and later attack proposals did not pass the existing guard, so the planned stop-after-attempt branch was not exercised and no post-recovery attack was dispatched. z02's fourth pixel difference was only slightly above 32, but the threshold was fixed before execution; no conclusion follows that admitting it would have been safe. The finite outcomes show an operational limitation of this particular threshold and trajectory, not a general failure rate.
