# WSLc Calc: one bounded re-grounding after a stale target

A fresh WSLc allocation used main-equivalent runtime 0099c1234656fe891eaa4b057c4a786ec00f5d9c and the pinned Calc image, one CPU, 1 GiB, no container network and 150-second timeout. This follows #9854. The test deliberately placed a black 8x8 X overlay on the first model-selected A1 point after the model saw the image. The caller observed changed target pixels and refused that decision before mint or input. The test then removed its own overlay and allowed at most one recovery: a new capture, a distinct model call, a fresh target check, and a new guarded click. This is an explicitly scripted research caller, not an autonomous general recovery implementation.

An independent audit checked captured image and patch hashes, distinct model call IDs and request associations, first stale observation sequence 2, new model image at sequence 3, fresh check at sequence 4, and the one click program's later source sequence 5. The caller's recorded pre-recovery inventory had no program or mint. The new click completed with verified release; compiled entry and Ctrl+S also completed with verified release. The graph stopped SAFE_YIELD / effect_unavailable with Save pending, so the graph did not verify persistence. A separate post-close FODS/XML audit found exactly A1=731, A2=864, one sheet, two direct rows, no formulas; SHA-256 211780721cc59491dfbdfb04ea86919a9009c0d2c15d707a6d51b9ca1315499b. Close release was verified and no X keys or buttons were down.

Two independent gpt-6.1-sol low calls used 24,396 input and 140 output tokens total, with 5.742 and 4.781 seconds model-call time; this is not a matched efficiency comparison. The model selected the same coordinates on both fresh images; the earlier response was not reused. The Save icon was checked but not clicked. Input hashes and 305 runtime / 2033 host-source hashes matched; the container was absent after the run. The archive retains inputs, conditions, images, logs, action receipts and both independent audits; local protocol journals are represented by hashes because they contain local paths. ZIP integrity passed.

This one known-layout controlled case demonstrates bounded caller-side re-grounding after an injected change that the test itself removed. It does not prove recovery when the obstruction persists, arbitrary target changes, recovery following partial input, general-purpose planner behavior, matched economics, or MAP01 completion.
