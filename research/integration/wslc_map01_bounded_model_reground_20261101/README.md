# WSLc MAP01: one bounded model re-grounding after stale observation

Two preregistered model-guided episodes extend the reviewed recovery and bounded-turn path. If the fourth-call fire target has valid bounds, center, binding and visual detail but its 8x8 patch changed by more than 32, the candidate refuses dispatch, obtains a fresh image, and asks at most one fifth model call. The same gate is evaluated again; initial interrupted fire is never replayed. Evaluator-only same-state screens and labels are recorded but not used by the policy. The candidate snapshot is not asserted identical to main.

- dt01 (natural change): the fourth-call gate passed without a fifth call. A guarded 200 ms recovery fire completed with separately verified neutral release. Between the game samples bracketing this action, ammo changed 49 to 48, hits 1 to 2, damage 15 to 30 and kills 0 to 1. This is a task-relevant effect observed in the action interval; these counters alone do not prove attribution of the kill to a particular input.
- dt02 (artificial change): the fourth-call target patch difference was 49.313, so no shot was issued and a fifth call received a new image. Its target patch difference was 32.354, still above 32; the gate again refused the shot. Terminal release was verified. The extra call took 3.332 s in the recorded model runner.

The first case used 60,046 input tokens (cached input included) and 146 output tokens across four calls; the second used 79,346 input and 189 output across five. These are unpaired exploratory observations, not an efficiency comparison or general reliability result. They do not prove causal attribution, complete MAP01, or justify weakening freshness checks. More controlled same-scene effect attribution and an appropriate paired baseline are needed.
