# WSLc Calc: bounded recovery after a temporary cell obstruction clears

Allocation ef01 extends the negative persistent-obstruction m01 probe. A compiled fixed-value Calc entry completed once and yielded `SAFE_YIELD / effect_unavailable` on a separate context change. After the original owner's neutral release, the harness placed an 8×8 overlay on the first cell. A fresh owner observed without issuing input. The overlay remained for 679.666 ms; five observed cell cues mismatched. The test then removed its own overlay. A fresh capture 101.437 ms later matched both the expected cell cue and context. Only then did the fresh owner mint a new reference and issue one guarded Ctrl+S program. It did not replay cell entry.

The save completed with verified release; final X keys and buttons were neutral. An independent parse of the whole saved FODS found exactly A1=731 and A2=864. Two `gpt-6.1-sol` calls at requested low effort used 25,763 input tokens (including 12,160 cached input) and 124 output tokens. The task interval was 10.360 s, but this is one case and is not an efficiency comparison.

This demonstrates recovery after a **test-controlled temporary visual obstruction is removed**, not recovery while the obstruction persists, autonomous obstacle removal, arbitrary cell recognition, partial-keystroke recovery, or MAP01 completion. The fixed reference encodes expected values and Save is scripted. No consumed allocation was rerun.
