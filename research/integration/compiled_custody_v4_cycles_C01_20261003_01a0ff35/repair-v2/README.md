core callback subsequence. Its first full raw and original result remain exact.

session and supplies no distinct worker or content/quorum vote.

schedule before accepting a method, in addition to every original v1 typed
payload, receipt, counter, roster and reduction gate. It executes only quoted
saved-data audit definitions. It never imports or runs the collector/runtime,
QueryThreadCycleTime, backend or any original measurement/producer.

For saved-only verification in a fresh owned complete package copy, verify the
root manifest and decompress the exact gzip as documented in the root README.
Then run `python -B repair-v2/auditor_v2.py.txt audit saved-audit-v2-01`.
It must reproduce the original audit-result bytes. Optional directed saved-copy
checks: `python -B repair-v2/test_schedule.py.txt saved-copies-v2-01`.

This verifies a recorded healthy schedule, not independent emitter authenticity,
real clock trust, live cancellation timing, physical input/release, concurrent or
blocking callbacks, model/task/latency/resource benefit, source adoption or main
authority. V1 proposal/acceptance/history are not erased or transferred to v2.
