# Calc OCR cue connected to a guard-rechecked graph

`calc_ocr_graph_perception_v1` provides an opt-in graph builder and perception callback for the existing Calc compiled graph. It combines the explicit expected-value OCR cue with a caller-supplied, independent blank observation for the same capture. A recognized mismatch is not treated as blank. A matching OCR result conflicting with blank evidence, malformed expected/context input, or an OCR callback exception cannot establish an entry or Save. An unknown OCR result can permit entry only when the caller independently establishes blankness for that capture. The caller must provide trustworthy capture-bound context/blank evidence and bounded OCR; the adapter does not establish those properties, input authority, or a saved-workbook effect. In particular, an OCR callback must signal failures rather than silently fabricate evidence.

The original Calc graph used `cells_match=False` to enter but its sheet guard did not recheck a positive blank dependency. A regression in which OCR evidence changes between the graph observation and the input guard dispatched entry with that original graph. The opt-in builder adds `cells_blank` to the initial branch and sheet dependencies; the composed perception callback sets it true only with independent blank evidence and a non-conflicting unknown OCR result. The same regression then stops before dispatch. A second regression changes a matching cue before Save and verifies that the existing Save guard stops the action. A post-entry mismatch retains the pending effect and does not issue a second action.

The retained WSLc f01 run used the pinned Calc image with no network and a fake bridge/transport, no GUI or model. The eight new graph tests plus existing guarded graph and native-dependency regressions passed: 67 tests under normal Python and 67 under optimized Python. Candidate and 2,092 mounted source hashes were checked before/after, and WSLc listed no running instances afterward; `conditions.json`, `result.json`, `verification.json`, `stdout` and `stderr` preserve the run. This is a bounded local regression, not live Calc evidence. Existing live OCR tests exercise a separate experimental composition. The new graph callback has not yet been connected to a real Calc capture or validated against arbitrary documents. Issue 57 remains open.
