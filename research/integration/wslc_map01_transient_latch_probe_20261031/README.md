# MAP01 sampled transient-change latch probe

This WSLc exploratory mechanism probe follows the same development-selected MAP01 navigation route as the fixed-patch time course, then waits while comparing an 8x8 screen-center patch and window binding with a source capture. A research-only latch remembers any sampled RGB mean absolute difference above 32 or binding change. At the endpoint, a scripted 100 ms attack is eligible only if no sampled change latched; a guarded pre-press capture checks the source patch again. No model is called and the point is not a semantic hostile label. The comparison labeled endpoint-only is computed from the endpoint observation; it is counterfactual and did not dispatch an independent control action.

| Allocation | Condition | Sampled RGB differences | Endpoint-only eligible | Latch eligible | Actual action |
|---|---|---|---|---|---|
| k01 | clean | 0.000, 0.000, 0.000 | yes | yes | attack completed and released |
| k02 | transient overlay | 145.245, 145.245, 145.245 | no | no | withheld |
| k03 | overlay, game-state advance after removal | 145.531, 145.531, 9.802 | yes | no | withheld |

k01 and k02 were frozen together and run in that order. In k02 the changed pixels remained in the endpoint capture despite the overlay being destroyed; the cause was not established. k03 was separately frozen after observing that result, adds one game-state advance after removal and moves the endpoint from 0.90 to 1.20 seconds. Its record shows the overlay mapped across both intermediate captures, destroyed before the endpoint capture, and a below-threshold endpoint following the game-state advance. On these sampled observations, the latch refuses an action that the endpoint-only rule would have admitted. It does not prove what an actual endpoint-only action would have done. k02 remains part of the result.

Both navigation inputs completed and were released in all runs. k01's bounded attack and all final owner closes recorded neutral releases; W/E/D/A/F keymap readback was empty. All runs reported health delta 0 and kill delta 0. No task success, target identity, cost benefit or MAP01 completion follows. A latch can also reject harmless animation, as the fixed-patch time course shows. Sampling can miss changes between captures, and capture-to-input remains non-atomic; this is neither continuous coverage nor a production safety guarantee. k03's post-hoc method change, fixed order, same seed and one example per condition rule out reliability and causal performance estimates.

Each isolated network-none WSLc container used the pinned image `sha256:6150a4f3c779a51b3ac6a7d93bc1d0450803325efb7ab38ade8b1aaf79c33e25`, one CPU and 1 GiB (host reports swap limit unavailable), private Xvfb and Freedoom2 MAP01 skill 1, seed 991031, ASYNC_SPECTATOR at 35 tics/s. Python runtime files in the read-only snapshot matched the source subset checked in the preceding fixed-patch probe, with research-only changes through main `1a04fda3f1c22a49697c16690389455dd354e6c5`; no full dependency identity claim is made. The three named containers were verified exited and removed.

The archives retain frozen conditions and runner, screenshots, owner receipts, game samples, inputs, releases and logs. `python audit.py` (Pillow required, normal Python mode) recomputes image hashes and per-capture differences, latch decisions and event ordering, and verifies recorded releases. The next useful test would compare a sampled latch with an endpoint-only control under independently labeled, matched changes and include missed-between-sample cases before considering runtime integration.
