# Private display draft: close status and unconfirmed startup cleanup

The preceding [startup race fix](../wslc_private_display_start_races_20261101/README.md) allowed `close()` to return during startup without indicating that cleanup was pending, and used an unbounded child wait on startup failure. In a local controlled test, a replaced `wait` method recorded a `None` timeout, causing the new bounded-wait assertion to fail before the change. A separate close-status test also failed before the change. These pre-fix console outputs are not in the archive.

The draft now returns `pending` when close occurs during startup and returns `retired` only after child termination is confirmed. Startup failure requests termination and waits at most 0.25 seconds for the child; a timed-out wait raises a cleanup-unconfirmed error without marking the child retired. A controlled test replaces the child's wait method with a timeout and then restores it to reap the actual child. This injection verifies the result path, not behavior of an actually uninterruptible kernel task. Startup preparation, signal dispatch and other operations do not have a demonstrated hard upper bound.

Six tests passed in each of two fresh WSLc containers, normal Python and `-O`, with pinned image `sha256:6150a4f3c779a51b3ac6a7d93bc1d0450803325efb7ab38ade8b1aaf79c33e25`, one CPU, 1 GiB memory limit, no network and no pull. WSLc reported swap was not limited. [raw.zip](raw.zip), SHA-256 `b72988111530f0061a9cd80f7acde7e5bf80a8004f6fee1c8eed0f09a9fcb4a3`, retains the candidate, test sources, hashes and both test outputs.

This is a draft, not a complete recovery primitive. Pending close still requires a later check after startup exits. Concurrent retire/close calls, pidfd-open failure followed by cleanup timeout, cookie lifecycle, resource exhaustion, broad test suites and production integration remain unverified. Earlier held-key composition was performed on a previous source revision. No old physical release, task recovery, MAP01 completion or hard deadline is established.
