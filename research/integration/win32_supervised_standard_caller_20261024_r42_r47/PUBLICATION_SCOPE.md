# Publication scope and redactions

The six attempt packets retain the public result, frozen conditions, source/audit files and raw fixture/caller receipts that support each stated outcome. Each `SHA256SUMS_PUBLIC_R01` manifest covers every file published in its attempt directory except the manifest itself.

The original `SHA256SUMS` and post-hoc manifests are retained unchanged as historical artifacts. They were generated before publication filtering and may list generated bytecode or local-only test logs that are not present in the public tree. Use `SHA256SUMS_PUBLIC_R01` to verify the published tree. The corresponding private excluded-file hashes are retained outside the repository.

Excluded local-only material: generated `sitecustomize` bytecode and focused test logs. R46's original phase-2 stderr contains a workstation-local path; the exact original is retained outside the repository and its SHA-256 is in the private excluded-file manifest. The public `fixture.stderr.redacted.txt` is a labeled redaction and explanation, not a verbatim raw log. R46's frozen result and failure classification are unchanged.

The publication filter does not alter any preregistered condition, original raw artifact that is included, frozen audit, or experiment disposition. No new experiment or replay was performed for this integration.
