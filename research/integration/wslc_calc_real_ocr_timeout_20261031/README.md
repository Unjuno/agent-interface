# WSLc Calc: real direct-child OCR timeout and clear control

Two preregistered one-attempt WSLc runs used frozen main `81a11b800b69c8e0e3a79cc3e94c27a4cbf8bdc4`, the recorded source snapshot and image, one CPU, no container network and a single model call each. The compiled method entered values once, then returned `SAFE_YIELD` because its intentionally stale check could not establish the effect. It did not replay entry.

* e08 ran a real Python child in place of OCR. The child wrote its PID, slept for three seconds and would have written a marker. The one-second `subprocess.run` timeout occurred; a later observation, more than three seconds after the child started, found neither the PID nor the marker. The recovery cue was unknown, no new Save was attempted, the disk file remained byte-identical to the blank fixture, and input release was verified.
* e09 used actual Tesseract on the same fixed crop geometry. Both OCR calls returned, the cue was filled, one separately guarded Save completed, and independent FODS parsing found exactly 329 and 517. Input release was verified. Each run used 12,200 input tokens and 62 output tokens.

Run `python audit.py` with Pillow installed to check the evidence archive. It verifies frozen hashes, the image crops, OCR output and cue, call receipts, guarded action and releases, and independently parses saved cells. `public.zip` excludes model session protocol journals; their hashes are retained. The `verification.json` in the archive records the source/input hash and empty WSLc list checks made after execution.

This is a controlled direct-child timeout, not a hung Tesseract process or proof about descendants, uninterruptible processes, or arbitrary deadlines. The observations use the test process's `/proc` check and controlled marker, not an independent OS trace. A fixed screenshot geometry and known expected values constrain the positive case. The compiled method itself remains `SAFE_YIELD`; the guarded recovery is a new Save, not a replay. The legacy OCR metadata reports psm 11; the call recorder identifies the submitted psm 7 commands. This does not establish MAP01 or general live-control completion. Issue 57 remains open.
