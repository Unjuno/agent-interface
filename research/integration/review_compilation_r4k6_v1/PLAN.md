## Read-only acceptance rationale

1. Bind each presented source digest and byte length to a frozen exact input.
2. Reconstruct the report using only the declared local report-reference marker,
   or retain the unprojected report. No external lookup substitutes for a record.
3. Compare all parsed report content and the independently expected diagnostic
   fields. This preserves the recorded prefix/uncertainty for the tested inputs.
4. Verify invocation is review, not dispatch. This does not establish authenticity
   of the original report or successful original task, and grants no new action.
