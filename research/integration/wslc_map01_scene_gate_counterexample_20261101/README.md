# Scene-change gate: one MAP01 sequence and a synthetic counterexample

The [large-turn probe](../wslc_map01_large_turn_tracking_20261101/README.md) showed that a fixed 8x8 patch can remain similar while the original target is not labeled. This study explores adding a whole-scene RGB mean-absolute-difference (MAD) check: accept the old fixed point only if the 8x8 MAD is at most 32 and the sampled scene ROI (y=60..379, x=40..599, stride 4) has MAD at most 18. Candidate decisions use image pixels only; game labels are used afterwards for scoring. The gate is a research candidate and grants no input authority.

The scene threshold 18 was chosen after inspecting the earlier 80 ms and 1000 ms turn sequences; it is not calibrated. A separately frozen aa08 WSLc run used a new 500 ms guarded left turn and otherwise the same development route, fixed game setup and scorer. Among 20 correlated frames, the original target was labeled for the first five and not labeled for the next 15. Fixed 8x8 returned its old point on all 20 (5 inside the labeled target, 15 target-not-labeled). Both the existing wide matcher and the scene-gated candidate returned 5 inside and abstained on the 15 remaining frames. Label absence means identity is unverified, not proof of disappearance or an unsafe shot.

A post-hoc **synthetic** counterexample covers the first-frame target box in magenta while preserving the original 8x8 center patch, and removes the target label for scoring. The scene MAD is only 1.073, so the scene-gated candidate still returns the original point despite the constructed occlusion. This demonstrates that the rule cannot establish target identity or authorize an action. The manipulation and label removal are deliberately artificial; it is not a new game observation.

The aa08 navigation and turn programs and owner close recorded verified neutral releases; final tested keys were up. WSLc used the pinned image, private Xvfb, no network, one CPU / 1 GiB, Freedoom2 MAP01 skill 1, seed 991031 and 35 tics/s. The original 20 frames and labels come from ViZDoom's game-state API, not the live X11 screenshot path. No model or attack was used.

`public.zip` retains frozen code, conditions, frames, labels, scores and release receipts. Run `audit.py` without Python optimization, with NumPy and Pillow, to check hashes and releases, rerun scoring and reconstruct the synthetic occlusion. One correlated sequence, a development-selected threshold and an artificial counterexample do not establish general tracking accuracy, calibrated safety, efficiency or MAP01 completion.
