## Decision

- **H:** Existing compiled representation, local branching, standard dispatch, and feedback can reduce repeated model-visible work while preserving correctness. The magnitude and even sign of net savings are unknown.
- **Evidence:** Current composition is regression-tested, and native-Windows fixture releases/effects have scoped successful samples. WSLc S02 proves one single-container runtime/read-only-input path on this host, not GUI/control. The separate Calc G14 WSLc attempt is retained as `SAFE_YIELD / effect_unavailable` with one unmatched sample (18,032 tokens; 9.277 s host wall); see [its correction](calc_consensus_report_3311_4d74_20261004/calc-measured-consensus-4d74/REPORT_CORRECTION.md). No retained source establishes the current compiled bundle's matched cold/warm/invalidation/repair comparison on the intended WSLc application.
- **D:** **HOLD for live qualification and adoption.** Do not promote synthetic `TASK_SUCCEEDED`, native fixture timing, local runtime portability, or historical P01 savings into an integrated WSLc efficiency/reliability claim.
- **C:** A live comparison could lose on method generation, schema preflight, retries/repair, extra observations or stricter safe stops; baseline task difficulty and app behavior can also dominate.
- **U / next gate:** Issue [#7924](https://github.com/Unjuno/agent-interface/issues/7924) remains STOP/HOLD for shared WSLc client/container ownership and allocation reconciliation. Do not run or enumerate shared WSLc state while this gate stands. Once an unused owned lane is evidenced, freeze a matched task schedule and run the standard caller across cold, warm reuse, invalidation and repair; preserve every attempt, actual model tokens/resumptions, separate local/model/verification latency, independent effect/collateral scores and raw evidence. Then issue RETAIN/HOLD/REJECT with uncertainty.
