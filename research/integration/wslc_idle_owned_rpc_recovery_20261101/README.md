# Spawned-owner idle RPC: stopped server and fresh synthetic task

One fresh WSLc allocation exercised the **unmerged draft** [#10074](https://github.com/Unjuno/agent-interface/pull/10074) at `da3545ad1e1c29d3927573ea2e26dddb5da74303`, through `OwnedGuardedSessionOwner` and its spawned-process RPC against a private Xvfb. A separate preflighted X client displayed a textured target and recorded received keys and a string value. The test used one CPU, 1 GiB, no container network and no model.

The old owner completed one healthy capture. After SIGSTOP, `/proc` showed the Xvfb in state `T` and the test observed the owner's RPC lock held while the server was stopped. The 500 ms idle observation returned unavailable approximately **0.137 ms after its deadline**. The parent marked the owner failed/review required; closing it while Xvfb was stopped retired that exact child without an automatic release and returned `cleanup_status=UNKNOWN`. This is deliberately not a release-success claim.

After SIGCONT, a different spawned owner captured and minted the target, then used the ordinary guarded owner interface to send `a`. The separate target recorded one `a` press and release and changed its value to `a`. The action release and fresh-owner close were verified, and keyboard/button readbacks were neutral before and after. Both target and Xvfb exited zero. No key was intentionally held across the stop; the old operation was read-only. The target and runtime do not establish MAP01, model behavior, safe recovery from held inputs, a hard deadline, or general reliability. The stopped/pending ordering is recorded by the trial process; an RPC lock being held does not independently prove exactly which X request had reached the server.

The target source matches the previously preflighted target. The archived source subset, after CRLF normalization, matches draft head `da3545ad` **except** `runtime/host_v1/test_primary_caller.mjs`, an unused test file from the earlier source snapshot; the audit checks and reports this mismatch. Source hashes for the actual frozen candidate remain in the manifest. `public.zip` also retains conditions, logs, snapshots, action and close receipts, screenshots and target output; SHA-256 `414c424a2557463c81b51e53073d28985aef31a1d0da4eef5eef40133388ab11`. WSLc reported its memory limit excludes swap.
