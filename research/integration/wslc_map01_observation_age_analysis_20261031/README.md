# MAP01 retained observation age and pixel change

This retrospective analysis uses existing archives from the bounded-aim, fifth-decision and bounded-model-retry pilots. It asks whether elapsed time alone distinguishes their recorded changed-patch cases. It invokes no game, model, GUI or input. The 15 records are gates from six development-selected attempts, not independent trials; there are multiple gates per attempt, a shared seed, differing scripts and selective continuation.

`analyze.py` reconstructs each source and checked screenshot association from the original owner records, checks their PNG hashes and model/point association, recomputes the 8x8 RGB mean absolute difference, and calculates capture-start to capture-start elapsed time using the two container observation timestamps. It also reports the caller-observed model start-to-done interval, which includes observation/polling effects; it is not provider-only inference time. Run `python analyze.py` from any directory with Pillow installed. `result.json` is the retained output. Input ZIP bytes were compared to Git blob IDs at main `1dcf66fe4d18e5ea49e05b8275fcc83d590ba71f`: n01 `684125948575d5801d21b47a3f7304aeee5e2f6a`, n02 `e9c431fbc7ef085922447ea1f81eec85e240410d`, n03 `e4d161d9631e5fe49b7f03f4a43a736be77d147b`, n04 `f8057a31e30b0246f9f39ff38bc949c8dc642cea`, ee02 `ed7f27967f70912edaafaa1bbd4fd2dcab60846a`, ff01 `f9f13115727974fd8f9e56043f0e72db5f315617`.

Across these 15 selected records, capture-to-check ages range 2.150–3.120 s (median 2.891 s); observed model waits range 2.084–2.988 s (median 2.753 s). In ff01, the fifth fire proposal's image pair was 2.377 s apart and its patch difference was 48.25, exceeding the existing threshold of 32; its fourth pair was 3.063 s apart and the difference was 24.81, below that threshold. Three of the 15 differences exceeded 32. Gate eligibility also includes geometry, binding and other checks, so it must not be equated with patch difference alone; the sixth ff01 action was idle even though its gate was eligible.

The measured waiting interval occupies much of the observation-to-check period in these selected cases. The two contrasting ff01 pairs show that simply choosing a cutoff between their ages would not reproduce the existing patch decision. This does not show that the patch threshold is correct, establish target identity or semantic safety, isolate the causal effect of model latency, predict other scenes, or measure actual task success. The capture-to-check measurement ends before input and omits the remaining check-to-press race. Future live comparisons need independently labeled state changes, matched tasks and timing, and action/effect verification; reducing or overlapping model waiting is a candidate to test, not a validated remedy.
