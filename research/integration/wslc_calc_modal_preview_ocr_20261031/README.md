# Calc paste dialog: OCR a new preview before arming the modal guard

This fixed-layout WSLc Calc follow-up removes the requirement that the previously reviewed screenshot contain the current preview values. The earlier reference shows 641/283; the new clipboard contains 329/517. The harness compares the unchanged title, options and button regions against the old reviewed screenshot, then runs bounded Tesseract on two fixed preview crops and compares them with explicit expected values. Only after both checks pass does it arm `ReviewedModalGuard` against the current exact modal capture, including its preview, and use a fresh guarded confirmation. The prior paste graph remains `SAFE_YIELD`; it is never replayed.

* f15 deliberately expects 330/517. OCR reads 329/517 at confidence 96.20/91.56, so the cue is `wrong`; no confirmation or Save occurs, the saved file remains blank, and input release is neutral.
* f16 expects 329/517. The cue is `filled`, one guarded modal click completes, fresh Calc-cell OCR confirms the values, and a separate guarded Save produces an independently parsed FODS containing exactly 329 and 517. Original, modal and fresh owners verify neutral release.

Before preregistration, an exploratory analysis of the earlier 641/283 screenshot found that wider preview crops produced unreliable OCR; tighter fixed crops recognized both. Both the unsuccessful wide-crop results and the chosen tight-crop results are retained. The new 329/517 pair was then run once per condition without retry. This is not a blind generalization study: the input values are known, coordinates and static dialog appearance are fixed, and the OCR crop was selected using a previous screenshot. No model was called.

`python audit.py` with Pillow verifies archive and source summaries, the exploratory OCR outputs, the older reference's different preview, static-region equality, reconstructed current preview crops and OCR transcripts, current-capture guard checks, original and recovery action/release receipts, fresh cell OCR, independent saved FODS and cleanup. It does not establish semantic identity outside the selected regions, arbitrary fonts/layouts, unseen dialogs, external concurrent changes or broad reliability. The recognition and orchestration remain experimental harness code; the reviewed guard is reusable. Source/image bytes and external dependencies are not fully reproduced. Issue 57 remains open.
