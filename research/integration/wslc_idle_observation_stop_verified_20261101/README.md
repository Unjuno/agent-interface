# Idle observation prototype: observed stopped-server ordering

One fresh WSLc cell follows the [earlier private-Xvfb trial](../wslc_idle_observation_prototype_20261101/README.md), using byte-identical frozen prototype source but a new runner and allocation. The prototype is **not integrated into runtime or MCP**. This cell adds `/proc` state and worker-pending observations to distinguish a stopped server from a merely delayed call.

After a healthy sequence-1 capture, the test sent SIGSTOP to its own Xvfb and observed process state `T`. It started a second observation with a 500 ms deadline, observed the reader pending and alive while the server remained `T` before that deadline, and saw the call return unavailable while the server was still stopped. The measured capture call was 501.239 ms and returned 1.365 ms after its deadline. The worker was retired but still pending/alive before SIGCONT; after resume it exited. Its later sequence-2 image was retained by the worker, while the owner sequence stayed 1 and required review. Input was neutral both before and after, and the private server exited zero.

The `wchan` sample was `poll_schedule_timeout.constprop.0`; that is an observational wait-channel label, not proof of the exact X request or network-stack state. `/proc`, worker status and event ordering are recorded by the trial process itself, not an independent observer. A single timing cell and a stopped private server do not prove a hard deadline, cancellation behavior under real input, physical release, finite recovery, application task effect, MAP01 completion or production readiness. The 1 GiB limit excluded swap according to WSLc. No task input or model was used.

`public.zip` contains the frozen candidate, conditions, timestamps, logs, observations and images; SHA-256 `1ca2f8069c6c788c3c39a553264f674c31a256b766be2f31e149f247cd85f5ed`. It checks all archive hashes, byte-identical source against the prior packet, event ordering and both screenshot artifact hashes. This validates retained records and does not independently re-observe the historical process.
