# WSLc Calc: saved-file effect after input-owner deadline

Two fresh WSLc allocations used LibreOffice Calc on private Xvfb, a known blank FODS, main-equivalent runtime f587541bb6343b797b6b80cdc96d7528ea9622a1, pinned image, one CPU, 1 GiB, no network and a 45-second outer timeout. The existing guarded keyboard path entered 731 and 864 with verified release; a reviewed fixed-layout pixel cue confirmed the filled cells and the file still matched the blank baseline. A research-specific supervised worker then checked the focused Calc ancestry under an X server grab, issued Ctrl+S and synchronized the X connection before an 800 ms deadline, then stalled. The existing prestarted supervisor retired the worker and returned UNKNOWN. The save worker directly used XTEST, bypassing public guarded dispatch; no model call or production integration is claimed.

- A01 running-Calc control: the snapshot at owner retirement already contained exactly A1=731 and A2=864.
- A02 stopped-Calc case: the harness verified the window's `_NET_WM_PID`, owned process group and executable, SIGSTOPed the Calc process, and confirmed `/proc` state T before the save request. At owner retirement the file still matched the original blank digest. After SIGCONT, without replay or any further save input, the file changed and an independently written XML audit found exactly A1=731 and A2=864. Thus a meaningful saved-file effect appeared after the owner timed out and retired.

The aggregate audit checks entry release, reviewed filled cue, owner UNKNOWN/retirement, focus ancestry, stop/resume and timestamp order, baseline/mid/after file hashes, XML values, neutral Ctrl/S and mouse states, absence of fallback and observation beyond the worker's scheduled later marker. The marker did not appear. Frozen inputs and 305 runtime hashes matched; both containers were absent and ZIP integrity passed. Each arm is one controlled observation. The snapshots show file contents, not crash durability; they do not establish a generic app acknowledgment, public dispatch behavior, all queued effects, model efficiency or MAP01 completion. The result reinforces preserving UNKNOWN and reconciling actual effects before any new action.
