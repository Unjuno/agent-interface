One new isolated WSLc allocation ran the fresh Calc route with the R588 fail-closed action release gate. All other staged runtime/input/driver source bytes matched R587, with the reviewed runner overlay and release_gate.py added. A host thread supplied fixed coordinates for three image-hash-bound requests; no model or token usage was involved. The runner entered 472/615, obtained a fresh third fixture response and guarded Save; a separate host XML parser confirmed the saved cells. Click, entry and Save each had nonempty verified neutral release, owner close was verified, final X readback found no keys and no mouse buttons 1–3 pressed, exit was 0, and the identity-verified container was removed.

Conditions, source hashes, scripts, independently checked results and the exact saved FODS are retained. Full raw local journals and action/image artifacts may contain absolute host paths and environment; the hashes listed here do not make the raw independently accessible. The no-release and missing-key rejection cases were tested offline in R588, not induced in this live trial. A single fixed-fixture run does not establish model effectiveness, statistical speed, parent-death recovery, total hard deadlines or MAP01. The stale pixel gate was checked before minting; no stale capability was submitted to runtime.

Independent review matched 169 staged source hashes and the experiment hash, verified the overlay bytes against R588, checked all three image/request pairs and sequence 1→3→12, and matched 37 driver inspections plus two cleanup inspections to one CID and label.
