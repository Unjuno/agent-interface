# Detached idle history: delayed-reply successor cell

One fresh WSLc cell repeats the [delayed-cancellation/RPC-reply experiment](../wslc_idle_owned_cancel_response_race_20261101) using unmerged [#10074](https://github.com/Unjuno/agent-interface/pull/10074) draft `0675ab810f7ee890d0904b8a402678c81f8dbafb`. The test runner and separate synthetic X target are byte-identical; five runtime/document/test files differ because this candidate stages a new observation in a detached history before publishing it. Parent-side test wrappers deliberately hold the real child RPC and control replies across the 500 ms parent deadline.

The parent returned the observation as unavailable about **0.116 ms after the deadline**, while the private Xvfb was stopped. Close while the control reply was held returned `cleanup_deferred` / `UNKNOWN` without release. After the wrapper released the actual child `cancel_requested` receipt, the quarantined parent returned `cancel_unconfirmed` / `UNKNOWN`; the delayed RPC did not restore the owner. A subsequent close retired the old child without automatic release. After Xvfb resumed, a new spawned owner performed a guarded `a` action; the separate target recorded the press, release and value `a`, the new owner verified release, and final input was neutral. Target and server exited zero.

The specific uncommitted-history exposure was reproduced and checked with a deterministic Fake X test in the draft; this real-X cell does **not** pause the history at that boundary or independently demonstrate its absence. The staged-history fork copies retained metadata and may cost O(number of observations); no long-session latency or memory benchmark is included. The wrappers induce delay rather than reproduce a natural pipe failure. This one cell has no old held input, model or MAP01 task, and does not prove physical cleanup, hard timing, general reliability, or readiness to merge. WSLc reported that the 1 GiB memory limit excluded swap.
