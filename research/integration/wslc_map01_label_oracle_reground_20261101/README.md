Two preregistered natural/injected episodes repeat the model-guided reviewed-recovery and bounded-turn path, adding ViZDoom label rectangles to evaluator samples only. Label boxes are not passed to the model or action gate. The candidate snapshot is not asserted identical to main. Each episode used four `gpt-6.1-sol` calls at requested low effort; an interrupted fire retained unknown partial effect and was separately released, followed by read-only review and a 100 ms turn with verified release.

The model's fourth target converts from desktop `(655,548)` to game `(335,276)` using the observed window geometry; both this point and nominal game center `(320,240)` lie within that sampled rectangle. The sample was 52.719 ms before the fourth image request, so it is not a pixel-synchronized guarantee about the screenshot or later firing. In dr02, the evaluator sample at tic 701 had no Zombieman label; it preceded the fourth image request by 48.868 ms. The model chose idle and no recovery fire was dispatched. In both episodes terminal neutral input was independently verified. These are scoped observations, not a successful recovery hit, a detection benchmark, semantic safety proof, or MAP01 completion.
