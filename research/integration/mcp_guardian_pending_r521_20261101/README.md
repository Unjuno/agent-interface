# Prestarted guardian after an injected MCP cancellation stall: r521

One preregistered synthetic trial used in-process MCP against a private Xvfb on Docker Desktop Linux. The server was configured with the real guarded owned-process, its prestarted cancellation supervisor, and the experimental owned-display Xlib guard. After MCP observation started those processes, the fixture started an independent guardian and transferred owner and supervisor pidfds; the guardian was ready before the guarded input began. The patterned target recorded KeyPress(a) and the X keymap showed `a` down.

The fixture injected a wait **before** the real owner cancellation method, then made one `interface_guarded_cancel` request. Its response, the original action and the retained cancellation were pending; the cancellation operation ID matched the injected gate. The fixture manually committed the guardian handoff, an outside observer pinned the owner, supervisor, guardian and display, and the parent exited via `os._exit(0)`. The guardian receipt reported sending signals to both transferred pidfds and observing exits. Independent pidfds also showed both exits while Xvfb and a sentinel remained alive. A subsequent connection to that still-running Xvfb observed the key up; this does not prove old release delivery, queue drainage, or task success. The old outcome remains UNKNOWN and no replay is authorized. Cleanup subsequently observed exit on each acquired pidfd.

The raw archive contains preregistration, scripts and pretrial hashes, MCP observe/mint/action/cancel/result metadata, parent and guardian receipts, observer checks, cleanup, stdout and exit. It used experimental draft `7a131be784b6c135c78cf63e48e21ece783c5b30` and image `agent-interface-xvfb-mcp:late-input-r19` (`sha256:bd191d30ea94871a1d3ca717252cd07a276e8ef7d1bcb4a130b63935ce075425`), no network, one CPU, 1 GiB and no pull. The observation's temporary image artifacts were not retained and no X authority cookie is archived.

This is a single manually committed, abrupt-parent-exit trial with an injected stall. The real owner cancellation method was not entered before parent exit; this is not normal cancellation completion or graceful MCP transport shutdown. The guardian's token is not a durable MCP operation/custody record and it does not know the input obligations. The gate's operation ID is captured, but its call token is not retained for independent comparison with the action call ID. The raw contains no independent witness of the configured Xlib guard's peer check. Pidfds were opened from trusted fixture PIDs without independently authenticating their incarnation; guardian signals are supported by its receipt rather than an independent signal trace. Early failures before observer registration rely on container containment, and partial parent output or the later Xlib query can rely on the outer timeout. No writer stall, guardian crash, old release, general reliability, hard deadline, real task, MAP01 or benchmark is established. This does not resolve the failing shutdown regression in PR #10131.
