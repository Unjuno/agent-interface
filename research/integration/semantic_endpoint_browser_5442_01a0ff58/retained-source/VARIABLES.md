# Variables and scope

| 記号/フィールド | 日本語の意味・定義 | SI単位 | 範囲・前提 | 型 |
|---|---|---|---|---|
| trial_id | 互いに独立した専用レコード対の試行識別子 | 非物理識別子 | C001〜C008 | 文字列 |
| phase | 初回操作か、別意図による修復か | 非物理識別子 | initial / repair | 列挙文字列 |
| namespace | この専用SQLiteファイルに限定した対象空間 | 非物理識別子 | owned-endpoint-5442-01a0ff58 | 文字列 |
| target | 意図した文書とイベント上の実対象 | 非物理識別子 | A / B、意図はA | 列挙文字列 |
| version | 保存レコードの更新世代、時間ではない | 1（無次元） | 整数0以上、本試行0〜3 | 整数スカラー |
| desired_text/value | 意図した/実際に保存された文字列 | 非物理データ | 固定2文字列、初期値は空 | 文字列 |
| nonce | 対象試行と操作段階を結ぶ一意識別子 | 非物理識別子 | 固定operation_idとphaseの結合 | 文字列 |
| written | アプリが記録する書込み有無 | 1（無次元） | 0 / 1、真偽値とは区別 | 整数スカラー |
| observed_ns | 同一プロセスのperf_counter_nsによる記録値 | ns（10^-9 s） | 単調時計、性能比較には使わない | 整数スカラー |
| utc | 観測開始・終了とUIログの壁時計 | UTC日時、物理差の評価なし | ホスト時計、同期精度不明 | ISO文字列 |
| semantic_status | 意図・実対象・前後版・実保存値の照合結果 | 非物理識別子 | CONFIRMED / UNKNOWN | 列挙文字列 |
| HTTP status | 当該フォーム要求へのHTTP応答 | 非物理コード | 初回/修復は200を要求 | 整数スカラー |
| SHA-256 | ソース/原出力のバイト識別 | 非物理識別子 | 64桁16進数、真正性証明ではない | 文字列 |

SQLiteの別接続からの読取りは保存可視性を示す。停電耐性や外部アプリの真正な状態を示さない。
UI操作回数14は構築の計画値であり、別方式とのモデル呼出し削減・待ち時間削減を実測していない。
