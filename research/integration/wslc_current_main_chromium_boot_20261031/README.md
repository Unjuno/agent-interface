# Current-main Chromium startup and explicit executable configuration

A prospective three-arm WSLc comparison on main `02508f645ab9000ea2f10a03f8b75d6cad532c71` did not reach form tasks. An initial launcher attempt `ax01` failed before any preflight because the chosen Python lacked `jsonschema`; the compact setup result is reconstructed from the captured error. A separately identified `ay01` used the system Python and completed one persistent-arm schema preflight (10,936 input and 126 output tokens), then failed before any task model call because the default Chromium path `/home/taka/.cache/ms-playwright/chromium-1208/chrome-linux64/chrome` did not exist in the pinned WSLc image. The launcher additionally masked the underlying startup failure as `KeyError('persistent')`; both records are retained. Later arms were not started. These are not a completed comparison or a zero-cost run.

Prior successful WSLc comparison snapshots had locally changed the client to pass `/usr/bin/chromium`; that override was not on main. This change makes `AGENT_INTERFACE_CHROMIUM` an explicit optional executable override. When unset, the existing downstream default remains unchanged; an empty override is rejected. The value is passed as a subprocess argument, without shell interpretation. It controls a research fixture client, not a production browser installer or process discovery mechanism.

An independently identified, no-model `az01` construction smoke used the candidate source with `AGENT_INTERFACE_CHROMIUM=/usr/bin/chromium`, the pinned Chromium WSLc image, isolated Xvfb, no network, one CPU and 1 GiB. The actual client emitted `ready` for Chromium and exited 0; the WSLc listing afterward found no remaining trial container. This verifies startup only: it does not show form submission, task effects, input release, comparative performance or MAP01. Fifteen local fake-client/caller unit tests passed in network-isolated Linux Docker; the configured, unset and empty cases are covered.

`public.zip` contains predeclared conditions, selected raw process output, result and preflight usage, the startup diagnostic, smoke runner and receipt, plus hashes. The preflight protocol remains private and is hash-indexed in the manifest. The main experiment mounted 2,092 exact-byte-hashed source files; each compared to the main Git blob after CRLF normalization, with no other mismatches. The packet does not include the full source or image bytes. `python audit.py` checks packet integrity and the scoped outcomes. Later arms remain unrun; a future comparison needs separately frozen IDs and complete accounting.
