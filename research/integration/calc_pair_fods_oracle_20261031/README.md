# Calc two-cell saved FODS scorer and format check

This is an offline file-format check, not GUI operation, independent control success, or an efficiency comparison. The scorer requires one sheet containing exactly two plain numeric populated cells A1=731 and A2=864; wrong values, extra populated cells, formulas and repeated populated cells fail. Unreadable XML is unknown. Five synthetic tests pass in normal and optimized Python. Existing A10 saved data is correctly not this task.

One fresh no-display headless conversion returned exit 0 but produced no output and reported `Can't open display`; it is a failure. A separate preregistered successor adds isolated Xvfb and produced a FODS file. The scorer found exactly the intended two cells in that LibreOffice-converted file. This tests file serialization of a pre-populated document, not GUI input. Both uniquely identified containers were confirmed absent. Input and runner hashes and raw outputs are retained. Host mount paths are placeholders in public command records.

The scorer has not been qualified against a document generated by the actual two-step graph, nor against every possible spreadsheet structure or adverse input. No live run is implied.
