# Bounded model-directed aim after MAP01 input cancellation

This four-allocation WSLc pilot extends PR #9887. A model-selected attack starts while a second model call is pending; after the test observes the attack key down it overlays the selected patch and requests local cancellation. After verified input release, the test removes its overlay, explicitly reviews the focused game window, rejects the old alias, and obtains a third model decision on the reviewed image. A research-only helper may propose **one** 60 ms horizontal key turn when a fire target is 41–96 pixels off center, vertically within 60 pixels, and the source patch/binding check passes. After the turn—or no turn in control—the caller captures a new image, requests a fourth model decision, revalidates its target and sends at most one new guarded attack. No old action or model result is replayed.

| Run | Aim condition | Cancellation/review | Aim result | Fourth decision and observed continuation | Health delta |
| --- | --- | --- | --- | --- | ---: |
| n01 | no correction | cancelled, reviewed, old alias refused | proposed, not sent | fire point outside center bound; no attack; 0 kills | -3 |
| n02 | one bounded correction | cancelled, reviewed, old alias refused | 60 ms right; game angle 100.20° → 96.68° | fire admitted and released; later first observed kill count 1 | -2 |
| n03 | one bounded correction | cancelled, reviewed, old alias refused | 60 ms right; game angle 100.20° → 96.68° | fire admitted and released; later first observed kill count 1 | -2 |
| n04 | no correction | cancelled, reviewed, old alias refused | no proposal | fresh point already within bound; fire admitted and released; later first observed kill count 1 | -1 |

Each allocation used the same development-selected route and seed 991031, skill 1, pinned image, private Xvfb, one CPU, no container network, main runtime `3d31d2e31074ef322f208751a4c4d02ea1ccf360` and four same-session real `gpt-6.1-sol` low image turns. The host model process has network access. The attack after review used the fourth model's newly validated fire choice and duration; the point determined the check, not direct cursor aim. Game-reported angle, health, enemy labels and kills were evaluator telemetry and were not passed to the model or the aim helper. Each action and owner close recorded verified neutral release.

This shows a bounded post-cancellation continuation with an observed later game score in n02/n03, but the effect of the earlier interrupted attack remains unknown. The game kill count first increased after the new action; it cannot by itself prove which emitted input caused the kill. n04 achieved the same observed kill without correction because its new model point was already within the bound, so this sample does not demonstrate a causal improvement from the turn or damage reduction. All runs still lost health. The fixed duration, ±40/96 pixel bounds and RGB threshold are research choices derived from earlier development observations, not calibrated for arbitrary geometry, enemy identity or animation. Same-seed, fixed-order runs are not independent reliability estimates. Screenshot checks and X11 key emission are not atomic; the prior monitor is test-specific. This is not the v39 threat policy, general autonomous recovery, reliable survival or MAP01 completion.

`aim_policy.py` has four local tests for direction, bounded inputs, unknown values and geometry; they pass under normal and optimized Python. The archives contain scripts, tests, schema, inputs, model call outputs/usage, screenshots, game samples and all receipts. Private model protocol journals remain local with hashes and sizes. `python audit.py` independently reconstructs the source and pre-press image checks, model/image/usage associations, cancel-release-review ordering, old-alias refusal, proposed nudge, observed game angles and post-action kill observations. All four attempted runs are retained.
