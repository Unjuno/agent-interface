# Controlled state-rebase construction under #6259

The model authors the task contract before operation. A local classifier only
evaluates a fresh read-only app snapshot afterward and issues no input. User
FINAL-v5 delegates this ordinary scoped research/design/probe autonomously.
The brainstorming path is a research spike: the result is an answer, with
throwaway source retained as inert evidence rather than a product subsystem.

H: in a purpose-built HTML/SQLite app with untagged acknowledgement, an exact
current state can satisfy two extensional contracts while request origin remains
UNKNOWN. The same displayed value cannot discharge two event-specific contracts,
forbidden collateral, incomplete coverage or an unverified release obligation.

T: one excluded read-only app/UI binding preflight, then frozen separate source,
goals, actor deck, observer, classifier, audit, output and one primary instance.
Eight distinct cases: eligible own effect, eligible external effect, exactly-one
event, duplicate event hidden by equal current value, forbidden notification,
incomplete coverage, hypothetical unverified release obligation, unsatisfied
state. One primary DOM dispatch per case; two explicit serialized actor writes
for the external/duplicate cases. The controller receives only contract and
fresh public projection. A separate fresh-process read-only SQL observer retains
complete snapshots/event counts for the scorer, including data masked from the
controller. No request retry or post-rebase write is allowed. Event-origin truth
is retained by the independent scorer, never supplied to the classifier.

D: construction pass requires correct exact typed binding, all eight first
records/actual requests/UI stages/DB snapshots, protected sibling preservation,
two state-goal satisfactions with origin UNKNOWN, two event-specific refusals,
two unsatisfied/forbidden results and two UNKNOWN results. Raw-only separate
auditor must reconstruct decisions/effects/coverage and detect effective copied
corruptions. Any source/identity/missing evidence/primary infrastructure failure
is retained HOLD/STOP; no primary reset/restart/replacement. Ordinary source and
metadata/auditor repair may proceed with first versions/outcomes preserved;
never rerun primary effects to satisfy an audit. Baselines: naive value equality
and strict global UNKNOWN on the same retained projection. No result promotion
from the prior model or other app run.

C: a genuine bound complete application event receipt could resolve origin
directly, and strict handoff may be sufficient for event-specific tasks. The
selected app deliberately lacks such request binding. Contract eligibility is
authored semantic input, not inferred from pixels. Standard SQLite transactions
and a direct exact-state predicate are the strong simple implementation.

U: controlled server/actor schedule and exposed invented bindings, not a general
GUI. Acknowledgement origin ambiguity is an information boundary of the public
interface, not a claim that the server lost its private logs. SQLite readback
does not establish power-loss durability or a trusted authentic observer. The
unverified-release case is an epistemic seeded obligation; no real held native
input is generated. No model calls, latency/tokens or physical event claims.

application; neither this plan nor a scoped pass supplies main permission.
