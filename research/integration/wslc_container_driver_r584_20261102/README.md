# WSLc container driver smoke: R584

A fresh isolated no-GUI/no-input container was started through the experimental ContainerDriver. A deliberately nonzero exit 7 was observed independently from cleanup, and the two-stage helper observed stopped state, removed the same identity-verified full CID without force, then observed an empty exact-ID list. `task_status` stays UNKNOWN. Conditions, exact source bytes and redacted observations are retained. Raw private journals and identity records contain paths, environment and command data and remain local; their hashes here do not make them independently accessible.

This is one normal-exit sample. It does not prove Calc task execution, input release, fault recovery, parent-death custody, all-process retirement, a total hard deadline, general reliability, MAP01 or efficiency. Failure before full CID acquisition remains unresolved. Model-host custody and an independent scorer are not integrated.
Independent review matched saved source hashes and all identity checks, observed running to exited/7, and confirmed the already-stopped path did not issue a stop command. The non-force remove followed exit evidence, and the final list was empty. Host elapsed time was 5.390 s. Cleanup journals lack per-command timestamps, so individual cleanup durations and the `returned_late` fields cannot be independently reconstructed from those journals. Source hashes bind the retained copies, not the entire host environment.
