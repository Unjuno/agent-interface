# Valid-generation Win32 public-MCP post-admission recheck R05

This is a one-shot native Windows compatibility trial on the user-authorized PC. It uses the actual public stdio-MCP observe/validate/dispatch sequence against one fresh fixture process owned by the probe. The frozen task writes a fixed sentinel to the fixture's local effect file. The independent auditor also requires a single public dispatch, a verified empty release receipt, exact character/save journal, and clean fixture shutdown.

The source is the exact main commit in `conditions.json`, containing the backend's per-operation target-generation checks. `probe.py`, `audit.py`, `conditions.json`, `.gitattributes`, and this protocol were frozen before the one-shot execution. The probe refuses an existing raw/attempt directory, checks the sentinel/operation agreement, uses no fallback or retry, preserves the public MCP reports and fixture logs, and cleans up only its owned fixture.

R05 checks positive-path compatibility under stable target identity after the implementation change. It does not test an adversarial native HWND replacement between focus and input, prove each internal generation read occurred, provide atomic OS fencing, establish bounded release under blocked I/O, or qualify recovery, MAP01, efficiency, or broad reliability. No WSLc or Docker allocation is used.
