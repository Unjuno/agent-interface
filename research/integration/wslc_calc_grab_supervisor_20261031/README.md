# WSLc Calc: supervised experimental X server grab

Two fresh WSLc allocations used LibreOffice Calc on private Xvfb, a known blank FODS, fixed reviewed A2 point [81,168], main-equivalent runtime 370819ef4d08ee0cfa5727e790e1798186b824d0, pinned image, one CPU, 1 GiB, no network and a 45-second outer timeout. A research-specific worker directly used XTEST and XGrabServer, after recording PID, session, X resource base and intended held button. Existing prestarted cancellation-supervisor instances watched that worker and provided the cleanup worker. This does not use the public guarded dispatch admission path and is not production integration. No model call was made.

- A01 normal: the worker's target hit chain included the Calc window, it sent a button pair during the server grab, returned a matched completed receipt and retired. The parent observed neutral buttons and a changed Calc name-box image. The initial A1 name-box matched the reviewed digest; after the action the image visually showed A2.
- A02 stall: the worker sent button down, then stalled while holding the server. At the 800 ms deadline the supervisor retired it with UNKNOWN / transaction_deadline. The button was observed down before cleanup. The prestarted X11 cleanup worker observed the owner disconnected and returned readback_verified for release, while preserving overall cleanup_status UNKNOWN and release_confirmed false. The parent observed neutral buttons after cleanup and no late artifact after the worker's scheduled late-action time plus 300 ms. The Calc name-box image also showed A2: a timed-out operation had visible effect and must not be treated as having done nothing.

Both initial OCR outputs were `Jaz`, not a success. After inspecting the images, a separate post-hoc crop and constrained OCR run returned `A2` for both; this adjustment and raw original outputs are retained, and is not an independently preregistered classifier. An aggregate audit checks image hashes, OCR input association, owner retirement, release readback, delayed observation and unchanged saved document hash. Frozen input and 305 runtime hashes matched, all containers were absent and ZIP integrity passed. The successful and stalled paths are one observation each. The test does not establish product-level release confirmation, absence of all late events, crash durability, general target safety, handling of hung X servers, model behavior, or MAP01 completion. Global server grabs block other clients; use requires independently bounded custody and explicit recovery.
