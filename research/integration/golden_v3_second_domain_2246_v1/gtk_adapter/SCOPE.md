# GTK second-domain adapter/scorer scope

This additive, model-free layer validates already-recorded GTK/X11 session and effect receipts. It does not drive GTK, send X11 input, create authority, call a provider/model, or infer success from process completion.

The eight preregistered cases remain ordered and distinct: useful effect; unavailable before input; guarded refusal; accepted input with no effect; partial/collateral effect; stale binding followed by bounded repair; ambiguous delivery with no replay; terminal cleanup failure.

A ready result is contract admission only. It is not live backend evidence, task success, provider evidence, or the full #2492 acceptance result.
