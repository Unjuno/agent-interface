# Reviewed modal guard: bounded Calc integration

`research/live_control/reviewed_modal_guard_v1.py` extracts the capture-bound check used by the prior fixed-layout modal recovery. The caller supplies an already reviewed RGB reference, explicit in-frame regions, a title, a bridge and a deadline. Arming requires the exact current retained capture, matching target/binding/focus/title, reviewed pixels and freshness. Each subsequent guard capture must be newer, still be the bridge's current exact retained capture, retain the same scope and binding, satisfy the deadline/freshness checks, and match the reviewed regions. Invalid or uncertain captures return false. The reference pixels are frozen when the guard is constructed; it cannot be rearmed.

The guard does not locate or review a dialog, mint an alias, issue input, prove content outside its regions, or verify a saved effect. The caller must choose suitable regions and establish the provenance of the reference. A match in those regions is not a general UI identity proof.

Two preregistered private-WSLc Calc runs exercised the exact new module. In f13 a controlled overlay changed the dialog preview after OK-target mint: the guard rejected the click before dispatch, no Save occurred, the saved file remained blank, and release was neutral. In f14 the unmodified reviewed dialog passed four guarded captures, one separately owned click completed, fresh Tesseract read 641/283, and a separately guarded Save produced an independently verified FODS containing exactly those values. The original compiled paste graph remained `SAFE_YIELD` with entry pending in both cases; the paste was not replayed. Recovery used distinct owners and verified neutral release. No model was called.

Run `python -m unittest research.live_control.test_reviewed_modal_guard_v1` and the same under `python -O` for eight unit tests, including mismatches, freshness, reference immutability and strict boolean/integer handling. In addition, 55 local graph/bridge tests passed in each mode. Run `python research/integration/wslc_reviewed_modal_guard_20261031/audit.py` with Pillow to verify the frozen candidate bytes, screenshot regions at recorded guard captures, deliberate race, action/release records, OCR crops and transcripts, independent saved FODS and cleanup. The artifact retains the fixed reference and raw records; source/image bytes and external dependencies are not fully reproduced.

These are one fixed-order pair on a known fixed-geometry dialog. The overlay is controlled by the test process; unrelated visual regions, other dialogs, external concurrency, timeout behavior in an actual stalled system, and general production reliability remain unverified. The dialog guard is reusable code, while target discovery, reference review, clipboard handling and recovery orchestration remain experimental. Issue 57 remains open.
