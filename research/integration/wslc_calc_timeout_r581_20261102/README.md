# WSLc Calc deadline stop: R581

A fresh isolated Calc window was captured before the payload's deliberate delay. The host observation deadline expired; the helper's stop command succeeded against the verified CID, then its exited-mode observed code 137, removed that CID without force, and found an empty ID-filtered list. The stop-mode status remained UNKNOWN because this was a non-auto-removed container and its immediate post-stop list was not empty. This is one timeout intervention, not normal task success. Conditions, source, helper copy, screenshot and redacted observations are included; raw outputs and journals are private locally and identified by hashes, so they are not independently accessible here.

The 6-second deadline is an observation-loop budget after launch, not a total wall-time guarantee. Journal sync, command execution, image copy and cleanup add time, and synchronous calls can block. The wrapper lacks independent custody on parent death, CID-acquisition failure or external state changes. It does not prove input release, no delayed input, process-tree retirement, bounded recovery in general, GUI task effect, benchmark performance, or MAP01 behavior. The source is an experimental wrapper rather than a reusable production driver.

Independent review matched all 22 running inspect responses to the same CID and label, both journals to their receipts, and the ready screenshot to its hash. Exit code 137 is an observed value consistent with this stop; it does not by itself identify the cause of termination or the order in which child processes exited.

The retained payload has a separate defect: after marking a window observed, an internal alarm can add an error while leaving the status unchanged, allowing exit 0 in that different ordering. After-stop copy exit codes are not enforced by the wrapper, though both were independently checked as zero here. If the stop helper itself raises, the shared exception handler skips removal. Fix these before reusing the wrapper; none of those untested paths is established by this sample.
