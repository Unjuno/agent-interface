# WSLc MAP01: shadow-only template ambiguity check

This exploratory experiment adds a shadow matcher to the bounded model re-grounding candidate. Only when a centered target's patch freshness check fails, it exhaustively compares a 16x16 RGB template at 4,941 positions (±80 horizontal, ±60 vertical, step 2). A provisional rule would accept only best difference ≤8 and a spatially distinct runner-up gap ≥5. **The shadow result never authorizes input**: the existing model re-grounding and gates remain in control. The rule and threshold are exploratory, informed by the earlier post-hoc replay, and not production policy.

- dw01/dw02: the fourth-call gate passed, so no shadow match was run. Both guarded recovery shots completed with separately verified neutral release; each bracketing simulator interval recorded ammo 49→48, hits 1→2, damage 15→30 and kills 0→1. The counters alone do not prove attribution of the kill to the individual input.
- dx01: a preregistered artificial gray overlay forced a target-patch mismatch. The shadow scan took 198.219 ms, best difference was 10.922, distinct runner-up 11.391, and gap 0.469; the provisional rule held. The overlay was removed before the fifth model call. That call took 1.922 s; its new target also failed the unmodified freshness gate, so no recovery shot was issued.
- dx02: the fourth model target was outside the center gate; the overlay and shadow scan were not run and no recovery shot was issued.

All terminal input releases were verified. Two of four cases do not exercise the matcher, the third is a synthetic intervention and the fourth fails another gate. The scan is extra work before the still-required model call, so these results do not establish a speedup, target identity, a general false-accept rate, semantic safety, or MAP01 completion. The candidate snapshot is not asserted identical to main.
