# WSLc MAP01 cancel, review and attack (2026-10-31)

This one-allocation controlled game experiment asks whether a held input can be cancelled and released, its old reference rejected after review, and a fresh guarded action produce a distinguishable game response. It uses Freedoom2 MAP01, skill 1, seed 991031, fixed navigation, no model and no learned or pixel-tracking action selection. Conditions were recorded before each attempt. Networking was disabled, one CPU and 1 GiB were assigned, and the runner used a 30 s watchdog.

`ab01` stopped because the key hold was not observed. Its owner close reported verified empty release. The cancellation worker outcome was not retained, so its dispatch and exact error are unknown. Its runner did not request the query worker required by `cancellation_scope`; the source configuration and absent retained worker outcome limit that diagnosis. It did not reach review or attack.

`ab02` enabled process identity and the query worker. The X keymap observed A down; after cancellation, the operation reported execution failure, a verified empty release, and an unknown partial effect. A fresh review advanced the binding revision; the old alias was refused before dispatch. A new guarded 1,000 ms F action completed with verified release. The simulator's kill counter changed 0 to 1 across that attack; same-state engine labels identify object 14 as `Zombieman` before and `DeadZombieman` after. Final owner close and keymap reported empty tested keys. The cancellation request-to-reported-release interval is available in `audit.py` output for this one run, not a latency distribution.

The attack was scripted and not selected by a model or tracking candidate. Engine labels and kill counter share the simulator and are not an independent physical oracle. The initial cancelled turn may have had a partial effect; release does not establish its absence. This is one successful finite trajectory, not evidence of general reliability, V39 planner-fence retry, model integration, efficiency, or MAP01 completion. Prior `#9928` live model runs did not admit their proposed attacks; this scripted probe does not overturn that result.

`ab01.zip` and `ab02.zip` retain the original conditions, runners, logs, action and owner records, game samples and available frames. Run `python audit.py` to verify source hashes, ordering, results and frame hashes; no image processing packages are required.
