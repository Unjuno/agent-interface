# Issue #3311 broker-instructions forwarding — review follow-up v2

## H/T/D/C/U

**H — hypothesis.** Because the request crosses a writable shared IPC boundary, forwarding an instruction path verbatim can expose arbitrary host files to the host CLI. The broker should only accept a path resolving beneath the declared repository, verify the request's SHA-256, and pass a private copy of the verified bytes. Requests that omit instructions must remain compatible with the existing schema bridge.
