# Strict scheduler count at the measurement consumer

The MAP01 measurement integration auditor accepted JSON `false` and `0.0` as zero missed periods because Python numeric equality aliases them with integer zero. Truthy non-object scheduler values could instead raise `AttributeError`. This repair changes only the existing auditor and its existing test file: scheduler must be an object and its missed-period count must be exactly integer zero. Wrong or missing values append the existing failure message and produce an audit FAIL.
