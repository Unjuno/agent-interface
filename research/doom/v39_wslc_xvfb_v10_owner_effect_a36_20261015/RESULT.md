# A36 result — synthetic app effect and bounded expiry

**Outcome: PASS for the preregistered synthetic X11 scope (22/22 independent audit checks).** A single frozen WSLc allocation, `MAP01-V39-WSLC-V10-APP-EFFECT-A36-20261015-01`, delivered one admitted `a` key to an independently running app. Its counter changed `0→1` within 151,392 ns (the frozen bound was 200 ms), remained 1 after release, and the app recorded exactly one matching key-up. V10 expiry release was verified with `keys_down=[]`, `buttons_down=[]`, `keys_unknown=[]`, and `key_state_errors=[]`; an independent X11 connection observed the server key-up. Expiry recovery overshot the 300 ms lease by 592,311 ns, within the 1 s bound. Both the merged #8771 known-empty cleanup predicate and V39 terminal predicate accepted the record, and each rejected mutations with either known-empty field removed. App, owner, and Xvfb exited cleanly.

The full audit, raw record, app JSONL/stdout/stderr, WSLc stdout/stderr, and exact invocation timestamps/arguments are retained in [`output/`](output/). SHA-256 values are in [`output/SHA256SUMS.txt`](output/SHA256SUMS.txt). `INPUT/FREEZE.json` binds the production source and experiment artifacts. Local candidate event-log regression tests passed 2/2 in normal Python and 2/2 under `python -O` before dispatch; WSLc also verified all frozen input hashes before candidate/audit execution.

**Problem boundaries found:** WSLc reported that this kernel cannot enforce swap limits, so the requested 1 GiB memory setting is not proof of a hard memory-plus-swap ceiling. The run uses one synthetic X11 app and one short interval; it does not establish Doom/MAP01 state transitions, model-selected behavior, Windows desktop integration, physical keyboard state, or comparative efficiency. The app emits an Xlib xauth warning, although it exits successfully and the independent audit passes. A35's earlier predispatch STOP remains intact and was not retried; A36 fixes its unretained stdout-readiness diagnostic by using a file-backed event stream and preserving both stdio streams.

This is a bounded integration result, not completion of computer control. The next high-value experiment is to connect the same receipt/effect/release checks to a real MAP01 environment and compare against a matched baseline, after checking that the corresponding live allocation is fresh and unconsumed. Do not repeat A36.
