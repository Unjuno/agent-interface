# Same-directory scorer/event bundle validation A01

This additive wrapper checks that a single runtime directory has the exact pinned MAP01 v15 `sources.json` inventory, a compatible `scorer-summary.json` with `controller_visible: false`, and a sample count matching the co-located `scorer-samples.jsonl`. It then calls the existing admission-bracket classifier on `events.jsonl` and `scorer-samples.jsonl` from that same directory.

The source policy was copied from `research/doom/absolute_pair_59_4d74_20261004/00-coast/runtime/sources.json` at main commit `31ce02c0a148aed9650b58ef31a8746d5e85e091`. Its exact input SHA256 is `8bda4ff1f769b47357107b264523e887fcf88133d89ff929a952db1cdee3edc5`, and the Git blob is `2439ba8ec7255082483b620fd4f35cfef92f596e`. The bundle event and scorer files are synthetic fixtures; they are not from that retained runtime episode.

The seven deterministic cases include a valid join and failures for changed or unexpected source entries, a modified frozen policy, sample-count mismatch, wrong summary schema, controller-visible summary, missing metadata, and malformed scorer rows. `RAW.json` records candidate outputs; `audit.py` independently checks the frozen cases and metadata pins. `AUDIT.json` is regenerated by the auditor.

```sh
python research/doom/scorer_eventlog_join_t0_v1/runtime_bundle_a01_20261005/run.py
python research/doom/scorer_eventlog_join_t0_v1/runtime_bundle_a01_20261005/audit.py
python -m unittest research.doom.scorer_eventlog_join_t0_v1.runtime_bundle_a01_20261005.test_candidate -v
```

This is local deterministic construction only. It does not authenticate episode authorship or prevent deliberate cross-file copying; a directory can contain files assembled from different origins. It does not validate the full scorer/event source content beyond the retained source manifest and summary count. It establishes no live episode behavior, timing under load, effect time, causality, recovery, or MAP01 completion. No game, model, GUI, input, GPU, container, or formal allocation was used.
