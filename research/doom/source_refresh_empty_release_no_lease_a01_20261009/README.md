# Passive source-refresh release receipt repair A01

This package isolates the A17 `source-refresh-2-0` failure: the program submitted one `observe` step, was accepted with a lease token, admitted no input, produced a newer typed health/ammo pair, and ended with a verified-empty owner release whose token was null. The runtime rejected that receipt as `refresh_release_unqualified` because it required every release to repeat the accepted token.

The repair permits a missing release token only for that exact passive observe-only command and only when the terminal release reports `verified: true`, empty `keys_down`, `buttons_down`, and `keys_unknown`, and empty `key_state_errors`. Token-bearing releases must still match the accepted token. Terminal completion and fresh observation checks remain in force; missing or malformed state fails closed.

`CASE.json` is a compact trace slice from the consumed A17 allocation, not a replacement raw log. Its provenance pins current main `6ceb8552df13a188f6aad9cbfed88eba6eb70689` and the retained event/refresh raw SHA-256 values. Protocol tokens are replaced by stable opaque labels and X11 focus/surface identifiers by small integers; equality and inequality relationships used by the audit are preserved. Literal private identifiers remain only in the private raw evidence and are not required to interpret the public trace slice. A local raw-to-case cross-check matched both raw hashes and the selected command, typed observations, prior cancel/release/terminal identity and token chain, and event ordering before pseudonymization. `audit_case.py` is an independent trace-slice oracle; its tests mutate input admission, prior lease release event/reason/errors, admission/cancel/release/terminal identity and token linkage, cancellation/release/terminal ordering, command type, passive release state, token identity, and public pseudonymization. A PASS establishes only this trace-slice contract and does not establish physical key state or game success.

Validation uses the bundled Python runtime: source-refresh tests (16), V39 overlap-controller tests (16), and independent trace-slice audit tests (14) pass in normal and optimized Python. The audit rejects boolean and floating-point values where exact integer counts are required. No live game/model run was performed for this repair. A17 remains consumed; do not retry it. No new live allocation is implied.
