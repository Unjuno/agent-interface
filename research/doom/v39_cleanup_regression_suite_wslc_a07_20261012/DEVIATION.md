# Execution deviation

WSLc was the preferred isolated runtime. The first invocation needed an image pull; after the cached `python:latest` image became available, the WSLc run ended with exit code 2 before test output, and the follow-up mount diagnostic reported `/runner/check_mounts.py` missing. The D: bind-mounted runner path was not visible inside the container. The WSLc attempt is retained as a pre-test infrastructure/setup stop; no WSLc PASS is claimed.

The exact frozen test/source inputs were then run natively in Ubuntu WSL. This fallback kept the same test module and source blobs, and its runner verifies the imported source path and SHA-256 before executing tests. WSL-native cgroups reported `cpu.max=max 100000` and `memory.max=max`; no CPU or memory limits are claimed. WSLc emitted a warning that the kernel did not support swap limits or the cgroup was not mounted.

Earlier harness diagnostics are retained. The first correct-source comparison attempt put the candidate directory (containing the candidate module) ahead of the selected main source. A direct receipt probe then demonstrated that frozen main certifies the duplicate inputs, revealing the source-shadowing problem. The final runner moved tests into a separate directory and asserts the imported module path for every comparison. Its summary classifier itself retained trailing spaces and duplicate subtest failures; `audit.py` independently parsed each preserved raw unittest transcript and recorded the corrected scoped classification while preserving the runner's original `FAIL_SCOPED` summary.
