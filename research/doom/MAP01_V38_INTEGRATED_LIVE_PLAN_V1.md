# Frozen v38 integrated MAP01 threat exposure

The prior v32 live allocation proved controller final-admission precedence but
admitted only one of six model plans. Decision4 specifically lost an eligible
answer because its cover-policy source lease expired before input. Schema v6
then passed a separately frozen no-image endpoint compatibility request. The
v38 implementation already composes the new schema, immediate health/ammo
action validity, continuous typed running-action validity, exact compiled
program/lease binding, and two-phase physical release. Its construction tests
pass on Windows and WSL, but v38 has never run a model-authored action in a
live game.

This allocation keeps the v32 enemy-visible fixture, Luna-low, six-decision
limit, continuously advancing MAP01 and zero retries. It starts from the
fixture's setup-only save, uses the actual X11 Executor for all runtime
input, and scores map exit/death/kill independently. It grants no authority
from model text, source screenshots, typed provisional signals or effect
receipts. Twenty-eight source/fixture hashes, the command, output-absence
condition, stop rule and audit source are frozen before any v38 model call.

The audit must reconcile every decision's planner terminal and final
admission, show no dependent plan input for rejected outcomes, match each
accepted program to an empty-release terminal, bind every active running
program to exact submitted steps/program SHA and lease token, reconcile early
typed health/ammo to the later exact frame, and compare the report score to
the raw independent scorer. An active invalidation additionally needs an
identifier-bound early physical release and later terminal; absence of a
natural invalidation is recorded as unexposed rather than success.

This is a gate for the integrated architecture, not a hero-clear benchmark.
`INTEGRATED_PATH_EXPOSED_RETAIN_LIMITED` requires at least one actual
model-authored active answer to pass fresh immediate validity and obtain a
primary program plus running-guard receipt with all mechanics audited. If no
action gets that far, the first run is held as unexposed; setup/runtime
failure remains retained incomplete. Liveness, actual token and model wait,
local feedback and independent gameplay are reported separately. One
nondeterministic same-fixture episode cannot establish causal improvement
over v32 or human-tempo control.
