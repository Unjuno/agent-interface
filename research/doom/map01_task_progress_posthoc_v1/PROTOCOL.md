# MAP01 task-relative progress posthoc protocol

This is a **retrospective diagnostic**, not a prospectively preregistered formal efficacy result. The exploratory computation existed locally before Issue #630 was created.

## H/T/T/S

- **H — Hypothesis:** the retained repeated-no-progress deopt can increase spatial coverage without increasing task-relative progress toward the actual MAP01 exit; coverage alone is therefore not sufficient for promotion as task progress.
- **T — Test:** bind the exact two retained evidence archives and exact Freedoom2 WAD by SHA-256; independently parse the unique MAP01 special-11 exit linedef; for every retained pose trajectory recompute coverage64, minimum point-to-exit-segment distance, step of minimum, and final exit distance; pair baseline/candidate by seed.
- **T — Termination:** exactly one deterministic retained-trace computation and an independent reconstruction audit. No new game/model/input allocation, no threshold tuning, no alteration of the source formal decisions.
- **S — Success criterion:** descriptive classification `COVERAGE_NOT_TASK_PROGRESS_SCOPED` if both retained blocks have positive paired median coverage delta while paired median minimum-exit improvement is non-positive and all source/hash/exit-line checks pass.

The classification does not say Euclidean exit distance is a complete task-progress metric; it says the already-reported coverage uplift is not, by itself, evidence of exit progress in these retained episodes.
