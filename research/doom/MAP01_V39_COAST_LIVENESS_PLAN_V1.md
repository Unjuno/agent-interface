# Frozen v39 unauthored-coast liveness allocation

The retained v38 first outcome exposed a precise runtime loop. Decision1's
active answer failed fresh action validity, so the next `reusable_cover()`
result was empty and unauthored. The v38 default monitor set tolerated health
loss to zero even though empty coast held no authored control policy. Damage
then invalidated the empty cover and interrupted decisions2–5 before their
answers could be considered. The v39 construction change suppresses only
policy invalidation for unauthored empty coast. It preserves exact observation,
fresh immediate action validity, and the existing authored-cover monitor.

This allocation uses the same enemy-visible fixture, seed990619, Luna-low,
six decision turns and continuously advancing game, with zero retries. It
freezes v39 source, audit, command and stop rule before model use. The audit
requires v38 mechanics plus correct monitor mode per decision: empty
unauthored coast must have no policy invalidation/interrupt, while authored
cover retains its guard. It separately reports whether a coast decision
completed despite a health decrease during its model wait. A run lacking
that natural condition is retained as unexposed, not claimed as a liveness
success. Plan admissions, renewal, no-input after rejection, typed/exact
reconciliation, physical release and score remain measured.

The v38/v39 episodes are not a causal paired trial; gameplay and model
answers may differ. This result can expose a repaired control boundary and
suggest further tests, but one MAP01 run cannot establish reliable human-tempo
operation or cross-domain performance.
