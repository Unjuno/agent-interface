# MAP01 running action controller v35

V35 composes immediate admission and continuous execution under one current
authority receipt. `final_action_admission` remains in each decision as the
historical transition through planner eligibility, action validity and the first
Executor acceptance. Once a running guard exists, consumers use only the root
`running_action_guard.current_input_authority`, `physical_input_may_be_down` and
`physical_release_verified` fields for current state.

Every primary or fallback program binds five layers: the exact validated planner
action, the semantic command slice, a fresh deterministic recompilation, the
submitted Executor step list and the matching Executor v10 program SHA-256
attestation. Matching ID and step count alone are insufficient. Primary
slices must be contiguous and non-overlapping. A fallback must also match the
authored contingency and the most recently completed primary program, including
program ID, command index, semantic command, completed terminal and the retained
full `no_visible_effect` receipt. A caller-created branch label alone is
insufficient.

The deterministic composition replay covers five paths and seven program
bindings: one primary bundle, two primary segments, a completed-primary fallback,
active invalidation with cancel/release, and inter-segment invalidation before a
second program. All five close with current input authority false and verified
empty physical release. Windows and WSL produce byte-identical audit JSON with
SHA-256 `ff8828924ffd97c0d48ea8fe0c20dd3dfd05aa901c38e2f76b8f7e1bf3cf56fb`.

MAP01 session v9 introduces that acceptance digest while preserving the
hash-bound session v7/v8 and Executor v3/v4 sources used by earlier allocations.

This is model-free composition evidence. V35 has not called an endpoint, run a
planner-authored schema-v6 action or demonstrated task progress, game completion,
latency improvement or human-tempo control. The effect classifier remains a
viewport-pixel heuristic; v35 proves that the exact retained receipt gates the
fallback, not that the heuristic has the right semantics. Preserve v34 and the
two frozen live-probe source hashes.
