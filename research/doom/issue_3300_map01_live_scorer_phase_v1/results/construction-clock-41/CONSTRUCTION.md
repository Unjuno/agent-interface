## H / T / D / C / U

- **T:** Three fresh hidden MAP01 `ASYNC_SPECTATOR` sessions at 35 Hz on the official ViZDoom 1.3.0 source tag, with a construction-only timestamp patch and official Freedoom 0.13.0 WAD. Each session had 1.5 s passive polling, the exact current-main `_coherent_progress_sample` once, no action/advancement API calls, a 150 ms post-scorer window and normal cleanup. Docker runtime was linux/arm64, `--network none --read-only`, tmpfs `/tmp`, read-only code/WAD mounts and one writable result mount. The patched engine wrote fixed-size binary `{pid, CLOCK_MONOTONIC_ns, gametic, vizTime}` records after sampling the clock.
- **D:** In all three rows setup, scorer and cleanup completed; passive API tic was static within each row (1→1, 1→1, 2→2). The engine trace held 64/65/66 entries with contiguous `vizTime`. A corrected independent audit placed all 24 scorer getter starts between successive samples; median entry intervals were 28.315/28.573/28.679 ms. Getter-start phase fractions within the adjacent sample interval were 0.023–0.033, 0.686–0.698 and 0.227–0.231 by repetition. Getter call spans ranged 1.835–25.178 µs, 2.209–40.393 µs and 1.835–15.424 µs. The first auditor incorrectly selected the earliest prior sample; its `FAIL_AUDIT` output is preserved at `audit.json`, and the corrected v2 audit is separately retained.
