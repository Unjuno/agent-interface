## Frozen adjudication rule

The vector components are paired differences (recovery minus coast). Positive progress is favorable; negative unsafe exposure is favorable. `PASS_DIRECTIONAL` requires all three progress signs nonnegative with at least one positive, and all three exposure signs nonpositive with at least one negative. `FAIL_DIRECTIONAL` is assigned if any progress sign is negative or any exposure sign is positive. All other patterns are `UNCERTAIN`. This intentionally treats any observed pairwise regression in either dimension as a bounded directional failure; it does not imply population-level significance.

Identity validation order is global and fixed: inspect required fields in the listed order for presence across all session identities; then inspect syntax for every session/field in stable session and field order; only after every value is syntactically valid compare identities for equality in field order. Hashes are exactly 64 lowercase hexadecimal characters.
