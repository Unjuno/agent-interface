# Issue #1998 A04 — Pillow PNG focused-payload economics

This successor measures canonical JSON/base64 bytes for exact crops of retained GUI screenshot frames, encoded through the exact main-branch `ImageArtifactSink` implementation at Pillow compression level 6. It covers 21 unique frames from Calc, Chromium, Inkscape, and xterm plus 441 fixed crop requests, including a full-bounds focus control for each frame.

The experiment is finite and offline. It tests payload size only; it does not establish that an ROI contains enough visual context, that a model can use the crop, that tokens or latency fall, or that GUI/task success changes. Formal disposition and the immutable first outcome are in `REPORT.md` after execution.
