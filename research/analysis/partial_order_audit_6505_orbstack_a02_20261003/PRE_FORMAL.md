# A02 pre-formal checklist

Before formal start: confirm latest main is merged and unchanged; verify issue remains open and exact branch has no competing PR; verify all frozen input/source/workflow hashes; run construction tests and analysis-index checks; confirm the designated output directory exists and is empty; save Docker config and inspect outside that directory; confirm OrbStack context, image digest/platform, and shared-container inventory. One invocation maximum. Any failed check is recorded as STOP; do not start or retry.
