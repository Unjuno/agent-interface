# Issue #6533 T0 — frame-qualified collateral checking

This package tests one finite, synthetic structured-document hypothesis: whether a source-generation-bound, writer-closed frame certificate can preserve full-state collateral verdicts while reducing checker-level work on disjoint state. It is not a GUI experiment or a claim about arbitrary applications.

- Read the frozen gates in [`PREREG.md`](PREREG.md) and exact configuration in [`FREEZE.json`](FREEZE.json).
- `scenarios.json` is generated by `build_scenarios.py` and committed before the formal run.
- `candidate.py` compares target-only, full-state, static direct-footprint, and qualified-frame policies.
- `auditor.py` is separately implemented and reconstructs all outcomes, qualification gates, read/cost counts, and the predeclared disjoint cost comparison from raw cases.
- `test_formal.py` is a construction/regression suite; it does not itself constitute the one-shot formal allocation.
- [`CONSTRUCTION.md`](CONSTRUCTION.md) retains pre-freeze harness corrections separately from formal evidence.
- `run_formal.sh` is fail-closed on an existing results path and runs exactly one candidate and one auditor in separate isolated OrbStack containers.

Reproduce the formal invocation only for a newly authorized allocation: `bash run_formal.sh`. Never delete or overwrite an existing `results/allocation-01/` directory or rerun the same allocation after any outcome.
