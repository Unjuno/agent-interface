# Decision-value observation acquisition — Issue #7934 T0 A01

This package compares cost-only, entropy-threshold and one-step downstream
decision-value check selection on a deterministic six-case finite model.
`HYPOTHESIS.md` defines H/T/D/C/U; `PROTOCOL.md` defines the frozen execution
and separation boundaries; `FREEZE.json` binds all exact inputs and code.

After formal execution, `REPORT.md` records the first outcome and limitations.
Reproduction commands and expected output identities are in `PROTOCOL.md`.
The result is synthetic method evidence only, not calibrated GUI beliefs,
runtime latency, or user benefit.
