# Chromium temporal focused-payload experiment — T0 A10

Prospective one-shot test of whether a fixed text-field crop can preserve the pixel sequence across an archived input/submit/effect trace with lower serialized payload bytes than full screenshots. See [PLAN.md](PLAN.md) and [FREEZE.json](FREEZE.json) for the frozen claim and source identities.

The test reuses only immutable source screenshots and ledgers. It does not repeat A09 OCR, run a GUI, replay a task, or alter runtime code. A positive result is a finite one-trace payload result, not evidence of semantic completion detection, control safety, latency benefit, or product success.
