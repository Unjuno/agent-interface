# A01 protocol

## H/T/D/C/U

- **H:** Dependency-aware operation contracts can preserve useful read-only outcomes under independent and common-cause failures, where binary all-or-nothing gating loses them, without overstating semantic/effect evidence or authority.
- **T:** Evaluate a frozen finite nine-scenario dependency/evidence graph. Compare binary full-route gating, an evidence/dependency contract, and an intentionally unsafe silent raw-to-semantic substitution. An independent auditor reconstructs every case from the frozen specification and checks six semantic mutations.
- **D:** Pass only if there is at least one additional supported outcome beyond binary gating; all three unsafe substitutions are detected; no authority inflation or false effect claims; and release obligations remain in all nine cases. Expected development check: 11 additional outcomes, 3 unsafe-control detections, zero authority/claim violations, 9/9 release obligations, zero dispatches.
- **C:** Nine named deterministic cases, four read-only operation contracts, explicit dependency graph, evidence freshness/integrity booleans, binary baseline, unsafe control, independent auditor, six mutations. No GUI, model, participant, real action, or external effects.
- **U:** One frozen candidate invocation and one independent auditor invocation, each from a fresh host Python process; candidate JSON via captured stdout and auditor stdin, results retained in memory and then recorded in GitHub. No output files or temporary files. Host-only CPython 3.12.10 on Windows 11 AMD64 because the shared WSLc lane is on explicit ownership HOLD in Issue #7924. No Docker/WSLc calls are authorized by this experiment.

This is a finite method-level simulation, not evidence of product reliability, human benefit, latency, safety in deployment, or resource limits. A formal failure is retained as-is; do not rerun or replace it in this attempt.
