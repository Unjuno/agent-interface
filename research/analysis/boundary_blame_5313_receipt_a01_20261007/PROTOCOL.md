# Issue #5313 A01: replay boundary-blame decisions against retained receipts

## H / T / D / C / U

This is a successor validation rung for the Issue's proposal to replay real receipt schemas. It does not satisfy the original synthetic single/paired fault-oracle, wrong-repair, repeat-failure, or authority-outcome comparison; a PASS here is deliberately package-scoped, not an Issue-wide result.

- **H:** Real saved process receipts can localize an observed diagnostic-read mechanism to the app-server client while still abstaining from assigning fault when the applicable timeout contract is not explicit. Healthy and fully closed transport controls should not receive fault blame; retained-stderr cases without the internal deadline observation must not be upgraded to a timeout-breach claim.
- **T:** Read eight exact saved cases from current-main `research/live_control/appserver_closed_diagnostic_59_20261003_01a0ff52`: request/notification × healthy, closed-both, retained-stderr (six original cells), plus the two retained-stderr local-deadline supplements. Candidate derives decisions from their real JSON receipts, stdout/stderr, child events, journal and hash-bound source. Independent auditor reopens those original bytes and reconstructs all classifications. Neither old native runner nor old saved auditor is run.
- **D:** `PASS_BOUNDARY_BLAME_REAL_RECEIPT_SCOPED` only if (a) all eight input sets match their retained file hashes and source identity; (b) both healthy and both closed-both controls remain `blame=NONE`; (c) the two uninstrumented retained-stderr cases identify only a blocked diagnostic-read mechanism and remain `UNLOCALIZED`; (d) both deadline supplements identify the app-server diagnostic-read mechanism after the sampled deadline but still remain `UNLOCALIZED` absent an explicit contract covering diagnostic collection; (e) no model/backend blame or automatic retry is emitted; and (f) the independent raw-only audit rejects every frozen output/input mutation. Any unsupported blame, missing case, hash mismatch, or audit disagreement is FAIL/HOLD.
- **C:** Standard-library-only saved-data analysis on a sparse checkout at current main `dd37f2ddbdb0a424e43676545595f5537e435473`. OrbStack context is `orbstack`; `docker info` succeeds as 29.4.0 linux/aarch64, but read-only `docker image inspect python:3.12-slim` fails on a containerd blob with `operation not supported`. No repair/restart/prune/pull/build. Native macOS is therefore used for this receipt-only analysis, with no container-isolation claim.
- **U:** The records originate in a prior controlled synthetic-child native construction, not a real app-server/model/GUI. Same-author candidate and auditor are not independent human adjudicators. This tests one saved receipt family and diagnostic attribution only; it does not measure repair success, wrong-repair reduction, latency benefit, production fault rates, accountability, safety, or task effect.

The key distinction is mechanism localization versus blame: the source frame and deadline observation can show where a blocked read occurred, but this probe deliberately abstains from calling it a contract violation unless the contract explicitly bounds that diagnostic path. The raw parent package and its original results remain unchanged.
