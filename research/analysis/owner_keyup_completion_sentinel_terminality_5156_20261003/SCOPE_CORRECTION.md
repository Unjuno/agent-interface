The preregistration's phrase “evidence-integrity gap in this formal-result gate” is broader than the test performed. The frozen target was invoked only in synthetic-cli mode; the formal mode's separately authenticated host receipt and raw-SHA binding were not invoked. The observed finding is strictly that this synthetic CLI audit accepts the tested nonterminal row order. It does not show that an altered raw file can pass an authentic formal receipt, that formal X11 mode accepts a forged trace, or that any historical result is invalid.

The correction preserves the original preregistration unchanged and narrows interpretation of the result. The existing runner source emits its completion row after its other records; this test changed the row order in synthetic input only.
