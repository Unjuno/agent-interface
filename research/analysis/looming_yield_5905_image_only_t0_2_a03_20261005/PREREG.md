## H / T / D / C / U

**H:** On six finite authored centered constant-speed approaches, an image-only secant time-to-contact (TTC) cue, after a shared trackability/abstention gate, requests release earlier than endpoint pixel-change and target-area-growth thresholds under the same observation budget and false-YIELD allowance on detectable controls. An exactly observation-identical nonapproach twin is excluded from the comparative score and reported separately as an identifiability witness.

**T:** Thirteen 5-frame 128×128 PGM sequences at 100 ms cadence: six approach cases; five detectable controls (camera zoom, lateral motion, partial occlusion, track swap, timestamp regression); one stationary nonlooming hazard; one byte-identical observation twin to approach-1. Candidate input contains only pixels, timestamps, track IDs. Hidden truth and contact deadlines are auditor-only. All three comparator families (pixel difference, area growth, TTC) use the exact same shared gate: valid monotonic cadence, stable track ID, centroid drift ≤4 px, circularity in [0.70,1.30], background marker scale drift ≤5%. The same five-frame budget and release latency 0.20 s apply. Threshold grids: pixel [.005,.01,.02,.04,.08], area-growth [1.02,1.05,1.10,1.15,1.25], TTC [1.5,2,2.5,2.8,3,4] s. Comparative scoring uses six positive approaches and six controls other than the twin, with a preregistered maximum of zero false YIELDs on these identifiable controls. The twin is a separate metamorphic check: same observation bytes/timestamps/track IDs must produce exactly the same candidate outputs; its semantic label is disclosed only to the auditor. This avoids spending the main error budget on a case no image-only rule can distinguish.

**D:** `PASS_METHOD_SCOPED_WITH_IDENTIFIABILITY_LIMIT` only if: all six approaches request release with positive analytic release lead; every one of the six identifiable controls is UNKNOWN/no-request under all three shared-gate comparator arms; the three threshold frontiers are independently reconstructed at false-YIELD=0 on the identifiable controls; TTC maximum true positives strictly exceeds both simple baselines at that same constraint; the twin input is byte-identical and its complete outputs match; auditor independently reconstructs all 13×5 image hashes, timestamps, tracks, metrics, gates, grids, outcomes and truth labels with zero errors. Any discrepancy is FAIL. Main drift, WSLc nonempty at start gate, source/hash mismatch, or environment setup failure before candidate evaluation is STOP. Candidate and auditor each have one invocation, retry budget zero.

**C:** Finite authored raster geometry and analytic contact oracle; this comparison only establishes properties on these fixtures. The image-identical pair establishes a hard identifiability limit. A false-YIELD allowance of zero applies only to the six declared detectable controls, not a population error rate. Marker scale is a constructed camera-motion proxy, not calibrated camera estimation. No GPU is allocated because these deterministic 128×128 scans are CPU work.

**U:** Not live gameplay, screen capture, enemy detection, authority change, safety filter, agent behavior, damage, task outcome, human tempo, release runtime latency or general TTC reliability. No-looming never means safe to continue. Does not consume #59's live-game allocation.
