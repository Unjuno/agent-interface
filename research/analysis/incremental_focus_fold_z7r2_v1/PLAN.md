## C / U and integration decision

The general fold law is already known (#1776). This tests an actual pure implementation and two error-state lifetimes. A naive sticky UNKNOWN loses valid recovery; resetting every UNKNOWN can hide malformed history. Neither is alleged deployed production code.

Fixed typed context, trusted initial snapshot, contiguous retained records, single owner and no out-of-band mutation are assumptions. Sequence numbers cannot establish complete real-world coverage or authenticate the sender. The candidate cannot detect an event omitted and renumbered by a dishonest source. It has a constant number of fields, but integer representation has bit costs; full raw history is still retained for audit, so total study storage is NOT constant.

**Base case.** The constructor checks exactly the reference context conditions and decodes the same32-byte seed. Invalid context sets z=true, reproducing F's UNKNOWN for every extension. Otherwise d is the same seed bit, k=true,f=true,p=false, z=false, and the next ordinal is C.first_ordinal. Thus A(S_0)=F(C,empty).

**Induction hypothesis.** After an arbitrary structurally valid prefix of length j, the nonpoisoned state's d,k,f,p and next ordinal equal the local variables obtained by running F through that prefix. A transient UNKNOWN at its output does not change those local variables.

**Invalid next event.** Both implementations require the same exact dictionary shape tests for fields used, contiguous strict integer ordinal, non-synthetic event marker and supported strict type. Every event-specific invalid field or invalid bitmap causes F to return UNKNOWN before reading any later record. Incremental T sets z=true. Future extensions cannot repair that invalid old prefix, so absorbing z preserves every later F result. This also covers KeymapNotify without the immediately pending normal FocusIn; its invalidity is permanent for this history.

**Valid key event.** Both first clear pending and mark known false if the mode is FOCUS_KEYMAP and p=true. Both update d only for the chosen key, to true on type2 and false on type3. All other logical fields are unchanged. The ordinal advances once. Equality of internal state is preserved.

**Valid focus event.** In KEY_EDGES mode both ignore its semantic effect after field validation. In FOCUS_KEYMAP mode both set k=false; f becomes true only for type9 with normal mode0; p receives the same f. The ordinal advances once. A valid later FocusIn may therefore begin recovery even after an earlier FocusOut; the transient UNKNOWN is not poisoned.

**Valid keymap event.** Both decode the same bitmap even in KEY_EDGES mode, which then ignores its state effect. In FOCUS_KEYMAP, pending normal focus is required; both assign d from the same bit and set k=true,p=false without changing f. The ordinal advances once. Thus valid recovery and later key edges remain equivalent.

**Output and conclusion.** In FOCUS_KEYMAP, A is UNKNOWN precisely when z is true or k/f/p does not support a known focused state. Otherwise A emits WAIT exactly when d=true and TYPE exactly when d=false, with the same neutral fields. KEY_EDGES ignores k/f/p identically to F. These cases exhaust the reference branches. By induction, for every finite fixed-context JSON history and each prefix, A(S_j)=F(C,prefix_j). This is conditional program equivalence, not proof that C or the event source describes reality.

**Batch boundaries.** A batch is repeated application of T in original order. An empty batch is the identity. Concatenating batches applies the same transition sequence as a single batch, including the absorbing invalid state. Consequently any partition of the same history has equal output at every shared boundary. No checkpoint or reordered-input equivalence is asserted.

**Work law for the valid benchmark.** At m=n/b boundaries, the unchanged full-prefix loop traverses b,2b,...,mb records. Therefore V_full=b*m*(m+1)/2=n^2/(2b)+n/2. The incremental loop traverses each record once, so V_inc=n. For n=1024,b=1 this is524800 versus1024 visits. These are algorithmic event visits, not CPU cycles, packets or empirical disk accesses. The candidate counter is recorded; the reference count is analytically derived, not falsely labelled instrumented.

**Timing and units.** Delta t=t_b-t_a has seconds because both operands use the same clock. R=Delta t_incremental/Delta t_full is dimensionless. Stored integer ns are converted to microseconds only for presentation; ratios are unchanged by that common scaling. All event counts and bitmap/sequence relations are dimensionless. CPU and wall durations are never subtracted from each other.

**ERROR CHECK.** The proof preserves early-return poison as distinct from recoverable focus loss, covers both modes and empty batches, and does not infer world-currentness, fixed byte memory, checkpoint authenticity or whole-task benefit from pure equivalence. Finite tests check implementation; they do not replace the conditional proof.
