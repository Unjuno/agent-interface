# Adjudication and audit protocol

The adjudicator receives randomized reviewer IDs, the blind packet, and all three arm outputs, but no arm-to-reviewer mapping, stratum, or gold defect labels. It classifies each finding as source-supported omission, harmless wording, unsupported addition, or ambiguity, and marks cross-invariant interaction only when the source explicitly links clauses and the proposed verification fails that relation. It may return UNCERTAIN; no majority vote resolves source ambiguity.

The raw-only auditor then receives the arm key and gold inventory. It verifies: exact 16 case IDs per arm with no duplicates; output schemas and stable finding order; adjudication has no invented finding IDs; unmutated and paraphrase controls have no unsupported addition; ambiguous controls remain unresolved; each true omission is credited only when an adjudicated finding names the missing source-supported obligation; and the preregistered decision rule is applied mechanically. It reports arm-level counts, qualifying cross-invariant recall, false additions, ambiguity disposition, reviewer completion time if recorded, and exact input/output hashes. It does not use a majority vote or alter classifications.
