**H.** On a finite affine corpus, a frame-typed transform graph with epoch transitions and bounded uncertainty agrees exactly with an independent hidden-matrix oracle, rejects stale/unmodeled controls, and reduces false UNKNOWN decisions by at least 20% versus a fair last-known capture-origin uniform scale/offset comparator on the preregistered exact-safe composed-affine stratum.

**T.** Enumerate finite affine edge-map options and measurement-offset options. The candidate receives only public frame/edge metadata, declared map-option sets, public target estimate, point, and baseline calibration schedule. The auditor independently composes exact hidden edge matrices, maps the original point and region corners through each total transform once, enumerates hidden truth assignments, and checks every reported mapped-value hull and decision. Include direct stable/translation/uniform-scale controls; crop/presentation, client/window, mixed-DPI, monitor-origin, backend edges; 7→8→9 epoch composition; common-mode and independent-error controls; and the identity product of an inverse-shear pair. Invalids include stale binding/epoch, missing/reversed/ambiguous/duplicate paths, unit and DPI-context mismatch, identity swap, non-affine reflow, target-boundary uncertainty, and forbidden-region overlap.

**Baseline calibration schedule.** The baseline never rejects a row for having multiple graph edges. It applies the single public scale/offset matrix registered by the current schedule state to both target and action coordinates, then computes its mapped values and decision. The schedule begins at `scale1`; a public row's `calibration_event.refresh_to` field changes state immediately before that row is scored, and the refresh may select only an entry in the predeclared `baseline_schedule.calibrations` table. No baseline matrix is selected from hidden truth or row-specific hidden transforms. This baseline is intentionally frame-untyped, so a point already expressed in presentation/client coordinates is still passed through the single capture-origin map, preserving the comparator's actual limitation rather than replacing it with refusal.
