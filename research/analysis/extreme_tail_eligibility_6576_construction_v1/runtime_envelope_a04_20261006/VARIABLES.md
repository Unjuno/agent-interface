# Variable table

| Symbol | Meaning | SI unit | Definition | Domain / assumption | Type |
|---|---|---|---|---|---|
| `N` | samples per stream | 1 | 1024 | fixed | integer scalar |
| `i_s` | shift index | 1 | 512 | 0 <= i_s < N | integer scalar |
| `W` | detector window | 1 | 64 samples | fixed | integer scalar |
| `K` | exceedance alarm count | 1 | 6 | 1..W | integer scalar |
| `H` | diagnostic horizon | 1 | 16 samples | fixed | integer scalar |
| `X_i` | synthetic delay magnitude | arbitrary synthetic time unit | generated by frozen distribution | X_i >= 0 | real scalar |
| `q_0.99` | reference 99th percentile | same synthetic time unit as X | `-ln(0.01)` for Exp(scale=1) | exact generator parameter | real scalar |
| `D` | deterministic cutoff diagnostic | same synthetic time unit as X | 8.0 | fixed; statistical policies never change it | real scalar |
| `A_s` | sample-alarm index | 1 | first window end with >=K values > q_0.99 | integer or null | optional integer |
| `A_m` | metadata invalidation index | 1 | first mode label != reference | integer or null | optional integer |

Dimension check: comparisons `X_i > q_0.99` and `X_i > D` compare identical synthetic-time units; indices/window/counts are dimensionless counts. No conversion to seconds or physical latency is claimed.
