# Frozen H / T / D / C / U

**H:** A finite scorer can keep initial contract success separate from a
later-reader result, detect planted loss of required significant properties,
preserve harmless cosmetic changes as PASS, and report incomplete dependency
access as UNKNOWN. A route-ranking reversal is possible under the stipulated
cost table.

**T:** Enumerate nine deterministic future-reader cases over two synthetic
routes (18 rows). Exact initial property vectors must match the same frozen
contract. Later transformations include identity, preserving migration,
formula/link loss, open failure, render-only loss, cosmetic-only change,
missing dependency, and route-specific survival reversal. An independently
authored auditor reconstructs initial and future statuses/costs and tests four
mutations: parse success as semantic success, cosmetic penalty, missing
dependency as PASS, and initial PASS overriding later failure.

**D:** PASS_METHOD_SCOPED requires exact initial property equality for both
routes, all later rows matching the independent oracle, semantic loss as FAIL,
harmless cosmetic as PASS, missing dependency as UNKNOWN, a synthetic cost
ranking reversal, and rejection of all four metric corruptions. Hash or
transport success is not a semantic oracle.

**C:** The strict current TaskContract may already capture every significant
property; if so, no later route reversal is relevant. Native format and
ordinary backup may suffice.

**U:** These are synthetic property maps, not real files, office formats,
readers, renderers, or version migrations. This tests scorer sensitivity only;
it cannot support compatibility or preservation claims. A finite version
ladder does not predict long-term usability.

No user artifact, network, model, app, GUI, container, or external data is
used. Host-only standard-library Python. Candidate and auditor each run once
after preregistration; no retries.
