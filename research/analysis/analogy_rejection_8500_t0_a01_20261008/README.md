# Rejected-analogy memory T0 A01

Issue [#8500](https://github.com/Unjuno/agent-interface/issues/8500). This is a finite, synthetic method test using a deterministic non-agent scorer. It is not a literature-search, human-review, model, GUI, deployed-memory, or product result.

Read [`PROTOCOL.md`](PROTOCOL.md) before the candidate or result. `fixture.json` holds eight target cards, 24 mappings, six rejection records and four changed-envelope controls. `truth.json` is the separately authored finite relation oracle. `candidate.py` is the fixed scorer and raw-row producer; `audit.py` reconstructs decisions and metrics without importing the candidate. Original inputs and outputs are never regenerated by the auditor.

Reproduce the construction suite with:

```powershell
python -B -m unittest -v test_candidate.py test_audit.py
```

The one-shot formal commands, if recorded in `RUN.json`, are:

```powershell
python -B candidate.py --dir .
python -B audit.py --dir .
```

All conclusions are limited to the authored corpus, fixed scorer, and word-unit budget in the frozen protocol.
