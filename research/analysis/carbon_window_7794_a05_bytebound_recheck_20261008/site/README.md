# Public site

This directory contains the GitHub Pages presentation layer for Agent Interface.

- [`index.html`](index.html) — public landing page.
- [`proof.html`](proof.html) — evidence/proof presentation page.
- [`media/`](media/) — media assets used by the public pages.

The site is a presentation surface, not the canonical research record. For current project status and claims, use the repository [`README.md`](../README.md), [`docs/`](../docs/), and [`RESEARCH.md`](../RESEARCH.md).

Research evidence and raw retained artifacts remain under [`../research/`](../research/).
