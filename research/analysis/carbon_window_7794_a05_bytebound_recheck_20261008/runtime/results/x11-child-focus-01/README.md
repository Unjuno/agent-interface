# Preserve existing X11 child focus

The public X11 backend previously called SetInputFocus on the registered top-level client on every focus operation and required exact XID equality afterward. The native research bridge already recognizes real X11 descendants and preserves a focused GTK InputOnly child. Integrate that ancestry behavior into the shared backend: if focus is already within the explicit target, leave it alone; otherwise request focus and verify ancestry. Only the actual X11 parent chain is used, bounded to 64 entries. A WM_TRANSIENT_FOR sibling is not implicitly admitted as a descendant.
