# Optional primary caller packaged on main

Past personal trials stopped after constructing the wrong mint field or omitting
an input offset. This integrates the candidate's tested positional helpers and
explicit sequential STOP policy into the optional portable host bundle. Its
source is `d8ec4e2add9ba3aa9688486c175e003c73e54532`, based on main
`2fbbd0430359a2de11609372e003c3f6ad632a36`.

`observe`, `mint`, `input`, and configured `reviewWindow` build documented
public arguments without selecting targets or actions. Reviews and text
acknowledgments require the returned integer `attempt`. Original responses are
preserved. Unexpected refusal, malformed outcome, incomplete input, nonneutral
release or invalid helper arguments latch STOP; only public close can then be
sent. Exact one-use declared refusal controls are an optional trial setting.
The generic host remains the caller-decided recovery interface. This optional
wrapper does not allow activation or promise automatic recovery; it is not
enabled as the default product control policy.

The unchanged candidate `primary-input-self-use-01` evidence bundle is included
inside the raw archive and reverified normally and with `-O`. It contains a
known serial six-task pair with guarded 6/6 and direct 6/6 exact-once effects.
Its fixed order, different program granularity, extra image reads, incomplete
provider measurements and overall candidate HOLD are preserved. No main
six-task acceptance or causal speed benefit is inferred from that result.

## Fresh main-specific use

The primary personally imported `primary_caller.mjs` from the newly built host
bundle, with source/build/driver/fixture hashes frozen before launch. On a private
WSL Xvfb/Openbox/Tk scene it used `observe()`, positional `mint`, pointer-only
`input`, reviewed the actual hover image, minted a fresh alias, and clicked APPLY.
The independent application journal records exactly one Save after motion ended.
All three original images were reviewed before subsequent input; no extra image
preview was needed. Six public calls, two input programs, policy STOP null,
verified neutral releases and public close, transport exit 0 and owned children
terminal `[0,0,-15]` are retained. No oracle was read before close.

First-send-to-last-reply host span was 43,240.53 ms: requests outstanding
1,955.28 ms, presentation callbacks 5.77 ms, other intervals 41,279.48 ms.
Other intervals include orchestration, logging and caller gaps; they are not
isolated model reasoning/waiting. This single known scene supports packaged
helper usability, not first useful feedback, semantic latency, human tempo,
matched speed or actual provider tokens/cost.

## Checks and failure preservation

The helper tests failed before its module was present. The complete host suite
then passed 86 tests. The first shared native run passed protocol tests but
failed one distribution test: its source-pinned build could not read the new
uncommitted helper from the old main commit. That failure and logs are retained.
After saving the source commit, a separate native run passed 337 protocol and
156 harness tests, including exact committed host export and conflict refusal.
No live trial was restarted or relabeled to repair this construction failure.

`raw.tar.gz` retains 163 files, including the original candidate archive, frozen
main trial, exported host modules, original requests/replies/images/reviews,
independent journal/cleanup, RED/green and both native-run logs. The member
inventory and hashes are in `raw-manifest.json`; `result.json` binds archive and
auditor. Verification freshly extracts the archive and recomputes public helper
argument shapes, exact export/build identity, image/review binding, neutral
release, independent effect, STOP/termination and test outcomes. A duplicate
Save journal is rejected normally and with `-O`.
