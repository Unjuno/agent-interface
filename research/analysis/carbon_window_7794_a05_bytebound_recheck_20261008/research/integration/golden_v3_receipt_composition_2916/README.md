# Golden-v3 receipt composition successor (#2916)

This additive, pure-Python boundary composes three receipts before a caller
invokes the existing native dispatcher: visual-target admission, source
identity, and an independent task-effect score. It emits no input, renews no
lease, discovers no target, and grants no authority.

Run:

```bash
python -m unittest -v research.integration.golden_v3_receipt_composition_2916.test_receipt_composition
```

A passing test means only that the typed decision table is internally
consistent. It is not a live desktop, six-task, Docker Desktop, latency,
token, portability, or task-success claim. The existing native result and
mixed-app evidence remain unchanged.
