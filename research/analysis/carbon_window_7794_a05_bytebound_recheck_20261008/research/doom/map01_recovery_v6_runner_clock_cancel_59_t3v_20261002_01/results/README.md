# T3V generated results

Before the frozen one-shot construction, this directory contains no candidate or audit output. The construction command's stdout/stderr and `construction_attempt.json` are retained here. Candidate `candidate_raw.json` is produced only if construction passes. Independent `audit_result.json` is produced only if the candidate exits zero. The files in this directory are not included in the pre-run source hash set in `FREEZE.json`; they are covered by the final `SHA256SUMS` after execution.
