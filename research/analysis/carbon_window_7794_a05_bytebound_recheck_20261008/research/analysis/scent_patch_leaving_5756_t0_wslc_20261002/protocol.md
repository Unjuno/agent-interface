# Issue #5756 — patch-leaving discriminator, T0

Status: frozen method-only synthetic experiment. This is a new allocation and additive path; the earlier #5756 T0 and its result remain unchanged. No GUI, model, GPU, network, or live effects.

## H / T / D / C / U

**H.** Given only visible labels, visited outcomes, and conservative public cost/yield bands (never hidden target locations), a bounded patch-leaving policy can choose when to leave a subtree with lower traversal cost than fixed-depth and exhaust-current-branch policies at equal target-finding correctness on held-out finite graph fixtures.

**T.** One WSLc container invocation, allocation `SCENT-PATCH-LEAVING-5756-20261002-01`, seed `57562026100201`. Generate 120 deterministic binary hierarchies at depth 5 (32 leaves each): 24 each of declining-yield misleading-high-scent, costly-reentry low-scent true branch, uniform-yield negative control, target-absent, and unsafe-edge exclusion. Within every stratum, 12 training and 12 held-out graphs. Three deterministic policies share the same visible local labels, branch ordering, reversible-edge contract, maximum 96 inspections, and inspection cost 1; backtracking/re-entry has the frozen graph's public cost band. Policies: (A) fixed-depth-2 backtrack, (B) exhaust current safe subtree before switching, (C) patch-leave after two unsuccessful inspections only when visible remaining safe-yield upper bound is below the next reachable branch's lower bound after traversal/re-entry costs; otherwise continue; if bounds overlap, abstain and use B. Hidden target positions are provided only to an independent scorer. Main per-graph endpoint is target found within budget with no forbidden transition; secondary metric is mean inspection+traversal cost among successful rows, plus full abstention/failure counts. No post-hoc threshold tuning: rule and strata are fixed here.

The fixture generator sets visible decoy/true cue rankings, safe/reversible flags, subtree size and public cost bands before assigning target leaves. For the declining-yield stratum, within-branch observed yield falls by construction after initial decoys; for costly re-entry, the true branch has low initial cue and higher public re-entry cost; uniform-yield has constant target density; target-absent has no target; unsafe-edge cases include one tempting unsafe edge that every policy must exclude. These are software fixtures, not a claim about real GUI frequencies.

**D.** `PASS_METHOD_SCOPED` only if all 120×3 policy rows are present exactly once, all hidden-location leakage controls and unsafe-edge control are rejected by an independent raw-only auditor, target-absent is never a success, all unsafe edges are excluded, and candidate output hashes match the frozen protocol. The schedule discriminator is descriptive only; H is supported only if C has equal-or-better correctness and strictly lower held-out mean cost than both A and B, with no unsafe effect. If it does not, report `H_FAIL_SCOPED` or `NO_ADVANTAGE_SCOPED`; no live-benefit claim. Method failure or incomplete rows is `FAIL_METHOD`/`STOP`, never silently dropped.

**C.** Synthetic binary trees, hand-coded yield schedules and public cost bands may favor the candidate. A fixed rule may dominate on regular trees; real GUI navigation can mutate state and have no defensible safe-yield bounds.

**U.** No model behavior, GUI transfer, causal effect, utility, wall-clock advantage, or external novelty is established. The construction is finite and synthetic; it cannot prove general optimality.
