## Correction incorporated from Issue comment

An existential path in one state does not certify advice for a belief set. `ROBUST_ADVISORY` requires one safe first action for every compatible state and a complete observation-conditioned continuation over every declared outcome. `CONDITIONAL_ADVISORY` states its unmet observation/authority precondition. `EXISTENTIAL_ONLY` is not presented as actionable advice. `NO_ROUTE_WITHIN_BOUND` is limited to the declared model and horizon, never global impossibility.
