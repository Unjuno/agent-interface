## Frozen protocol

The eight fixture rows and decision rule in this package are the complete T0 corpus. Each source clause has a separately adjudicated finite atom set. A derived clause must link to valid source IDs and preserve every atom; any added atom unsupported by linked source fails. Only a later authenticated turn may supersede an earlier source clause. Genuine ambiguity must remain `UNKNOWN`. The comparator implements a static clause-to-targeted-test trace baseline and intentionally has no authenticated-turn retirement rule. The independent oracle is hard-coded separately in `independent_audit.py`; it does not import candidate logic.

Required mutation tests: omitted prohibition, conditional weakening, unsupported permission, forged/equal-turn supersession, and mismatched source span; a forced interpretation of ambiguity is also checked. Thresholds and oracle labels are not to be tuned after execution. One frozen run; no model calls, retries, seed search, or result overwrites.
