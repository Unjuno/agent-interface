## Frozen design and execution

The exact fixture, hidden oracle, candidate, independent auditor and test source are hash-bound in `FREEZE.json`. Sequence identifiers are opaque; condition-role truth is kept in `oracle.json`, which is never mounted in the candidate container or included in reviewer packets. All final probes are crossed with all four sequences, so no sequence uniquely predicts the final truth. The same uniform action choices appear in every cell.

Two separate reviewers would receive the two differently ordered packets and independently mark: same current facts for each probe; no mismatch in task family/difficulty/layout/options; no prior sequence reveals the final hidden effect; UNKNOWN remains UNKNOWN; and the proposed correct action follows the current evidence, not history. Signatures remain absent until actually supplied; packet generation is not reviewer approval.

Formal output begins empty. Candidate and auditor each have a one-invocation budget; retries/replacements are zero. Containers use the dedicated `research-6680-a01-20261003` OrbStack VM and its separate Docker Engine, pinned `linux/arm64` Python image, `--network none`, read-only root/source, 0.25 CPU, 256 MiB RAM/swap, 32 PIDs, UID/GID 1000, dropped capabilities and `no-new-privileges`. The OrbStack-shared Docker context is not used.
