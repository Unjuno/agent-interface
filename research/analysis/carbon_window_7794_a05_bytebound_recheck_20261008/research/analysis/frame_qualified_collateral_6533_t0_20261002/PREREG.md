# Issue #6533 — T0 preregistration

## H / T / D / C / U

- **H:** In a finite structured-state fixture, a qualified target/resource footprint can preserve the full-state collateral verdict while reducing accounted checker work on a genuinely disjoint region; aliases, hidden/incomplete writers, stale generations, incomplete dependencies, and non-durable snapshots must fall back to full checking, never become a clean frame PASS.
- **T:** On eleven frozen no-model document-graph traces, compare `TARGET_ONLY`, `FULL_STATE`, `STATIC_DIRECT`, and `QUALIFIED_FRAME`. Include exact target write, transitive formula collateral with an independently identified dependency rule, alias write, hidden callback, external writer, stale generation, delayed durable save, missing dependency edge, and three genuinely disjoint regions at 8/64/256 unrelated-cell sizes. Each certificate binds version, action/input identity, authorized footprint, exact elided collateral predicate, source generation, dependency provenance, writer/alias/callback/persistence coverage, and a hashed event manifest. Candidate emits all 44 policy/case rows. A separately implemented auditor receives the frozen before/after states, event/manifest bytes, and candidate rows; it independently checks event-to-state correspondence, reconstructs all verdicts, and checks exact full-oracle parity and qualification refusal.
- **D:** `PASS_METHOD_SCOPED` requires all 44 rows reconstructed, zero qualified-frame false-clean cases, exact parity with the independently derived full-state outcome whenever a qualified frame is used, every ineligible case falling back to full-state, and at least 10% reduction in checker-level accounted bytes in aggregate over all three predeclared disjoint sizes after certificate/graph bytes are charged. Otherwise retain `FAIL_METHOD` or `FAIL_NO_COST_REDUCTION`; no threshold changes after running. Wall-time medians are measured over 31 in-process evaluations per row and reported descriptively, not substituted for the byte-work gate.
- **C:** A fixture can make the writer closure artificially complete. Full-state remains simpler; certificate construction/validation may erase the benefit. The checker's accounted-byte metric is not end-to-end file I/O because both methods receive already-materialized snapshots.
- **U:** No claim about real GUI applications, autosave, cloud writers, concurrent humans, causal attribution, production safety, or application performance. T0 cannot prove completeness of a real app's writers or close a check-to-effect race.

## Cost definition

`accounted_bytes` is checker-level data work after the before/after structured snapshots have already been materialized: canonical bytes of state records actually examined plus canonical bytes of certificate/generation/dependency metadata and the event manifest parsed and validated. Full fallback scans charge the entire full-state record scan in addition to certificate/event work. Snapshot file ingestion, application rendering, durable storage I/O, certificate issuance outside this fixture, and external audit cost are not represented. `state_read_calls` counts two in-memory before/after record accesses per examined state record; `metadata_read_calls` counts virtual certificate/event/dependency-record examinations. Neither is an OS/file syscall count. Wall time is reported separately.
