# Issue #6342 safe-stop presentation T0

This is a no-participant, finite synthetic method experiment. It tests whether a matched pair of safe-stop card framings preserves the same evidence, stop rule, safe action set, and accessibility structure, and whether an independent checker rejects two planted unsafe cards.

It does **not** measure human choice, reactance, comprehension, safety behavior, or any GUI/runtime outcome. See [PREREGISTRATION.md](PREREGISTRATION.md) and the final [REPORT.md](REPORT.md) after the one-shot OrbStack allocation.
