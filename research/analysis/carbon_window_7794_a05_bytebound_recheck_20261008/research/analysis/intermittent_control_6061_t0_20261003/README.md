rows, synthetic position/residual inputs, and operation counts rather than
measured latency. The historical Windows construction receipt reports exact
candidate/auditor agreement and five rejected mutations. This is not a formal
Issue result, live controller/game/GUI/model/held-key observation, user-safety

are described in the unchanged PLAN and construction report; their transcript
console output is not in this remote package. The report refers to stderr

published source tip. Recovery does not invent those missing artifacts.

original freeze. All eight declared hashes are verified. Package-local
