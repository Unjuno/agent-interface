# AI-6147 T1 — disposable X11 GUI transfer experiment

## H / T / D / C / U

**H.** In this frozen deterministic disposable GUI fixture, a public-family-conditioned adaptive safe sequence P→Q will reveal the current action-relevant output for both hidden A/B initial states and permit exactly the corresponding safe action. For the same hidden-state support, no-probe and one-safe-probe arms will yield on A/B; action-equivalent C/D will permit COMMON without full identity probing; impossible E/F and post-probe expired G/H will yield; and convergent I/J may permit COMMON only at shared current terminal Z without identifying the initial state. No arm selects U.

**T.** Run 10 hidden initial states in each of three arms (30 trials total). The states are A/B (separable), C/D (action-equivalent), E/F (safe probes cannot distinguish), G/H (p→q labels the initial state but expires the current target/effect envelope), and I/J (same initial alias converges under p→q to shared current terminal state Z, without an initial identity claim). Each arm contains each hidden state exactly once; assignments are separately shuffled. Public contexts disclose trial index and family only. The candidate receives public contexts and model color/button calibration, but no fixture/deck/oracle source or hidden-state ID. The fixture runs as a separate Xvfb/X11 process/container and owns the hidden deck and effect oracle. The candidate uses XTest input and classifies only sampled XGetImage pixels. Candidate output and fixture/oracle log are retained separately. A third, separate auditor container independently reconstructs expected outputs, decisions, post-probe terminal states/effect envelopes, event order, generations, and mutation controls from raw logs; it imports neither candidate nor fixture code.

The fixed arms are `no_probe`, `one_step`, and `adaptive`. Trial order is the frozen input order. F12 is a harness-only reset between trials and is excluded from policy probe/effect counts. The fixture contains no real application, account, user data, model, game, GPU, host GUI, network, or external effect; successful effects are in-memory fixture receipts only.

**D.** `H_PASS_SCOPED` requires all 30 rows and all ten unique hidden states per arm; exact raw-only replay with zero audit errors; no U or wrong/rejected effect; exactly one verified LEFT and one verified RIGHT across adaptive A/B, no actions for no-probe/one-step A/B, COMMON for action-equivalent C/D, COMMON only at Z for adaptive I/J with no initial identity claim, and YIELD for impossible E/F and target-expired G/H despite their distinguishable outputs. The five corruption controls (drop row, forge candidate hidden ID, swap distinguishing branch, inject U, act after expiry) must all be rejected. A complete eligible run that violates any performance or safety condition is `H_FAIL_SCOPED`; incomplete launch, missing raw, runner/auditor error, or resource/runtime failure is `STOP`/`NOT_EVALUATED`, never a semantic failure or pass. No retry, tuning, or replacement run is allowed for this allocation.

**C.** This uses one deterministic authored fixture, one arm per fixture/candidate container pair, one pinned image and one OrbStack arm64 engine. Public family labels are supplied as a declared model assumption. A direct task-specific typed query or ordinary YIELD may be simpler and safer; the action-equivalent class deliberately shows that identity is not always necessary.

**U.** This cannot establish safety, observability, usefulness, or performance for real applications. It assumes finite known states, stationary deterministic pixels, valid reset semantics, sound hidden-state/effect oracle, and safe P/Q operations within this fixture.
