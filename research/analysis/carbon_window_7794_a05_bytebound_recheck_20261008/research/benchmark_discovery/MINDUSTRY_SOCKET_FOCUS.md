# Mindustry private-socket focus interruption

New Mindustry socket entries reuse unchanged stopped_socket_v1, CommandOnce and PendingAction with the previously measured interactive v2. A test-only backend transfers actual X11 focus to a private sink after acknowledged drag button-down. The long drag has a trailing click, which must not execute. This is scripted integration, not assistant gameplay or model latency measurement.

First run results/mindustry-socket-focus-01 did receive input_stopped, two passive observations, needs_decision/focus_changed terminal and successful observe-only recovery. The sink retained focus; subsequent no-input delivery evaluation timed out after30 seconds. Background focus is a plausible cause, not separately isolated. The driver additionally attempted a second finish from its finally block after a20-second receive timeout, which violates the intended no-resend discipline. Both defects and raw calls are retained; cleanup confirmed all owned processes exited and the save remained unchanged. The first run is not an end-to-end pass.

Version2 adds test-fixture focus restoration after the fresh recovery snapshot and changes cleanup/waiting to command-free polling. Thus recovery observes the sink state; only the fixture restores game focus before evaluation. This is not an agent refocus operation or a new grant of input authority. The v2 driver also continues command-free evaluation polling if the first response times out, although the successful second run did not exercise that timeout branch. These changes were made together, so no isolated causal performance comparison is claimed.

The second fresh run, results/mindustry-socket-focus-02, completed with exit0. Seven actual AF_UNIX calls and25 runtime events show one focus-drag submission, input_stopped_capture_pending followed by terminal_received on the same PendingAction, exactly two passive post-stop observations, no drag endpoint or trailing click admission, a fresh observe-only program and exactly one finish command. Four transported frames reconstruct exactly. Independent game scoring correctly reports missing targets and zero delivery; no construction was attempted. All owned processes exited, save unchanged.
