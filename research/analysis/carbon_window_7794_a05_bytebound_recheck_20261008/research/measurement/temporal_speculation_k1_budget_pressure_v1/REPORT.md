# K=1 branch-budget temporal speculation — first outcome

Decision: `PASS_TEMPORAL_SPECULATION_K1_BUDGET_SCOPED`.

Only branch budget changed from K=2 to K=1; planner gap, realization timing, corpus category counts, fresh admission/effect semantics and latency thresholds remained unchanged from #1127. Current-only used a fixed +1 tie-break; the authored corpus is exactly left/right symmetric. Temporal used +1 for monotone-right, -1 for monotone-left and +1 for ambiguous.

400,000-case first outcome: current-only hits **151,814 (37.9535%)**; temporal-informed **231,610 (57.9025%)**, gain **+19.949 percentage points**. Mean realized-state->effect latency: WAIT **31.0000 ms**, CURRENT **19.61395 ms**, TEMPORAL **13.62925 ms**. Temporal improves current-only by **5.9847 ms** and WAIT by **17.37075 ms**, clearing the frozen >=3 ms / >=10 ms gates.

24 selected monotone-left subprocess discriminator cases (72 arm runs) all independently logged EFFECT_APPLIED; wrong0. Median realized->effect: temporal **0.7978 ms**, current **30.8995 ms**, wait **30.8461 ms**.

Interpretation: history becomes materially more valuable when speculative capacity is tighter. This does not justify a rich temporal system: the gain is still generated by a trivial velocity feature and fixed tie-break under an authored symmetric distribution. The correct next question is whether real branch-preparation cost makes K=1 preferable to K=2, not whether to add a learned predictor.
