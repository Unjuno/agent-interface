## Resource and retention contract
One allowed CPU, address-space ceiling 256 MiB, CPU ceiling 30 seconds and subprocess wall timeout 30 seconds. Set OPENBLAS_NUM_THREADS=1/OMP_NUM_THREADS=1 before Python starts. A timeout or limit exit remains STOP without retry. Source and observations are loaded read-only. Output paths use exclusive creation.

Construction only: use 67x65 top-left crops of the retained images through the same runner, no performance claim and no formal pixels measured. This tests partial-edge tile serialization and retention/auditing mechanics. Inputs remain unchanged; crops are explicitly derived diagnostics. Construction can be repaired before freeze while retaining all attempts. Freeze runner, auditor, protocol, provenance and all original inputs after construction and independent protocol review, before the single formal launch.

Independent auditor imports neither encoder nor runner. It parses the retained first-pass wire packets using struct/json/zlib and byte-row copy, compares exact expected headers, reconstructs exact source bytes, checks row count/order/pairing/state/hashes and recomputes gates. Effective corruption controls are made only on temporary raw-record copies: missing row, wrong prior-pixel hash, wrong wire hash, wrong state sequence, wrong wire length, invalid allocation data, prior-state mismatch, process-exit/log/resource mismatch. A separate coherent positive allocation mutation must preserve wire-parity PASS while forcing allocation HOLD. The unmodified audit must pass before controls run. Controls must be rejected normally and cannot alter the retained source/raw record. The code/process audit is distinct from external human review.
