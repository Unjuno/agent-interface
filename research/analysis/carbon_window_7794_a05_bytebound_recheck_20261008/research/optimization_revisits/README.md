# Optimization revisits

This directory contains explicit revisits of previously tested optimization ideas.

A revisit does not rewrite the predecessor result. It should be read as a successor experiment with its own changed condition, evidence, and disposition.

See [`../REVISIT_LEDGER.md`](../REVISIT_LEDGER.md) for the broader revisit record and [`../../RESEARCH.md`](../../RESEARCH.md) for project-level claims.
