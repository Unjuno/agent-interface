## H / T / D / C / U

- **H:** The 16-row and 4-row set-class samples can have the same normalized template × field joint distribution, not just the same separate marginals, if both arms use the same four predetermined cells.
- **T:** From each of 128 synthetic support pools generated by the prepared #5139 construction source, set offset = support_seed mod 4 and choose the four cells (template t, field (t+offset) mod 4). The imbalanced arm takes all four pool rows in each selected cell (16 set rows); balanced takes one SHA-ranked row per cell (4 set rows). Other classes use the same deterministic within-class ranking and frozen quotas. Assert exact same four joint cells in both arms, template/field counts, 32 rows per arm, and per-class nesting.

Per-class containment is checked in the intended direction because yield-class quotas reverse direction between arms. No outcome or quality-based seed selection.

A single formal seed picks one diagonal relation; the rule and seed must be frozen before outcomes, and one run does not estimate a population effect. Other class contrasts are unchanged. ## Disposition

This is a stronger allocation-independent sampler design candidate than matching only template and field marginals: it also matches the selected joint-cell distribution by restricting the 16-row arm to the same four cells. It reduces coverage breadth and does not resolve individual-row differences. A fresh protocol must preregister the cell mapping and support seed before any model result; it must not search mappings for performance. This diagnostic changes no #5014 artifact or allocation and does not authorize formal #5139 work.
