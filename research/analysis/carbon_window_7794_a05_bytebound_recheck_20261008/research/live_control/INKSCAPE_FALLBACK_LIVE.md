# Actual GUI continuation after optional presentation failure

inkscape_fallback_live_v1 is a test-only copy of the v2 candidate with a fixed injected composer exception after stage move-save. Initial plan pins the source and marks the fault scope. Runtime is unchanged cause socket v5 / interactive v4 / executor v8 on private Linux X11, seed229. No global default or measured previous client is changed.

The assistant viewed the initial and selected rectangle, then used one six-step program to set X74 and save while preserving Y50/W40/H30. After the command returned completed, the optional formatter threw. The client emitted presentation-fallback-v1 containing the complete original result and explicit RuntimeError. The assistant actually received that output through the tool, viewed its referenced image, and recorded that only formatting failed. It did not repeat the move or save. A fresh observe-only program verified X74 and the saved document title; a tooltip appeared but did not obscure the fields. Final GUI prediction was hash-committed through a clock command before independent scoring. Saved SVG confirms X74/Y50/W40/H30, no transform, success true.

Audit passes all 66 events, nine socket exchanges, fifteen exact PNG/AIT frames, source pins, receipt/state-table regeneration and all five output payloads. Initial/finish use original JSON because the envelope would add bytes. Select/verify use exact composed results. Move-save uses the full fallback. The only submit IDs are select, move-save and verify; verify contains just observe, and the entire input history has exactly one Ctrl+S step. Runtime/bridge exit0 was observed. This completes one actual GUI fallback-use check beyond the earlier synthetic socket fixture.

The known injected error is after successful command execution, not an unknown real formatter bug or runtime interruption. There is no claim of handling every presentation/storage/receipt error. Raw output hashes prove local emission and the assistant used the shown fallback, but authoritative model receipt timestamps/tokens remain absent. Initial capture to final GUI commitment was 73.628s including orchestration; this is not a matched speed experiment or human-tempo result. Explicit verification adds one observation program and two socket exchanges; it is not mandatory for every formatting failure.
