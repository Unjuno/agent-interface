# Orchestration documentation

Use:

- [`../CURRENT_GOAL.md`](../CURRENT_GOAL.md) for the current governing research direction;
- [`../LOCAL_RESEARCH_HANDOFF.md`](../LOCAL_RESEARCH_HANDOFF.md) for the latest detailed handoff;
- [`../../RESEARCH.md`](../../RESEARCH.md) for the evidence ledger;
- [`../../ROADMAP.md`](../../ROADMAP.md) for project-level research sequencing.

Historical coordination files remain unchanged for provenance.
