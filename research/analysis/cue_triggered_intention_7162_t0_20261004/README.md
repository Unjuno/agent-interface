# Issue #7162 T0 — cue-triggered unfinished-intention retrieval

Finite no-model test of whether an object/state cue retrieves only lifecycle-
eligible unfinished intentions. It compares plain text recall, typed lifecycle
memory, and a #5404-style validated resumption packet. Retrieval is descriptive
only and grants no action/input authority. This tests the object/state
re-encounter discriminator specifically; it does not repeat the general packet
validity experiment in #5404.
