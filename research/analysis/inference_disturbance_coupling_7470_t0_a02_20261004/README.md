# Issue #7470 T0 — fixed-marginal inference/disturbance coupling

Finite deterministic standard-library experiment comparing all 24 pairings of the fixed inference-duration multiset and fixed disturbance-severity multiset. It contains a no-interaction plant and a deliberately planted latency×disturbance interaction, with a separate raw-only reconstruction.

This is method evidence for this declared toy transition system only. It does not establish a real agent hazard, runtime coupling, or deployment threshold. No model, GUI, game, network, external actuation, user data, or hardware input is used. The Issue specifies a CPU-only standard-library simulator and does not require container isolation; execution is host-only, with no isolation claim.
