## Frozen model and analysis

The only trace change removes the optional `warmup` event from the current-main #8152 base trace. All other event names, ordering, dependency checks, exact target fingerprint, competing fingerprint, and shared exit code 17 are retained. The fixture assigns disjoint deterministic seeds to each case/window and puts windows in increasing slot order. The generator uses the same seed for base and reduced traces, producing paired binary target outcomes.

For each pooled case and each frozen window, the risk difference is `P(reduced is exact target) - P(base is exact target)`. It is estimated as paired gains minus paired losses. A conservative interval is formed as the exact one-sided Clopper–Pearson lower bound for gains minus the exact upper bound for losses (and conversely for the upper endpoint). Bonferroni tail alpha is `0.05 / (4 * 20)`: 20 comparisons are fixed in the fixture (six pooled plus 14 window contrasts), and four component tails form two-sided intervals. A contrast passes only when its lower endpoint is at least -0.20; it fails only when its upper endpoint is below -0.20; otherwise it is unknown.

The block rule returns UNKNOWN before making a pooled substitution if any scheduled transition window is explicitly ambiguous or any identified block has fewer than 64 paired rows. Otherwise any blockwise failure rejects the candidate, all blockwise passes accept it, and interval overlap returns UNKNOWN. Pooled confirmation intentionally combines every row, including a transition-ambiguous window, to test the exact failure mode in the Issue.
