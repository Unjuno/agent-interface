Auditor fixtures are independently hand-declared 32-world oracle labels,
not generated by/imported from the producer. Its 75 structured corruptions
and 17 raw-byte corruptions each assert changed bytes and FAIL. These test
schema/model rejection, not a real-world detection rate. CLI success fixtures

The pre-freeze read-only reviewer accepted the producer/proof but identified
an Important evidence-retention defect in capture v1: buffered communicate()
and receipt creation only after completion let KeyboardInterrupt lose the
attempt's first evidence. The regression reproduced both absent prelaunch
metadata and the escaping interruption before repair. New capture v2 writes
immutable attempt.json and an initial receipt before launching, streams the
child output directly to files, catches timeout/KeyboardInterrupt, stops only
its owned Popen child if still live, records terminal state, and never retries.
Four real-child/file boundary tests cover these behaviors; only wait/launch
boundaries are instrumented for deterministic interruption/prelaunch checks.

Capture v1 is retained as inert construction/CAPTURE_V1_SOURCE.txt, matching
SHA-256 d46c27ba13c122287129550eb39abeccff4ac80949edd57a6ad01b53af631a92.
