# Issue #7418 T0 — exception-preserving episode consolidation

Finite, no-model comparison of exact episode retrieval, unqualified majority
consolidation, and an applicability-bounded skill that retains source-linked
exceptions. The corpus deliberately includes one forbidden minority exception,
a rare but irrelevant context variation, contradictory evidence, and held-out
ordinary/protected combinations. Nothing is executed; the output is a proposal
classification only.

This tests a stipulated representation and oracle, not learned memory, real GUI
work, task success, or action safety.
