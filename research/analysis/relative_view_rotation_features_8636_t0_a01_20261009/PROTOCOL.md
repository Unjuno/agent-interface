## H / T / D / C / U

**H:** On fixed-position three-landmark views with held-out yaw/pitch starts and a fixed nominal projection, a spherical-bearing feature controller will achieve the same exact terminal-view criterion and no greater target-loss or out-of-envelope-action rate than raw normalized point coordinates, while reducing median corrections by at least 20% on the rotation-only and combined-rotation strata. Focal variation and explicit fault controls test limits/abstention, not the primary improvement claim.

**T:** Run 30 paired held-out seeds in each of four frozen strata (pure yaw, combined yaw/pitch, focal shift, and feature loss/ambiguity). The feature-loss stratum assigns, by seed, one each of nine controls: hidden landmark, landmark identity swap, moving landmark, near-singular geometry, one-pixel low-texture markers, translated camera center, stale target/viewport generation, viewport resize, and radial range variation. The range-variation control is an analytic null under perspective projection; the other eight invalidate the fixed correspondence/viewport contract and must make the two image-only arms abstain. Compare (1) a target-frame-localized raw-coordinate controller using a fixed reference-image linearization, (2) a spherical-feature controller using three normalized bearings, three pairwise angular distances, and an image-derived oriented two-bearing frame whose relative rotation is represented by an angle-axis vector, and (3) a hidden-pose oracle upper reference. All arms share the deterministic 2-D actuator, action limits, 12-step cap, image schedule, goal oracle, and neutral-release receipt. Candidate controllers receive PPM frames and target/viewport generation metadata only. Truth labels and target pose remain in a separate scorer file. A standalone raw-only auditor independently reconstructs every frame from the seed schedule and hidden state, replays actions, scores outcomes, checks frame/feature/action custody, and exercises source, event-order, stale-generation, missing-release, and forged-feature corruption controls.

**D:** `PASS_METHOD_SCOPED` requires 120 paired fixtures complete, exact frozen frame/event/source identities, arm budgets equal, independent replay with zero errors, all planted mutations rejected, all eight invalid feature-loss controls abstaining for both image-only arms (54 trials total), the radial range null preserving its projection, no out-of-envelope actions, and a neutral terminal release on every arm. `H_SUPPORTED_SCOPED` additionally requires exact terminal-view success no worse than raw coordinates and at least 20% median correction reduction in the 60 rotation-only/combined pairs, with no increase in target loss. Focal-shift performance is reported separately as an out-of-calibration stress stratum. A valid audited run that misses the quantitative gate is `H_FAIL_SCOPED`; invalid fixture/input/audit integrity is `HOLD_UNCERTAIN`. No retries or threshold changes.
