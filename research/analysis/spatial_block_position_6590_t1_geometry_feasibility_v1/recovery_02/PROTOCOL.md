# Recovery successor 02 protocol

## H / T / D / C / U

- **H:** With a corrected, hash-verified runner, OrbStack reproduces the known host candidate bytes exactly and the frozen independent auditor reconstructs every site with zero errors.
- **T:** Separate new candidate and auditor containers, each once, using the exact parent candidate/auditor source hashes and existing pinned image. Allocation 01 stopped before any container was created; this allocation has fresh names, a distinct result directory, and a new freeze. No model fit, no retry, no shared-container access.
- **D:** `REPLICATION_PASS_WITH_GEOMETRY_HOLD` iff exact candidate bytes match the retained host output, audit errors are empty, and geometry remains below the fixed eight-sites-per-block floor. Any source/image mismatch, candidate/auditor nonzero exit, or reconstruction discrepancy is retained as STOP/HOLD.
- **C:** This reproduces a known deterministic finite geometry result and audits its serialization; it does not test a learned model.
- **U:** No visual efficacy, real GUI, task effect, calibration, safety, authority, or spatial-autocorrelation claim. A different canvas/support design requires another scientific protocol, not posthoc promotion.

The only protocol repair relative to allocation 01 is reading the frozen image and resource settings from their actual `environment` object and writing formal results to a distinct path. Candidate/auditor code, geometry, decision gates, image, and resource limits do not change.
