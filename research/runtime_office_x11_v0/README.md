# Real LibreOffice Calc X11 integration v0

Research Preview lane stacked on the portable contract and private X11 backend. It tests whether a real office application produces an independently recoverable semantic file effect rather than merely accepting XTEST events.

The office candidate keeps semantic AST unchanged. It adds X11/EWMH activation and 12 ms strict-ASCII text pacing as backend policy. The bounded XLSX confirmation step is task/fixture-specific, not a universal office method.
