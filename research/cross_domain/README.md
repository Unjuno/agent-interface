# Cross-domain research

This directory contains transfer and compatibility experiments that move a mechanism across applications, domains, tools, or effect types.

Use these studies to distinguish a mechanism that works in one fixture from one that survives a changed domain. Child files/directories remain scoped evidence and are not product-level support claims.

- Project evidence ledger: [`../../RESEARCH.md`](../../RESEARCH.md)
- Current objective: [`../../docs/CURRENT_GOAL.md`](../../docs/CURRENT_GOAL.md)
- Broader research workspace map: [`../README.md`](../README.md)

Read each experiment's report/plan/audit for the exact source domain, transfer domain, changed factor, and disposition.
