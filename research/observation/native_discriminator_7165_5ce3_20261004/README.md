An initial native read observes all three cues. A single unique field is selected in title/parent/anchor priority (or an explicitly insufficient title default when no unique cue exists). MEMORY_CUE retains only which cue to ask for, not target coordinates or action authority. FRESH_CUE receives the same explicit field without relying on historical memory; it is a strong information-matched selective-observation comparator, not a test of how a fresh model discovers that cue. Both request exactly the same current native data. Their equality is structurally expected; the measured residual is native observed work and conflict/staleness behavior, not a novel memory advantage.

In STALE_HINT the initially sufficient title is replaced by nondiscriminating titles while parent context becomes sufficient. In CONTRADICTORY the old title stays but a parent cue points to the opposite object; current evidence cannot safely establish an unambiguous referent. The hidden scoring oracle designates the opposite object and all policies must abstain from conflict if claiming conservative identification. A one-cue-only arm cannot see the unqueried contradiction; no automatic authority or hidden scorer is provided to it. These are authored counterexamples, not a reported production vulnerability.
