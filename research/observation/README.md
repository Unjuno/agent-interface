This is distinct from [`../observation_gating/`](../observation_gating/) and [`../observation_tiles/`](../observation_tiles/), which retain the earlier scoped gating/transport tracks.

Use [`../../RESEARCH.md`](../../RESEARCH.md) for claims and scientific status. Child directories are retained experiments, not automatically promoted observation semantics.
