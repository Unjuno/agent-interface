# Proof sketch
For a fixed post-reversal direction and a fixed interval containing the reversal time r, each sample position is affine in two unknowns: offset c and reversal time r. The observation contract adds |error_i|<=1 px, producing linear half-plane constraints. Feasibility is therefore exact convex polygon non-emptiness in (c,r). Eliminating c is equivalent to requiring every pair of offset intervals to overlap, which gives linear inequalities in r. Intersect those inequalities with the reversal segment. Constant-motion worlds are the zero-reversal special case. The candidate returns a direction only if the union of all feasible worlds contains exactly one current direction, so under the declared model class it cannot return the opposite of the true direction when the true trajectory remains feasible.

Variables: t [s], x [px], v [px/s], epsilon [px], r [s], c [px]. Unit checks: v*t is px; every position inequality compares px; reversal-time bounds compare s.
