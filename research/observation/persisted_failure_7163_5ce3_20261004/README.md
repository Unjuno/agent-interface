## H / T / D / C / U and roadmap

- H: observed-condition failure memory blocks recurring eligible conditions without
  a timeless ban after clearing. Stronger residual: can its one-field envelope replace
  checking every currently relevant condition when another failure appears?
- T: 100 fresh private Xvfb fixtures: five author-seeded failure classes (cover,
  displaced geometry, wrong focus, app-pending, unrelated business refusal) × four
  current states (RECUR, CLEAR, WITHHELD, NEW_FAILURE with next cyclic class) × five
  arms (NO_MEMORY, NOTE permanent ban, persisted TYPED selective field, FRESH all
  current fields, TYPED_PLUS_FRESH). Serial fixed order, no statistical timing claim.
  Initial actual click/F8 must not save; then persist observed conditions/evidence.
  Each attempted continuation uses actual XTEST input and recipient events; a tiny
  authored application writes `COMMITTED\n` only after target click→target F8 and
  readiness/business checks. Saved file bytes, not a declared task-success boolean,
  are retained. All input stays inside owned private Xvfb.
- D: PASS_METHOD_SCOPED only if typed recurring BLOCK, cleared TRY+file effect,
  withheld UNKNOWN and all native/event/memory/file/cleanup checks hold for all 100.
  If selective TYPED tries a newly failing condition that FRESH refuses, retain
  FAIL_SELECTIVE_TRANSFER_AUTHORITY. Equality with FRESH in the guarded arm supports
  no incremental correctness benefit; never promote construction to live efficacy.
  Any missing/invalid evidence is first STOP, not a scientific regrade/retry.
- C: all-condition fresh guard may suffice; learning a seeded known field is not
  causal discovery. Selective input packets can omit new hazards. This collector
  acquires all five observations even for TYPED, so no observation-cost saving is
  established. File effect is tiny-fixture-specific, not Save in a stock application.
- U: same fixture/collector process owns two Xlib connections and file oracle, not
  an independent/blinded application observer. Cover is overlapping root-child
  routing, not semantic modal. Pending/business are authored X11 string properties,
  not network/transient OS failures. WITHHELD deliberately removes an acquired field,
  not a native query failure. Seeded reason attribution is not model-learned causality.
  Static quiescent fixture, no atomic query→input authority, hostile peer, real app,
  general cleanup certificate, persistent cross-session identity or task/model benefit.
