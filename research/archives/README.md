# Research archives

This is a retained historical archive namespace.

Existing contents remain at their original paths to preserve links and provenance. Directory placement is not a scientific disposition and should not be used to infer whether an experiment passed, failed, was superseded, or was promoted.

Use the top-level [research index](../../RESEARCH.md), the relevant report, and its retained audit/result to determine status.

A separate legacy namespace, [`../archive/`](../archive/), also exists. Repository cleanup documents both namespaces instead of renaming or merging them because exact paths may be part of the evidence record.
