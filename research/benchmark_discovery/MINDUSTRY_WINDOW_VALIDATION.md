Portfolio review found stale matrix entries: the earlier readiness, construction and post-control delivery pilots already exist, although the README still described Mindustry as feasibility only and queued the completed initial pilots. The matrix now reflects the actual evidence while retaining fresh-route, multi-object and dynamic-recovery gaps. DOOM remains one orthogonal stress domain; no formal benchmark adoption follows.

mindustry_build_score_v1 validates initial/final ticks through the placement scorer, but its separate delivery-before tick was subtracted without finite/type/phase-order validation. Offline mutations of the archived successful episode demonstrate false VERIFIED results for NaN, negative infinity, boolean start tick, start before the initial phase, boolean pending-plan count, NaN or zero minimum duration and boolean minimum copper goal. Positive infinity already produced UNKNOWN because its elapsed window was too short. These are synthetic malformed evidence controls; the original live snapshots are finite and are not invalidated.

mindustry_build_score_v2 checks all three ticks are finite numeric non-booleans, initial <= delivery-before < after, a finite positive minimum duration, a positive integer copper target, and an exact integer-zero pending plan count. It then calls the frozen v1 scorer, retaining placement guards and separate delivery accounting. Invalid measurement returns UNKNOWN with no success claim. It is a narrow trusted-fixture scorer, not full arbitrary-input validation or a global causal verifier.

The probe confirms all nine malformed cases now return UNKNOWN. The archived actual score is exactly unchanged, including 48 delivered copper. Four existing controls retain their contract outcome: zero delivery, pending build, short window and changed layout. Sources, original input hashes, old/new statuses and failure diagnostics are in results/mindustry-window-01. No new game run occurred. The existing interactive entry still imports frozen score v1; v2 is an explicit tested candidate for the next new cohort, not retroactive mutation of measured runtime sources.
