# Miscellaneous scoped experiments

This directory is reserved for small scoped experiments that do not yet belong to a more specific research category.

Prefer an existing named namespace such as `measurement/`, `integration/`, `coordination/`, `observation/`, or `cross_domain/` when the work clearly fits one. This directory should not become a second unstructured research root.

Current contents remain at their existing paths for provenance. Use [`../../RESEARCH.md`](../../RESEARCH.md) for scientific status.
