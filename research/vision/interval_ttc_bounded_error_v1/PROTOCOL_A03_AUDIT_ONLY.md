# Issue #8157 A03 audit-only protocol

## H — bounded hypothesis

An independently authored prefix-local reconstruction can determine whether the preserved A02 candidate outputs match their public input on each causal prefix, including prefixes before later occlusion, and whether the recorded A02 mismatch set is confined to that future-history audit defect.

## T — one-shot audit allocation

Use only the immutable A02 public observations, oracle labels, candidate JSONL, first auditor report, source files and their published manifests. Reconstruct point secant estimates, interval estimates, radius-change cues and timestamps using each history prefix only; compare all 2,400 candidate rows; independently join oracle truth by ID and timestamp; and attribute the original report's reconstruction mismatches by profile. Exercise five in-memory corruption controls: declared bound, timestamp, removed sample, oracle hazard label and candidate interval endpoint. Run this audit-only program once in a pinned, network-disabled CPU container after freezing this protocol and the new auditor. Do not invoke the A02 candidate, A02 auditor, or A02 generator.

## D — decision

- `PASS_RAW_RECONCILIATION_ONLY` if all source/artifact hashes match, IDs/strata and all 2,400 prefix outputs reconstruct, every numeric interval on an eligible in-model hazard prefix contains its oracle TTC, the original 98 reconstruction mismatches are 49 point plus 49 interval rows confined to `occlusion`, and each of the five mutations is rejected.
- `FAIL_AUDIT_ONLY` if any integrity, reconstruction, oracle join, mismatch attribution or mutation check fails.
- The recorded A02 `FAIL_METHOD` remains unchanged under either A03 outcome. A03 cannot produce `PASS_METHOD_SCOPED`, recompute its threshold comparison, or repair the original allocation.

## C — alternatives

The mismatch could reflect a candidate defect or changed raw artifacts rather than future leakage. Prefix-by-prefix reconstruction from public history, exact manifest checks and independent oracle alignment discriminate those explanations. Passing this reconciliation does not establish that the estimator is useful or that its scientific decision gates pass.

## U — limits

This is a raw-only audit of one finite synthetic A02 bundle. It creates no new observations, estimates no new method outcome and does not test a real vision pipeline, GUI/game, action, runtime, or safety property.
