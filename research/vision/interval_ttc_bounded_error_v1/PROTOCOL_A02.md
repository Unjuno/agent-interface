# Issue #8157 formal A02 protocol (frozen before candidate invocation)

## H / T / D / C / U

**H.** On finite synthetic traces with stated bounded radius error and constant radial velocity, the set-valued TTC estimator contains oracle TTC and, at a calibration-matched zero-false-YIELD operating point, produces fewer false confident YIELDs than nominal two-point secant TTC in bounded-noise and irregular-sampling evaluation strata without delaying an in-model warning by more than 100 ms.

**T.** Generate 200 sequences from seed 8157: ten declared profiles, 20 sequences/profile, 12 time slots/sequence, nominal 30 Hz, declared radius error bound 0.5 px, TTC cue threshold 2.0 s. Each profile has 10 hazard and 10 nonhazard sequences. Sequence membership is split by within-profile ordinal: even ordinals are calibration, odd ordinals evaluation (100 each; 50 hazards and 50 controls per split). The candidate input contains only opaque IDs and public observations; profiles, split, hazard status, true radii/TTC, and actual error amplitudes are auditor-only. Missing observations use null radii and do not expose their cause. Track ID changes remain visible as a validity signal.

Profiles: (1) constant-velocity approach; (2) pass-by with radial expansion followed by contraction; (3) stationary/no-expansion; (4) constant-velocity approach with bounded iid error; (5) constant-velocity approach with bounded correlated error; (6) constant-velocity approach with irregular times and dropped samples; (7) onset acceleration/deceleration; (8) partial occlusion; (9) track identity swap; (10) deliberately understated declared error bound. Profiles 1, 4, 5, and 6 are the in-model hazard strata when their oracle says hazard; other profiles test fail-closed behavior and the limits of the declared model. Understated-bound cases are explicitly misspecified, so confident cues or lost containment are a method failure, even if other profiles pass.

Each method emits per-prefix raw point estimates or conservative TTC intervals. A common threshold is selected separately per method using calibration controls only: among thresholds at observed calibration score values plus 2.0 s, select the largest threshold with zero confident-YIELD calibration controls; ties use the smaller threshold. The primary matched operating point is therefore 0/50 false-YIELD calibration controls for both methods. No threshold is selected from evaluation labels. A prefix yields only if its point estimate (secant) or entire interval upper endpoint (set-valued) is at or below that method's selected threshold. Earliest YIELD time is scored. Warning lead is oracle TTC at that timestamp; the interval method may not trail a paired point-method detection by more than 100 ms. If the point method detects an eligible hazard and the interval method does not, this is a lead-criterion failure.

For context, also retain public per-prefix absolute radius change and relative circular-area change (`abs(r_now-r_prev)` and `abs(r_now^2/r_prev^2-1)`). Score them with the frozen #8112 threshold grids (pixel: 50, 100, 200, 400, 800, 1600, 3200, 6400, 12800; area: .01, .02, .05, .10, .20, .40, .80), selecting the largest threshold with zero calibration-control false YIELDs. These are radius-only derived cues, not a reproduction of #8112's raster/PGM measurements or corpus, and are descriptive only; the primary matched comparison remains point secant versus interval TTC.

The independent auditor reconstructs all oracle traces and candidate values. It checks interval containment for every in-model eligible hazard prefix, UNKNOWN on invalid/empty/nonexpanding/threshold-crossing or unsupported track histories, zero calibration false-YIELD matching, evaluation false-YIELD counts per profile, the 100 ms paired lead criterion, and one-shot hashes/invocation counts. It runs five corruption checks: changed bound, timestamp, removed sample, oracle hazard label, and interval endpoint. Every corruption must be rejected by an independently recomputed invariant. No retries or result-driven tuning.

**D.** `PASS_METHOD_SCOPED` only when every in-model oracle TTC is contained, invalid and misspecified cases fail closed, at least 50% of observed eligible prefixes receive a numeric interval separately in approach, iid, correlated, and irregular/dropout profiles, interval false-YIELD count is strictly below point secant separately in iid, correlated, and irregular/dropout evaluation profiles at the matched calibration operating point, the paired lead criterion passes, each method yields on at least one eligible in-model hazard, all mutations are rejected, and run integrity is exact. `NO_INCREMENTAL_VALUE` if valid intervals are mostly UNKNOWN, there is no strict false-YIELD reduction, or the reduction costs more than 100 ms of lead. `FAIL_METHOD` for any in-model interval miss, confident cue on invalid/misspecified data, audit mismatch, or integrity failure. Report each profile separately; no averaging across failures.

**C.** A point cue may be adequate; conservative intervals may suppress useful cues; image-radius bounds can be wrong; nonradial motion, zoom, animation, or identity changes can mimic expansion. The #8112 corpus remains unchanged and is not this experiment. The older #8112 thresholds are not silently transplanted because its five-frame raster corpus and endpoint-cue definitions differ from this 12-slot radius corpus. This protocol's point-secants are the matched primary baseline.

**U.** This is synthetic finite-method evidence under explicit assumptions. It does not calibrate real measurement bounds, recognize scene semantics, test GUI/game behavior, authorize actions, or establish runtime or safety claims.
