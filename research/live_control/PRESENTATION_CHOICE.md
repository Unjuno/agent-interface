# Prepare presentation fallback before output

presentation_choice_v1 parses and validates the saved original JSON before trying composed_result_v1. It requires exact reconstruction and selects composition only when canonical UTF-8 bytes decrease. Otherwise it emits the original JSON directly. A preparation exception or mismatched reconstruction returns a presentation-fallback-v1 wrapper containing the complete original result and the formatter error. This does not change terminal status, infer task success or send an operation.

The catch covers only composition/validation, before output begins. deliver writes a choice sidecar then invokes the existing emission recorder once. Stream failure is propagated with the existing emission receipt; there is no second fallback frame after a partial write. The module has no runtime socket or operation-submission dependency. Source parse errors, evidence directory collisions, filesystem failures and unrecoverable process failure are not silently treated as successful delivery. Raw operation results must already be saved by the caller.

Linux probe presentation-choice-01 uses the archived Inkscape invalid-entry result. Four controls cover valid composition, no-size-benefit original output, formatter exception and corrupted reconstruction. Every retained result exactly matches its original, including all negative/unknown attention fields. Injected partial stream failure acknowledges seven bytes, then raises on the second write; only one emission attempt is made. Duplicate source keys and nonfinite JSON are rejected. No new GUI actions or model calls were involved, and no latency/token advantage is claimed.

inkscape_composed_live_v2 wires this helper after saving result.json, leaving measured v1 unchanged. The v2 wiring has been syntax-checked but not used in a new live episode. It protects only the optional final composition stage; failures earlier in receipt/state-table construction still propagate and need separate recovery design. A storage failure before emission can still prevent delivery. Full original records remain available for explicit reconciliation without resending input.
