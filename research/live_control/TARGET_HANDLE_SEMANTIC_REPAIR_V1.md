# Target-handle semantic repair

This step removes the direct handoff from a hard-coded window crop to semantic
probing. A verified exact-pixel Save-button handle supplies the anchor. A frozen
local relation maps that anchor box to the future submission-heading region.
The derived predicate remains a no-authority observational contract.

In the fresh seed212 Chromium allocation, the interface minted and resolved the
Save handle, derived the initial completion region, then resized the same
surface from 1050 to 930 pixels wide. The old contract refused
`surface_size_changed` before hashing pixels. Current exact Save-button pixels
then revalidated the same handle, and the interface regenerated the semantic
contract for the new geometry without a model call.

The repaired handle point submitted `t000212`; independent server scoring,
exact-frame reconciliation and empty release passed. The first allocation
passed all 17 frozen checks and both Windows/WSL audits, with zero retries.

The anchor-to-semantic relation was calibrated for this fixture. This result
does not show automatic relation discovery, success rates across layouts,
actual model-token savings, portability, a causal speed comparison or human
tempo. The next meaningful comparison is a matched block with cached local
repair versus model reacquisition on changed geometry, using the same model,
task and layout changes and charging every model call and image.
