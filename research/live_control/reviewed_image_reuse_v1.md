# Explicitly reviewed image reuse (opt-in host presentation)

Set `reuseReviewedImages: true` in `createInstrumentedRelayClient` to enable this host-local adapter. The default remains full image presentation. Present the initial response, actually inspect its image, then call `review(attempt, {task, phase, reason})`. Presentation alone and a review of an unpresented response do not establish a base.

After that acknowledgment, a response containing exactly one identical, canonical-base64 PNG can replace its image callback with a text callback carrying `agent-interface/reviewed-image-reference-v1`. The reference identifies the original attempt, retained reply SHA, explicit review receipt SHA, and image SHA. Equality is a direct comparison of encoded PNG bytes, not a hash match or perceptual similarity. All original text and other response blocks are still presented. The full original MCP response, including the image, is transferred and retained unchanged.

The adapter holds one base, limited to 16 MiB of encoded data. A changed image, ineligible response, or full presentation clears the base; a new explicit review of the latest full presentation is required. References always point to the original reviewed full image, never a reference chain. A fresh connection has no base. Presentation/instrumentation failures clear state and block subsequent action; cleanup remains allowed.

Use `present(attempt, callbacks, {forceImage: true})` whenever the earlier image is no longer available in the model context. Prefer a fresh observation for this resynchronization: retained review receipts are exclusive and an old attempt cannot be reviewed twice. The adapter does not detect model context eviction automatically. Only enable reuse when the caller can preserve that reviewed image or explicitly request a full image after context changes.

Host events record full versus reference presentation. The read-only Python host-timing checker independently validates the base acknowledgment, receipt hash, retained image bytes, event order, and reset history. A review receipt is caller attribution, not proof of attention or model ingestion. Unchanged PNG bytes do not prove redraw, application readiness, lack of intermediate changes, or task completion. Current reply metadata must still be evaluated independently.

This changes host-to-model presentation only. It does not avoid capture, encoding, MCP image transfer, or raw evidence storage. Image callback counts and encoded byte counts are measurable here; actual model input tokens, cost, useful-feedback latency, and semantic completion latency require separate measurement. No performance improvement is claimed from the adapter tests.

Validation includes the existing full-presentation path, explicit acknowledgment, changed image, unpresented review, original-base retention, force-full resynchronization, fresh connection, failed reference rendering, and cross-language validation of real Node-emitted events. Independent mutation controls reject forged base identities, missing acknowledgment, changed bytes, and inconsistent completion annotations.
