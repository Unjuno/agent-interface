# Local presentation emission boundary

presentation_emission_v1 records the exact intended UTF-8 JSON plus newline, SHA-256, byte length, and local serialization/write/flush timestamps in an exclusive attempt directory. It writes to a binary stream, handles short writes, and records failures before propagating them. Reusing an attempt directory fails without overwriting evidence. CLI accepts a JSON source and a new receipt directory; stdout contains only the serialized payload.

The saved payload is intended output, not proof of delivery. accepted_bytes counts only successful write return values; a write that changes the stream and then raises may have transferred additional unacknowledged bytes. Flush success is a local boundary, not tool-layer or model receipt. Receipts are not authenticated and a hard process crash or evidence-storage failure can prevent final receipt persistence. Timing records do not establish a shared clock epoch with other processes. Serialization timestamps exclude initial directory creation; payload persistence sits between serialization and write.

Linux probe presentation-emission-01 passed four stream controls: full write, three-byte short writes, failure after three acknowledged bytes, and failure on flush. It also verified exact received bytes through a real subprocess pipe and rejected an attempt-directory collision. False task success and Japanese/negative attention text survive JSON serialization. Source hashes and raw evidence are retained. This is transport evidence, not a GUI benchmark or an input-token reduction result.

Model receipt, model identity, input tokens and cost are explicitly null / not recorded. Output can still be transformed or truncated by the tool layer. Never derive these missing endpoints from local output length or elapsed runtime. No existing frozen client or default is changed. Next integrate this boundary into a new explicit client candidate and a changed task with negative evidence, then obtain independently exposed model usage if available. Until then matched model-facing speed and token comparisons remain incomplete.
