## Provenance and independence boundaries

at the base above (A01 scientific source lineage 48ce12d529c1a9127e46eda4b33bcaaa278129a2).
execution_guard is an identical copy of the historical oracle used for per-cell
fail-fast; it is NOT an independently implemented scientific oracle. The saved-only
auditor is a separate process that imports the immutable historical audit and
qualification, never producer, observer or execution_guard. Its eight historical
mutations exercise saved-data rejection. New qualification unit tests provide
literal boundary/unknown/type counterexamples; they are construction evidence.

timing.py copied from D01 main; observer.py adapts D01 instrumented observer to
the new path and old producer CLI. Deadline/resource telemetry is retained for
diagnosis; A02 scientific qualification does not independently adjudicate every
optional scheduler-counter grammar. Snapshot/flush overhead precedes XGetImage,
so this is an instrumented variant, not a replay of original A01 pacing.

runner.py launches one native container with a fresh private Xvfb per cell,
read-only source/root, network none, no capabilities and no new privileges.
Private engine is not an exclusive physical host. GitHub-hosted Actions unchanged.
Construction runs three fixed dark/persistent/pulse cases, excluded from formal
114-cell data; all outputs and first failures are retained.
