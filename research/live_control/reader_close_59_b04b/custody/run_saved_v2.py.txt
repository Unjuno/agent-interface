"""One saved-only auditor invocation with actual PID, UTC and byte streams."""
import datetime, hashlib, json, pathlib, subprocess, sys
R = pathlib.Path(__file__).resolve().parent
def utc(): return datetime.datetime.now(datetime.timezone.utc).isoformat()
def sha(b): return hashlib.sha256(b).hexdigest()
argv = [sys.executable, '-B', str(R / 'check_saved_v2.py')]
intent = {'argv': argv, 'cwd': str(R), 'created_utc': utc(), 'auditor_sha256': sha((R / 'check_saved_v2.py').read_bytes()), 'saved_only': True}
with (R / 'SAVED_INTENT.v2.json').open('x', encoding='utf-8') as f: json.dump(intent, f, indent=2); f.write('\n')
started = utc(); p = subprocess.Popen(argv, cwd=R, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
out, err = p.communicate(timeout=10)
(R / 'saved.stdout.v2.log').write_bytes(out); (R / 'saved.stderr.v2.log').write_bytes(err)
receipt = {**intent, 'pid': p.pid, 'started_utc': started, 'ended_utc': utc(), 'exit_code': p.returncode, 'stdout_bytes': len(out), 'stdout_sha256': sha(out), 'stderr_bytes': len(err), 'stderr_sha256': sha(err)}
with (R / 'SAVED_RECEIPT.v2.json').open('x', encoding='utf-8') as f: json.dump(receipt, f, indent=2); f.write('\n')
if not p.returncode:
    with (R / 'SAVED_AUDIT.v2.json').open('xb') as f: f.write(out)
print(json.dumps(receipt, indent=2)); print(out.decode('utf-8', errors='replace')); print(err.decode('utf-8', errors='replace'))
raise SystemExit(p.returncode)
