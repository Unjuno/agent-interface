# Retained runtime results

This directory contains committed runtime demonstration/result artifacts used by the runtime reports and audits.

Current retained result namespaces include:

- `golden-desktop-live-*` — earlier golden desktop runs;
- `golden-desktop-app-server-v2-live-*` — app-server v2 retained run(s);
- `golden-desktop-app-server-v3-live-*` — app-server v3 retained run(s).

Use [`../README.md`](../README.md) and the corresponding `GOLDEN_DESKTOP_DEMO_V*.md` report for interpretation. A result directory is retained evidence, not a claim of general runtime or platform support.

Fresh local executions should continue to use ignored local artifact paths rather than overwriting committed retained results.
