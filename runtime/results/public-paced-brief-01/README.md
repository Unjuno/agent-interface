# Opt-in public paced-dispatch brief integration

Public MCP dispatch and retained results now accept detail=brief for eligible
paced-text dispatches with compact/report_refs. Full remains the default.
Supported completed execution records can be projected to a distinct partial
schema, preserving outcomes, release records, images and session state. Complete
source reports remain retained; presentation.retrieve names the exact full call.
Failures, inconsistent/unknown wait records and non-smaller projections stay full.

two brief action images, recorded reviews against their unchanged image identity,
retrieved the first action's full report without input, exercised unsupported
