sample; they do not establish a generic performance benefit.

The first full loop includes one-time common adapter/program registration, and
its owner window additionally includes plan/caller preparation. These costs remain
counted; its apparent token advantage is not attributed to summary. Fixed order,
evolving context, cache and learning further confound causal attribution even with
ABBA ordering. Model alias/effort match; exact provider build and context equivalence
are unproven. No significance, billing savings or human-speed claim is made.
